## 数据源计划(按优先级,逐个验证再用)
### 韩国(首尔)
1. FRED `QKRN628BIS`(BIS名义房价,全国,季度)— 兜底,注意全国口径低估首尔
2. KOSIS / KB / REB R-ONE — 首尔公寓月度,如需注册则放弃
3. 首尔 PIR 锚点: KB口径峰值约 2021-22 ≈ 19(中位房价/中位收入),用 web search 确认
### 台湾(台北)
1. 内政部 pip.moi.gov.tw 季度「房价所得比」— 现成 PIR,优先
2. FRED `QTWR628BIS` — 可能不存在(BIS不含台湾),备用信义/国泰指数
### 新加坡
1. data.gov.sg API: HDB Resale Price Index + URA Private Residential PPI(开放,无需注册)
2. SingStat 家庭月收入中位数序列(data.gov.sg)做收入校正
3. PIR 锚点: 组屋 ≈4-5, 私宅 ≈13-15(需 search 确认)
### 中国/美国(重建序列用于对齐图)
- 中国: 东方财富70城API 二手房环比连乘(已验证)
- 美国: datahub Case-Shiller cities-month-NSA.csv(已验证)

## 方法
- 指数→PIR: 用官方 PIR 锚点年标定,PIR(t) = 锚点PIR × [P(t)/P(锚)] ÷ [Inc(t)/Inc(锚)],收入用当地名义收入增速序列(非常数)。
- 峰值对齐: 各序列除以峰值,横轴 = 年份 - 峰值年。
- 图: matplotlib + Microsoft YaHei(Windows),中文标注。
