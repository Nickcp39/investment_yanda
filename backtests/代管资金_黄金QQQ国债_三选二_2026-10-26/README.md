# 黄金 / QQQ / 国债 三选二 · 2026-10-26

代管资金系列第五篇。前提：基本放弃个股、不想买太多国债。按担保人指标（5 年滚动中位 / 最差 / 为负比例 / 期望赔付、最大回撤、2022）算了三个单资产、两两组合、三三组合和保本结构，两个样本：1985 起（纳指100 接 QQQ 含分红）和 1970 起（标普替代，含 1980 年黄金顶）。

结论：去掉国债的 QQQ/黄金是两两组合里担保人指标最好的一对，但黄金今天在 1980 起 98 分位；去掉黄金的 QQQ/国债在国债只占三四成时挡不住 2000 和 2022；去掉 QQQ 的组合被前两对压住。数据给的答案是三个都要但国债不多（QQQ40–50 / 金25–30 / 债25–30），1970 起没有过负的 5 年。
