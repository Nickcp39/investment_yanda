# QQQ 一次性买入 vs 分批买入 · 按起点高低分组 · 2026-10-11

问题：从和 2026-10 一样「偏高」的起点进场，一次性和分批各自后来怎样。
数据：../QQQ_现在高不高_危机后视角_2026-10-09/data（QQQ 含分红复权，截至 2026-10-08）。
起点高低 = 纳指100 相对 2009 起对数趋势线的偏离在时代内的分位（样本内，与 10-09 报告同法）。
分批 = 每月等额，未投现金零收益。起点按周采样（每 5 个交易日一个）。

- `lump_vs_dca.py` → `results.csv`（每个起点的 3y/5y 结果、期间最深浮亏、1 年后是否仍亏）、`summary.csv`（按样本分组汇总）、`named_starts.csv`（2021-11 顶等具名起点）、`lump_vs_dca.png`
- 关键数（起点 ≥90 分位，n=79，集中在 2010–11、2020–22、2026 三段）：3 年后中位 一次性 +35% / 分 24 月 +43%；期间最深浮亏中位 -22% / -16%，最差 -35% / -21%；一年后仍亏概率约 54–61%。
- 全部起点：一次性 3 年赢过分 12 月的比例 87%，5 年 91%；≥90 分位起点降到 52% / 71%。
- 样本少且重叠，只能当案例读。
