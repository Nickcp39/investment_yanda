# SPY / QQQ 五年滚动回报（历史回测）

更新时间：2026-07-25  
数据截至：2026-07-24

## 数据口径

- 来源：Yahoo Finance Chart API。
- 使用 `adjclose`，反映拆股和现金分红调整。
- 五年窗口按“起始年最后一个交易日 → 五年后最后一个交易日”计算。
- 累计总回报：`结束复权价 / 起始复权价 - 1`。
- CAGR 按实际经过天数计算：`(结束复权价 / 起始复权价)^(365.2425 / 实际天数) - 1`。
- 2021 年末 → 2026-07-24 尚未满五年，单独标为不完整窗口，不计入完整窗口统计。

## 文件说明

- `SPY_daily_adjusted.csv`、`QQQ_daily_adjusted.csv`：复权日线原始数据。
- `year_end_adjusted_prices.csv`：各年最后交易日复权价格。
- `rolling_5y_last_30_years.csv`：近 30 年 / 全部可用历史的逐年五年窗口。
- `rolling_5y_2008_to_2026.csv`：2008 年末起的逐年五年窗口。
- `analysis_snapshot.json`：汇总统计、整体持有期和来源信息。
- `download_and_prepare.ps1`：可重复运行的数据下载与计算脚本。

历史回测与当前年度、2027 年预测应分开处理；本目录暂不包含预测。
