## 1. 主轴：目标 2 和目标 3 是同一件事

**段永平的招牌动作就是卖 put。** 所以"搞懂 put"和"学段永平"不该分开学。

而他卖 put 的逻辑，和你自己 BTC 计划 v2 §7 写下的纪律**是同一条**：

> 「时间 / 挂单代替决定——到日期就买，永不临场问该不该。」

**一份现金担保 put ＝ 一个会付钱给你的限价单。**

这就是整份计划的主轴：**不学"期权交易"，只学"用期权更好地执行你本来就要做的买入"。**

## 2. 期权最小必要知识

### 2.1 定义（就这么多）

| | 是什么 | 买方的权利 |
|---|---|---|
| **Call（看涨期权）** | 以**行权价买入**标的的权利 | 涨过行权价才有价值 |
| **Put（看跌期权）** | 以**行权价卖出**标的的权利 | 跌破行权价才有价值 |

- 美股 1 张合约 = **100 股**
- **买方付权利金**（premium），**卖方收权利金**
- 买方有权利无义务；**卖方有义务无权利**——这是全部风险的来源
- 到期日（expiration）、行权价（strike）、内在价值 vs 时间价值

### 2.2 四个基本头寸，只有一个符合你的体系

| 头寸 | 本质 | 判定 |
|---|---|---|
| 买 call | 同时押方向 + 押时间 | ❌ **时间是你的敌人**，标的不动你就亏光。纯投机 |
| 买 put | 买保险 / 做空 | ❌ 长期持有者常年付保费是负和游戏 |
| **卖 put（现金担保）** | **收钱等自己的买点** | ✅ **唯一符合**——见 §3 |
| 卖 covered call | 收钱，但封顶上涨 | ⚠️ **把最好的结果卖掉了**。长期复利最怕这个 |

> **为什么 covered call 对你是错的**：你的整套体系押的是"找到能拿十年的生意"。
> 卖 covered call 等于在最该拿住的那一次上涨里被强制卖出。用一点权利金，
> 换掉那条决定一生回报的右尾。**不做。**

## 3. 段永平的 put：机制与三条铁门槛

### 3.1 机制

你想在 $80 买 A 公司（现价 $100）。卖一张行权价 $80、到期 3 个月的 put，收权利金 $3/股：

- **跌破 $80 被行权** → 你以 $80 买入（本来就想要的价），**外加白拿 $3** → 实际成本 $77
- **没跌到 $80** → 白拿 $3，继续等下一轮

**两种结局你都不亏。** 这就是为什么它和你的 DCA 哲学同源——**每种结局你都"部分对"**。

### 3.2 ⚠️ 三条铁门槛，缺一条就变成赌博

```
1. 你真的想在那个行权价买这家公司（已过 pipeline，有 decision_card 裁决）
2. 账上真有全额现金（cash-secured，不是 margin）
3. 你接受被行权，不打算靠"平仓"逃跑
```

**违反第 2 条 = 裸卖 put = 无限风险的赌博。** 券商允许你用保证金卖 put，
那是它的生意，不是你的策略。

**违反第 1 条最隐蔽**：为了权利金去卖一家你不想要的公司的 put，
迟早会以你不想要的价格，买到你不想要的公司。

### 3.3 这条工具在本 OS 里的位置

它属于 **L6 Portfolio judgment 的执行层**，**不是选股层**。

> **前置门**：任何标的要卖 put，必须先有 `decision_card.md` 且 verdict ≥ STARTER，
> 行权价必须 ≤ `valuation.md` 里的"Buy below"。
> **没有 decision_card 的标的，不许卖 put。**

## 4. 巴菲特的 put 案例（学思路，别学动作）

2004–2008 年伯克希尔卖出超长期股指 put，收取约 **$49 亿**权利金〔待核〕：

- **欧式**期权（只能到期日行权，中途再深的浮亏都不用交割）
- 期限 **15–20 年**
- **不需要缴保证金** —— 这是最关键的一条

→ 等于拿到一笔**期限极长、成本为负的浮存金**。2008 年按市价计价的浮亏让
财报难看，但他从头就知道那不是真实亏损。

**⚠️ 为什么你复制不了**：能这么做的前提是**伯克希尔的信用评级换来了"不缴保证金"条款**。
散户卖长期 put 必须全额占用现金或保证金，浮亏会触发追缴。
**学的是"卖出别人恐慌时高估的保险"这个思路，不是这个动作。**
