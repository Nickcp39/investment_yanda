## 0. 三段式：这是行业里真实在用的流程

投行 / 自营的初级交易员走的就是这三段：

```
课堂培训  →  模拟盘  →  小额实盘（限额 + 监督）  →  放开限额
```

对应到你这里：

| 段 | 内容 | 载体 | 状态 |
|---|---|---|---|
| **① 理解** | 概念、定价、结算机制 | **OIC + CBOE 免费课程**（见 §1） | ⬜ **本文件** |
| **② 学习** | 五个设计实验，模拟盘 $100k | `paper_trading_program.md` | ✅ 已建 |
| **③ 测试** | 真金 $3,000，条款驱动，记账归因 | `single_name_discipline.md` + `position_book.md` | ✅ 已建 |

**你自己想出的顺序是对的。缺的只是第一段。**

## 2. 排期：8 周学完，实验并行跑 12 个月

每阶段学完**必须跑对应实验**才算过。**不做实验的阅读等于没学。**

### 阶段 0 · 概念（1 周）

- **学**：OIC "Options Basics" ＋ CBOE `Options 101`
- **搞懂**：call / put、行权价、到期日、1 张 = 100 股、内在价值 vs 时间价值、买方 vs 卖方的权利义务不对称
- **验收**：不看资料，说清五种做法各自的盈亏（买股 / 买 call / 买 put / 卖 put / covered call）
- **实验**：无（先建概念）

### 阶段 1 · 定价三因素（2 周）

- **学**：OIC 的 pricing 模块；**delta 和 theta 就够了**
- **搞懂**：为什么"股票不动，买方也在亏"
- **⚠️ 不深挖** gamma / vega / rho —— 卖现金担保 put 用不到，早学是浪费
- **验收 → 跑 E2**（买张平值 call 什么都不做，每周记价值）

### 阶段 2 · 卖方视角（2 周）

- **学**：OIC 的 cash-secured put、covered call 模块
- **搞懂**：为什么时间站在卖方这边；卖方的风险边界在哪
- **验收 → 跑 E1**（卖 put vs 挂限价单，两条腿并行）
- **验收 → 跑 E3**（covered call 的机会成本）

### 阶段 3 · 波动率（2 周）

- **学**：OIC / CBOE 的 IV 模块
- **搞懂**：IV 是什么、财报前后为什么会崩、**为什么方向猜对了还亏钱**
- **验收 → 跑 E4**（财报前买 call）

### 阶段 4 · 结算与行权（1 周）

- **学**：**OIC 的 assignment / exercise 模块**（OCC 自己办的，这块没有更权威的）
- **搞懂**：什么时候被通知、现金怎么扣、成本基础记成多少、提前行权在什么情况下发生
- **验收 → 跑 E5**（故意被行权，走完全流程）

### 阶段 5 · 段永平 / Buffett 的用法（持续，无课程）

> **⚠️ 这一段任何期权课程都不会教。**
> OIC 和 CBOE 教的是**策略**（怎么用工具赚钱）；
> 段永平和 Buffett 的用法是**把期权当买入执行工具**（我本来就想在那个价买）。
> **这是两种完全不同的心智模型，标准教材里没有。**

- **材料**：段永平雪球原帖（苹果、网易）；Berkshire 股东信里关于股指 put 的段落
- **产物**：`frameworks/duan-yongping/principles.md`（README 承诺过，至今不存在）
- **核心问题**：他们为什么几乎只卖不买？为什么从不做价差组合？

## 3. 每阶段的验收标准（自己诚实打分）

| 阶段 | 能不看资料回答，才算过 |
|---|---|
| 0 | 我买一张 $32 call 花 $150，股票涨到 $33 我赚还是亏？为什么？ |
| 1 | 股票三个月一动不动，我那张 call 会怎样？第一个月和最后两周哪个掉得快？ |
| 2 | 卖 put 和挂限价单，什么情况下卖 put 会输？ |
| 3 | 财报后股票按我想的方向涨了 5%，我的 call 为什么反而亏了？ |
| 4 | 被行权那天，账户里具体发生了什么？成本基础是多少？ |
| 5 | 段永平卖 put 时，他真正在赌的是什么？（提示：不是权利金） |

---

## 4. 明确不学（省下的时间用来读财报）

| 不学 | 理由 |
|---|---|
| 价差、铁鹰、跨式、日历价差等组合 | 交易员的活，不是所有者的活 |
| gamma / vega / rho 深挖 | 卖现金担保 put 用不到 |
| 期权定价模型推导（Black-Scholes） | 你不需要自己算，只需要会读报价 |
| 0DTE、周期权 | 纯赌博 |
| 技术分析择时 | 与整个 OS 的证据标准不兼容 |
