# 单票操作纪律 · 散股层

> **适用范围：散股桶的个股（NBIS、GOOGL、MSFT…）。**
>
> **不适用**：
> - **BTC** → `execution_plans/btc_investment_plan_2026-08-07_v3.md` + `tax_residency_exit_plan.md`
> - **大盘指数（QQQ/SPY/BRK.B）** → `execution_plans/equity_index_plan_2026-08-07.md`
>
> 那两层是机械定投，没有自由裁量空间，也就没有本文件要治的病。
> **本文件只管一件事：单个股票上，buy / sell / call / put 四个动作各自的触发条件。**
>
> 立约日期：2026-08-08 · 活例子：NBIS

## 0. 诊断（为什么需要这份文件）

**买入端有数字，卖出端没数字。**

以 NBIS 为例，`companies/nbis/2026-07-10/decision_card.md` 写着：

| 动作 | 有没有规则 |
|---|---|
| **买** | ✅ 有精确数字：buy-below `<~$150–180`，STARTER 门 `<~$180`，max size `≤4%` |
| **卖（thesis 坏了）** | ✅ 有：K-A ~ K-F 七条 kill criteria + monitor「2+ reds → trim」 |
| **卖（价格太高）** | ❌ **没有。这张卡没有 Trim zone。** ASML 有（`≥$1,900–2,000`）、HWM 有（`≥$300–330`），NBIS 没有 |
| **call / put** | ❌ 全库零内容 |

**"找不到卖的机会"不是心理问题，是这张卡上真的少了一个字段。**
买入你知道 $180 是门；卖出你没有任何数字，于是只能盯盈亏。**盈亏是唯一每天都在动的数字。**

## 1. 铁律：盈亏百分比不是任何规则的输入

```
"我现在赚 X% / 亏 Y%"  →  与四个动作的所有规则无关
```

成本价是**你的历史**，不是**公司的现实**。合法的参照系只有两个：
**thesis 是否成立**（monitor.md）、**价格相对内在价值在哪**（decision_card 的价格带）。
两个都与你的买入价无关。

## 3. BUY

### 3.1 触发条件（三个全满足才动）

```
1. verdict ≥ STARTER（不是 WATCH，不是 INFO-GAP）
2. 价格 ≤ decision_card 的 buy-below 带
3. 完整度封顶已解除（或明知封顶而接受更小仓位）
```

### 3.2 不是买入信号

| 情形 | 判定 |
|---|---|
| 跌了很多 / 从高点腰斩 | ❌ **跌幅不是估值**。要看的是价格 vs buy-below 带 |
| 别人在买、消息面好 | ❌ |
| "再不买就来不及了" | ❌ 这是 FOMO，不是规则 |
| verdict 是 WATCH 但"感觉快到了" | ❌ **WATCH 就是不买。** warming 也是 WATCH |

### 3.3 NBIS 实况

```
现价 $219.65  |  STARTER 门 <$180  |  buy-below 带 $150–180  |  max size ≤4%
距门还有 -18%
新钱裁决 WATCH（warming toward STARTER）→ 不买
持仓裁决 HOLD（持有成本 ~$190–195，+13%）→ 不加不减
```

**注意：$219.65 是 2026-07-10 的收盘。用之前先刷新价格。**

## 4. SELL

### 4.1 S1 — Thesis 破了（与价格无关）

**照抄 monitor.md 的动作规则，不许临场发挥。**

NBIS：`Q2 2026 6-K (~Aug 2026)` → 查 **active MW / capex 实际值 / 递延收入趋势 / MSFT-Meta tranche**
→ **动作规则：2 项转 🔴 就 trim**。

> 不是"感觉不太好"就减，也不是"1 项红但我很担心"就减。**数 🔴 的个数。**

七条 kill criteria（K-A 至 K-F、K-VAL）见 decision_card，此处不重复。

### 4.2 S2 — 价格到了（与 thesis 无关）⚠️ NBIS 缺这个字段

NBIS 的卡上**没有 Trim zone**。但它自己的数字足以推出一个 —— 逻辑是
**"涨到哪里，base case 就不再跑赢 hurdle"**：

```
base 目标 $330–400（horizon end-2028 ≈ 2.48 年）
hurdle 12–15%
临界价 = 目标 / (1+hurdle)^2.48

  $330 @ 15% → $233        $330 @ 12% → $249
  $400 @ 15% → $283        $400 @ 12% → $302
```

→ **推导出的 no-chase 区间 ≈ $233–302**（52 周高点 $299.86 落在上沿）。

**⚠️ 这是我用你卡上的数推的，不是你定的。** 你需要自己拍一个数字写回 decision_card，
比如 `Trim / no-chase zone: ≥ $250`。**在没有这个数字之前，S2 无法执行，
NBIS 的卖出端就只有 S1 一条腿。**

**这件事今天就能做完，而且它直接解决你"找不到卖的机会"。**

### 4.3 ❌ 明确不是卖出信号

> 这张表比上面两张更重要。BTC 计划 §6 最有价值的部分就是"什么**不是**停手理由"。

| 情形 | 判定 |
|---|---|
| **单纯下跌 / 出现浮亏** | ❌ **这是你现在最主要的失败模式** |
| 涨了很多 / 浮盈很大 | ❌ 除非进了 Trim zone（S2） |
| 宏观 risk-off、大盘在跌 | ❌ |
| 别人在卖、社媒在恐慌 | ❌ |
| "已经赚够了" / "落袋为安" | ❌ 这是把成本价当参照系 |
| 财报当天股价大跌 | ❌ **看财报内容对 monitor 变量的影响，不看当天的价格反应** |
| 某个 monitor 变量转 🟡 | ❌ 🟡 是加密关注，不是动作 |
| 越看越慌 | ❌ 这是 §7 的问题（看太勤），不是卖出问题 |

**一个例外，需额外条件**：「好消息、坏反应」（`_derated_bigtech_2026-08-07/synthesis.md` C9）
—— 业绩全面超预期但股价大跌，是体制切换的当天可读信号。
**但它单独不构成卖出理由，必须配合 monitor 变量的实际恶化。**

## 5. PUT

### 5.1 🔴 先算资金规模门槛（这一条会否决掉绝大多数情况）

美股 **1 张合约 = 100 股**。现金担保 put 必须锁定 `行权价 × 100` 的现金。

```
总盘 $35,798 | 散股桶 11% = $3,938 | 单票上限 4% = $1,432

卖 1 张 NBIS put @ $180 → 锁定 $18,000
   = 散股桶的 4.6 倍
   = 单票上限的 12.6 倍
   = 总盘的 50%
```

**反推：要在 4% 单票上限内卖 1 张 put，总盘需要 `行权价 × 2,500`**

| 行权价 | 所需总盘 |
|---:|---:|
| $180 | **$450,000** |
| $150 | $375,000 |
| $50 | $125,000 |
| $20 | $50,000 |

**你当前总盘能支持的最高行权价 = $14.32/股。**

> ### 结论：**期权在你当前的资金规模下不可用。**
> 不是策略不对，是**买不起最小单位**。一张合约就会让单票敞口超限 10 倍以上，
> 直接违反你自己的 4% 上限。
>
> **重估触发点：总盘 ≥ $125,000**（此时 $50 以下的标的开始可行）。
> **在此之前，PUT 一节只需要理解，不需要执行。**

### 5.2 规模够了以后，三条铁门槛（缺一条就是赌博）

```
1. 你真的想在那个行权价买这家公司 —— 有 decision_card 且 verdict ≥ STARTER，
   行权价必须 ≤ buy-below 带
2. 账上真有全额现金（cash-secured，绝不用 margin）
3. 你接受被行权，不打算靠平仓逃跑
```

**违反第 2 条 = 裸卖 put = 无限风险。** 券商允许你用保证金卖，那是它的生意，不是你的策略。
**违反第 1 条最隐蔽**：为了权利金去卖一家你不想要的公司的 put，
迟早会以你不想要的价格，买到你不想要的公司。

### 5.3 为什么这个工具值得学（虽然现在用不了）

**卖现金担保 put ＝ 一个会付钱给你的限价单。**

你想在 $180 买 NBIS（现价 $220）。卖一张 $180 的 put 收权利金 $5/股：
- **跌破 $180 被行权** → 以 $180 买入（本来就想要的价）+ 白拿 $5 → 实际成本 $175
- **没跌到** → 白拿 $5，继续等

**两种结局都不亏** —— 和你 BTC 计划 §7 的「时间/挂单代替决定、每种结局我都部分对」是同一个哲学。
这也是**段永平的招牌动作**。

## 6. CALL

| 头寸 | 判定 | 理由 |
|---|---|---|
| **买 call** | ❌ **禁止** | 同时押方向 + 押时间。标的不动你就亏光。**时间是你的敌人**，与十年持有体系正面冲突 |
| **卖 covered call** | ❌ **禁止** | 收一点权利金，**把右尾卖掉了**。你整套体系押的是"找到能拿十年的生意"，卖 covered call 等于在最该拿住的那次上涨里被强制卖出 |

**这一节没有例外条款，也没有资金规模门槛 —— 任何规模都不做。**

## 7. 仪式（没有这一节，上面全是纸）

**缺的不是规则，是把规则变成行动的日程。** monitor.md 的 Freq 列全是 `Q`（季度），
因为它跟踪的 MW 接入、tranche 交付、递延收入、折旧政策**一天不会变**。
而实际行为是每天看盈亏 —— **盯的是噪音里唯一会动的指针**。

| 频率 | 看什么 | 明确不看 |
|---|---|---|
| **季度**（财报后 3 个工作日内） | 打开 `monitor.md` 逐行更新 🟢🟡🔴，填状态行。**这是唯一做 S1 决策的时刻** | — |
| **每月一次** | 只问纪律：「该读的 monitor 读了吗？违约记录有没有新增？」 | **不看盈亏** |
| **每日** | **不看** | 不看价格、不看盈亏、不看新闻 |

**如果实在忍不住每天打开** —— 只允许查一个布尔值：

```
价格 ≤ buy-below 带  → 触发 BUY 流程
价格 ≥ Trim zone     → 触发 SELL-S2 流程
两带之间             → 无动作，关掉
```

**这两个数字是买入时就写好的，不是今天算的。** 查它 = 查布尔值，不是"评估行情"。

## 8. 两个测试，治两种反向的病

### 8.1 治「亏了就想卖」：**重新买入测试**

> **如果我今天完全空仓、手里是现金，我会以现价买入这个仓位吗？**

- **会** → 没有理由卖。你的浮亏与这个判断无关
- **不会** → 该卖，**不管盈亏**。继续持有只是不想认错

作用：**把参照系从"我的成本"换成"当前价值"**，从机制上绕开盈亏心理。

### 8.2 治「不亏就不想卖」：**私有化测试**

> **如果这家公司明天退市、我必须持有十年不能交易，我还愿意持有吗？**

这是 `souls_workflow.md` 里段永平（Chair）那条「100% 私有化测试」。

- **愿意** → 持有是判断，不是逃避
- **不愿意** → 你持有的理由是"还能涨"而不是"这生意好"，那么 S2 必须严格执行

### 8.3 通用兜底

> **我现在想动手 —— 是 BUY / S1 / S2 / S3 里的哪一条？具体哪一款？**
>
> **说不出具体条款 = 不动。**
