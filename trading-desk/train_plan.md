# 模拟盘训练计划 · 期权与单票操作

> **目的：在不赔真钱的前提下，把 call / put / 买 / 卖 四个动作的机制跑通，
> 并用可证伪的预测卡衡量判断力。**
>
> 立约日期：2026-08-08 · 周期：12 个月
> 配套：`discipline.md`（操作条款）、
> `../execution_plans/position_book.md`（记账格式）

---

## 0. 两个账户，分工明确

| | 模拟盘 | 真金账户 |
|---|---|---|
| 资金 | **$100,000（虚拟）** | **$3,000（学习资金）** |
| 练什么 | **机制**：期权怎么定价、怎么被行权、时间怎么吃掉价值 | **情绪**：钱真的在动的时候，纪律还在不在 |
| 仓位 | 按真实规则（单票 ≤4%，即 $4,000） | 同样规则，绝对金额小 |
| 允许犯错 | ✅ 鼓励，专门设计了会亏的实验 | ❌ 只做条款触发的动作 |
| 衡量 | **决策命中率** | **纪律遵守率** |

**为什么模拟盘要设 $100k**：它大到能让期权按正常仓位规则执行
（4% = $4,000 → 可做 $40 以内行权价；10% = $10,000 → $100 以内）。
**你练的是 3-5 年后要用的纪律，不是现在这个规模的临时约束。**

**为什么真金只用 $3,000**：模拟盘唯一教不了的是情绪，而情绪不需要大钱就能学到。

## 2. 铁律：先写预测卡，再下单

**模拟盘失败只有一种方式：变成免费点鼠标。** 防它只有一条规则。

```
下单前必填，写不出来就不下单：

标的 / 方向 / 数量 / 行权价 / 到期日 / 权利金
触发条款：            ← BUY / S1 / S2（见 single_name_discipline.md）
属于哪个实验：        ← E1-E5，或"计划外"
我预期会发生什么：    ← 必须是可证伪的具体陈述，不是"我觉得会涨"
什么情况算我错了：    ← 事前写死
持有到：              ← 事前定，不许中途改
```

**"我预期会发生什么"这一栏是全部意义所在。** 没有它，模拟盘只是在收集随机数。

## 3. 五个设计好的实验（核心）

> 这些不是"练手"，是**为了搞懂某个特定机制而专门设计的、允许亏钱的**测试。
> 每个都有明确的学习目标和结论模板。

### E1 · 卖 put vs 挂限价单：那笔权利金到底值多少

**目标**：验证 `discipline.md` §5.3 的论断——两者决策相同，只差权利金。

- 选一只你**真的想在 $X 买**的股票
- **A 腿**：卖 1 张行权价 $X 的现金担保 put，锁定现金
- **B 腿**：同时挂一个 $X 的 GTC 限价买单，等额现金
- 持有到 put 到期，对比两条腿

**要回答**：没成交时 A 多赚多少？成交时 A 的成本低多少？**有没有 A 输给 B 的情形？**
（有——股票暴跌时 B 可以取消，A 必须接。这就是权利金的对价。）

### E2 · 时间怎么吃掉一张 call

**目标**：一次性搞懂 theta（时间价值衰减）。

- 买 1 张平值（行权价≈现价）call，3 个月到期
- **什么都不做**，每周记录一次价值
- 持有到到期

**要回答**：股票原地不动时，第 1 个月掉多少价值？最后 2 周掉多少？
**（答案会吓到你——这是买 call 亏钱最常见的方式，和方向无关。）**

### E3 · covered call 的机会成本

**目标**：亲眼看见"卖掉右尾"。

- 持有 100 股你**真心看好**的股票
- 卖一张行权价高于现价 15% 的 call
- 记录：被 call 走后，它后来又涨到多少

**要回答**：那笔权利金，和你少赚的钱，比例是多少？
**（这个实验的目的就是让你以后再也不想做 covered call。）**

### E4 · 财报前后的 IV crush

**目标**：搞懂为什么"方向猜对了还是亏钱"。

- 财报**前**买一张 call
- 记录财报前的隐含波动率（IV）
- 财报后**即使股价按你想的方向动了**，看权利金变成多少

**要回答**：IV 从多少掉到多少？**方向对了为什么还亏？**
**（这是新手最集中的亏损来源。做一次，省一辈子。）**

### E5 · 被行权全流程演练

**目标**：知道"被抓住"的时候具体发生什么。

- **故意**卖一张大概率会被行权的 put（行权价高于现价）
- 走完整个流程：到期 → 分配（assignment）→ 股票进账户 → 现金扣除

**要回答**：什么时候通知你？现金怎么扣？成本基础记成多少？
**（真金账户里第一次被行权时手忙脚乱，代价就不是虚拟的了。）**

## 4. 评分：看判断，不看盈亏

12 个月，目标 **20 个决策**（含 E1-E5 与计划内的常规操作）。

年底统计这三个，**不统计收益率**：

| 指标 | 怎么算 |
|---|---|
| **预测命中率** | "我预期会发生什么"那栏，被验证的比例 |
| **条款遵守率** | 有多少笔是条款触发的，多少笔是"想做" |
| **归因四象限分布** | thesis 对/错 × 赚/亏（见 `../execution_plans/position_book.md` §6）|

> **右上角「thesis 错但赚钱」的比例，是最重要的一个数。**
> 它高 = 你的收益主要来自运气，流程还没成型。
> **只看收益率，永远看不见这一格。**

收益率照样记，但记在**旁边**，不作为通过标准。**20 个决策的样本能说明问题，1 个年度收益率数字不能。**

## 5. 模拟盘教不了什么

| 教得了 | 教不了 |
|---|---|
| 期权定价机制 | **真钱波动时的情绪** |
| 时间衰减、IV crush | 深度浮亏时想割肉的冲动 |
| 行权、分配流程 | 真实滑点与流动性 |
| 下单、平仓的操作 | 大单冲击成本 |

**所以两个账户并行，不是二选一。** 模拟盘练机制，$3,000 真金练情绪。
**情绪那门课你其实已经在上了**——BTC 现在 -44.92%，那个感受就是教材。

## 6. 结业标准（满足才把期权用到真金上）

- [ ] E1–E5 五个实验全部跑完并写了结论

- [ ] 预测命中率 ≥ 50%，且**能说清失败的那些错在哪**
- [ ] 条款遵守率 ≥ 90%
- [ ] 至少经历过 1 次真实被行权
- [ ] 能不查资料解释：为什么卖方时间站在你这边、IV crush 怎么发生、被行权时账户里发生了什么
