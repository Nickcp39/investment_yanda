# 交易日志 · 模板

> 命名：`journal/YYYY-MM-DD_<ticker>_<buy|sell|put|call>.md`
> **规则：当天写完。隔天补写的记忆已被结果污染，等于伪造证据。**

---

## 事前（下单前填完，写不出来就不下单）

```
日期时间：
账户：        模拟盘 / 真金
标的：
方向：        BUY / SELL / SELL-PUT
数量：
价格：        计划___  当时市价___
（期权）行权价___  到期日___  权利金___  占用现金___

触发条款：    ← BUY / S1 / S2 / S3。写不出来 = 停手
条款细节：    ← 例："$178 ≤ buy-below 带 $150-180，verdict STARTER"
对应卡：      ← companies/<ticker>/<date>/decision_card.md
属于哪个实验：← E1-E5 或"计划外"

【我预期会发生什么】← 必须可证伪的具体陈述
  不合格："我觉得会涨"
  合格：  "Q2 6-K 会披露 active MW ≥250MW，届时 EV/RPO 回到 2.0×以上"

【什么情况算我错了】← 事前写死
  

【计划持有到】← 事前定，中途不许改
  

Tier 检查：   当前 T__，本笔是否在限额内？ ⬜是
风控检查：    本月已回撤___，距 $450 线还有___
```

## 违约版（没有条款却动了手，用这个）

```
日期：           标的：           想做什么：
当时浮盈亏：$___  ← 只记录，不作为理由
我给自己的理由：
能对应哪条条款：  ← 大概率是"无"
72 小时冷静起算：
72 小时后是否执行：  是 / 否
如果没执行，现在回头看当初的冲动对不对：
```

> **违约记录不是道德审判，是数据。**
> 攒够十几条你就能看出自己的冲动有什么模式——
> 是特定标的？特定跌幅？特定时间？**看出模式才能设针对性的刹车。**
