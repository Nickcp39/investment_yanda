# 百万粉财经博主发家史：早期选题与打法

**日期** 2026-09-28 · 接 `report.md`（画像 / 内容 / 失败模式）
**范围** 只研究**粉丝确认过百万**的号。老唐（峰值 60 万）不在正文里。猫笔刀的粉丝数查不到，放在附录。
**数据等级** B/C 级：新榜专访、界面、澎湃、36 氪、百度百科等的转述。B 站、抖音都打不开，**"第几条视频"这类细节来自媒体报道，没法逐条核对**。

---

## 0. 结论先行

1. **第一个爆款几乎都在前三条。** 巫师第 1 条 213 万，温义飞第 1 条 80 万，半佛第 3 条拿了 B 站全站日榜第一，老蒋从第 3 条开始起量。**账号开头那几条，就已经决定了它的命运。**
2. **起步有两条路，速度差一个数量级。**
   - **带粉入场**：先在文字平台攒下种子用户，再转视频。半佛是知乎 → 公众号一年 60 万 → 转 B 站，**一个月 100 万**。
   - **从零摸索**：小Lin 花了半年试方向；小A学财经用**一年到 1 万粉、再一年到 10 万**，然后**两个月从 10 万冲到 100 万**。
   - **你属于第二条路。** 预期要按小A来定，不能按半佛。
3. **第一次的方向基本都猜错了，赢家是改得快的人。** 小Lin 先讲求职、咖啡，没人看；老蒋头两条蹭热点，被叫"蹭凉点的 UP 主"；温义飞原本想做一分钟的短视频，压不进去，改成 10 分钟。
4. **早期的爆款选题只有五种：** 揭秘、事件、平台自指、利益钩子、金融奇闻。**没有一种是"系统讲一门知识"。** 系统化的内容（林超的跨学科课、小Lin 的"一口气"系列）都是有了粉丝**以后**才做的。
5. **2019–2020 年是一个窗口，现在已经关上了。** 当时 B 站的财经区几乎没人做，疫情让人宅在家，西瓜和 B 站在抢创作者。**这批人的速度复制不了，方法可以复制。**
6. **大蓝和头部的起号速度一样快（三个月 400 万），差别在打法。** 他自己总结的流量密码是"反差、博眼球、反向认知"，什么都评，然后卖课、办 10 万元的私董会。**决定结局的不是速度，是打法。**

## 二、逐人发家史

### 2.1 半佛仙人：带粉入场的教科书

| 阶段 | 发生了什么 |
|---|---|
| **积累期** | 在风控行业做了好几年，"见过很多风险，也见过它们的后果"。**这是他日后内容的原材料。** |
| **知乎** | 先在知乎攒了一批种子用户 |
| **公众号**（2018 年末 → 2019 年末）| 把知乎的用户带过去。一篇文章常常 5,000 字以上，写互联网内幕、股票、网贷、非法集资、各种灰产。**一年从 0 到 60 万**，行业里叫"现象级"。代表作《再坚持一下，你的奶茶店就要倒闭了》：15,274 个"在看"，全网阅读几百万，"奶茶传销"上了微博热搜 |
| **B 站**（2019-12 底）| 第 3 条就是**把公众号上的爆款改成视频**：《你知道奶茶加盟有多坑人吗？》，全站日榜第一 |
| **爆发** | 一个月 100 万，半年 200 万，十个月 500 万 |
| **细节** | 第一期被吐槽收音差，马上换了专业设备 |

**打法：**
- **人设是"韭菜局终结者"**：揭露普通人被坑之前根本不知道的套路。**这正好是在做行业内部人的反面**，内部人靠信息差赚钱，他把信息差免费说出来
- **B 站第一个爆款是公众号上已经验证过的选题。** 他不是在 B 站试选题，是把已经证明过的东西搬过去
- **原材料来自上一份工作**，不是临时学来的

### 2.2 巫师财经：第一条就是平台自指

| 阶段 | 发生了什么 |
|---|---|
| **积累期** | 在投行做了几年金融分析师。**做视频也照搬投行尽调那一套** |
| **第 1 条**（2019-09-17）| 《**B 站资本市场成绩单**》，213 万。**在 B 站讲 B 站自己的股票** |
| **第 2 条** | 《金融各细分行业概览 + 鄙视链 + 职业发展》：给想进金融圈的年轻人看的 |
| **第 5 条** | 《逆风翻盘！保时捷 & 大众的恶意并购【资本战争 02 集，本期硬核预警】》|
| **第 8 条** | 《香港金融保卫战》（索罗斯）：**爆红的那一集** |
| **系列** | "明星与资本"让他彻底出圈；"资本战争"成了招牌 |
| **结果** | 14 条视频、千万播放、300 万粉；B 站 2019 新人奖 |

**打法：**
- **第一条选题是平台自指**：B 站用户最关心的公司就是 B 站自己
- **人设很强**："名校毕业""投行精英""霸道总裁"，还有"资本永不眠""以我为准"这种中二口号。媒体评价是"有别于传统知识型大 V 的聚粉方式"
- **第 2 条就开始给粉丝画像**（想进金融圈的年轻人），第 5 条开始做系列
- **赶上了空白期**："B 站财经科普区一直是无人问津之地，直到巫师财经进驻"
- 后来的问题（抄袭、退站）见 `report.md` F4 / F5

### 2.3 温义飞：事件 + 疫情 + 平台补贴

| 阶段 | 发生了什么 |
|---|---|
| **积累期** | 阿尔伯塔经济学本科、LSE 经济史硕士；2018 年回国创业 |
| **起因** | 2020 年初疫情，宅在家里开始做视频 |
| **第 1 条**（2020-04-10，西瓜）| **美股暴跌**（刚好是 3 月熔断之后），80 万+ |
| **形式调整** | 原本想做一分钟以内的短视频，发现财经内容压不下去，改成 **10 分钟左右** |
| **爆发** | 21 条视频涨了近 200 万粉，单条最高 1,000 万；不到一年 1,100 万+ |
| **二次爆发** | 2021-06 解读教育政策，一条涨粉 120 万+ |

**打法：**
- **第一条就挂在当时最大的金融事件上**
- **在短视频平台做 10 分钟的中视频**，逆着平台的习惯来，反而站住了
- **赶上了西瓜"中视频"的扶持期**（字节当时在跟 B 站抢长一点的视频）

### 2.4 所长林超：国运 + 利益钩子

| 阶段 | 发生了什么 |
|---|---|
| **积累期** | 中山大学国际金融 + 应用数学双学位；毕业第二年创办 AI 公司，有发明专利；后来做私募合伙人 |
| **B 站**（2020 年初）| 一个半月、8 条稿件，33 万粉 |
| **第一个大爆款**（2020-03）| 《年轻人如何抓住 5G 时代红利，中国未来发展机会分析》，249.5 万 |
| **二次爆发** | 2021 年十四五规划解读，全网 1.7 亿 |
| **后来** | 跨学科课程、两本书；2020 B 站新人奖 |

**打法：**
- **标题里同时放了三样东西**：身份（年轻人）+ 利益（红利）+ 国运（中国未来）
- **系统化的课是在有了粉丝之后才做的**，起号靠的是单点爆款

### 2.5 老蒋巨靠谱：零经验，改得快

| 阶段 | 发生了什么 |
|---|---|
| **积累期** | 媒体人、评论员，给虎嗅、创业邦写稿。**没有任何视频经验** |
| **第 1、2 条**（2019-07）| 蹭孙杨事件。**结果 B 站用户叫他"蹭凉点的 UP 主"**：热点已经过了 |
| **第 3–5 条** | **转向，连做三期《哪吒》**：拉十年时间线讲中国电影市场，流量明显变好 |
| **形式** | 20 分钟，面对面纯聊，很少配画面，封面粗糙；每期都露脸，封面放头像 |
| **结果** | 一年 60 万；后来破百万、进百大；"解构 B 站"系列破百万 |
| **2024 年新榜演讲** | "太精致的内容不会火"是**误判**：粗糙和精品可以并行。他当时在做精品微综艺《以假乱真》，第 1 期 268 万 |

**打法：**
- **两次失败就换方向**：从"抢热点的时效"换成"热点 + 长时间线的深度"
- **粗糙起步，后来再精品化**：顺序是先靠内容起量，再往上加制作
- 后期选题"已经不太考虑大众吸引力，更多看自己的兴趣和选题本身的价值"，**这是有了粉丝以后才有的奢侈**

### 2.6 小Lin说：业余起步，半年摸索

| 阶段 | 发生了什么 |
|---|---|
| **积累期** | 北大 → 哥大 → JP Morgan |
| **起步** | **在投行上班时业余做**，最开始是帮留学生找工作：简历、面试、谈薪 |
| **摸索** | 试过求职、金融、咖啡；发现金融流量最高；先做偏严肃的，反馈一般 |
| **转折** | 开始讲**行业里的奇闻故事**，突然爆了 |
| **后来** | 辞职全职做；团队化；"一口气了解"系列；两届百大 |

**打法：**
- **和你的处境最像**：有正职、业余做、一开始没有粉丝
- **摸索了半年**，这段时间是正常的
- **转折点是从"讲知识"改成"讲故事"**

### 2.7 小A学财经：慢，然后突然

| 阶段 | 发生了什么 |
|---|---|
| 2019-04-01 | 抖音注册 |
| 第 1 年 | **到 1 万** |
| 第 2 年 | **到 10 万** |
| 之后 | **两个月从 10 万到 100 万** |
| 风格 | 邻家女生形象；有趣大于专业；广告用剧情植入 |

**打法：**
- **这是"复利曲线"最干净的一个样本。** 前两年看上去几乎没有进展，然后两个月涨了十倍
- 大部分人会在第一年、1 万粉的时候放弃

### 2.8 段永平：从来没"做"过

| 阶段 | 发生了什么 |
|---|---|
| ~2010 | 在网易博客回答网友问题 |
| 2018 | 网易博客改成 Lofter，他不喜欢，发了一条"博友们可以在雪球上开个号"，就搬过去了 |
| 后来 | 雪球 126 万，平台第一；网友把他的问答整理成《投资问答录》 |

**打法：**
- **没有打法。** 他的声誉是在做内容之前就有的（企业家），内容只是这份声誉的延伸
- **对你的意义：** 声誉可以先于粉丝存在。你库里的东西，是在没人看的时候就已经在攒了

### 2.9 大蓝（反面）：速度一样，打法不同

| 阶段 | 发生了什么 |
|---|---|
| 之前 | 浙江衢州人，健身教练；2015 年前后做微商卖健身餐。**没有任何金融背景** |
| 2020-06 | 开始拍口播，很快出爆款，**三个月 400 万** |
| 流量密码（他自己说的）| "**反差、博眼球、反向认知**" |
| 选题 | 什么都评：情感、秀恩爱、致富经、时政 |
| 变现 | 卖课；"私董会"要将近 10 万元；**被人民网点名"割韭菜"** |
| 2024-06 | 被禁止关注（当时约 950 万粉）|
| 2024-10 | 连发几十条股市视频，9 天涨粉近百万 → 荐股 → **永久封禁** |

**对照：**
- 起号速度和巫师、温义飞同一级，**速度证明不了什么**
- 他没有"原材料"（行业经验），只能靠"反差、博眼球"。**没有原材料的人最后只能卖情绪，卖情绪卖到头就是荐股**
- 被封前 9 天涨粉近百万，**离悬崖最近的时候，涨得最快**

## 三、早期选题分析

### 3.1 第一个爆款归类

| 类型 | 谁 | 选题 | 为什么有效 |
|---|---|---|---|
| **揭秘** | 半佛 | 奶茶加盟有多坑 | 人人喝过奶茶，很多人想过加盟；**信息差** |
| **事件** | 温义飞 | 美股暴跌 | 当时所有人都在问"发生了什么" |
| **平台自指** | 巫师 | B 站资本市场成绩单 | **B 站用户最关心 B 站自己** |
| **利益钩子** | 林超 | 年轻人如何抓住 5G 红利 | 身份 + 利益 + 国运 |
| **金融奇闻** | 小Lin | 行业里的奇闻故事 | 故事比知识好传播 |
| **热点 + 长时间线** | 老蒋 | 《哪吒》× 十年电影市场 | 热点是入口，时间线是深度 |
| **反差 / 反向认知** | 大蓝 | 什么都评 | 有效，但没有底 |

**没有一个人的第一个爆款是"系统讲一门知识"。**
系统化的东西（林超的课、小Lin 的"一口气"系列、巫师的"资本战争"）全都是**有了粉丝以后**才做的。**起号靠单点爆款，留人靠系统内容。**

### 3.2 早期失败的尝试

| 谁 | 一开始猜的方向 | 结果 | 改成了什么 |
|---|---|---|---|
| 小Lin | 求职、咖啡、严肃金融 | 反馈一般 | 金融奇闻 |
| 老蒋 | 抢热点（孙杨）| "蹭凉点" | 热点 + 长时间线 |
| 温义飞 | 一分钟短视频 | 内容压不进去 | 10 分钟 |

**规律：** 第一次猜错是常态。**要看的不是第一条火没火，是前 10 条里有没有哪一条明显比其他的好，然后往那边改。**

|---|---|---|
| 半佛 | 灰产、骗局、风控 | 上一份工作 |

## 四、时代窗口

| 2019–2020 | 2026 |
|---|---|
| B 站财经区几乎没人做（"无人问津之地"）| 已经有 744 万粉的小Lin，头部都站稳了 |
| 疫情宅家，所有人都在刷视频 | 没有这个外力 |
| 西瓜、B 站抢创作者（西瓜给巫师开千万合约）| 平台之间的战争结束了 |
| 监管相对宽松 | 2024 年大蓝被封，2026-01 雪球一次封 22 个号，财经号要主体认证 |
| 巫师 2022 年回归：**"知识区早就变了"** | — |

**结论：**
- 这批人"一个月 100 万""14 条 300 万"的速度，**是窗口给的，不能当成基准**
- **能复制的是方法**：原材料、前三条放最强的、改得快、先单点后系统
- **现在更合理的参照是小A学财经的曲线**：一年 1 万，两年 10 万，然后看运气
- **窗口关了也有好处**：监管收紧把"反差、博眼球、荐股"这条路堵死了，走正路的人竞争反而少了
