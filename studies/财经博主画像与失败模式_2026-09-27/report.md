# 财经博主：头部画像与失败模式

**日期** 2026-09-27 · **性质** 调研（非个股）· **目的** 用户计划做 B 站财经视频（业余、不变现、不荐股、攒 reputation），先**模仿头部、研究失败**。
**数据等级** 全部 B/C 级（WebSearch 转述，平台与数据站均无法直接访问）。粉丝数注明日期；标 ⓒ 为记忆、未核实。

---

## 0. 结论先行

**头部博主的共性只有一条真正重要：他们讲的是"故事/逻辑"，不是"票"。** 小Lin说讲金融奇闻，半佛讲商业段子，巫师讲资本史，温义飞讲经济学——粉丝百万到千万的账号里，**没有一个靠讲个股起家**。讲个股的账号（大蓝、雪球那 22 个）粉丝也大，但结局是封号。

**失败模式七种，其中三种（荐股封号 / 实盘反噬 / 变现反噬）对"不荐股、不实盘、不收费"的人结构性免疫。** 剩下真正要防的是：**预测型人设**、**内容诚信**、**言论越界**。

### 1.2 从头部提炼的七条

| # | 共性 | 证据 |
|:--:|---|---|
| 1 | **全部先在文字平台成名，再转视频** | 半佛（公众号）、巫师（知乎）、老蒋（媒体）、小Lin（知乎回答）|
| 2 | **讲故事/逻辑，不讲票** | 百万级以上无一例外 |
| 3 | **长内容在 B 站成立** | 小Lin 30–40 分钟"不愿快进"；巫师、半佛均为长视频 |
| 4 | **有一个可信度钩子** | 北大华尔街 / LSE / 银行风控 / 投行——**观众要一个"凭什么听你的"** |
| 5 | **选题 = 热点 × 底层逻辑**，不是热点本身 | 小Lin"先找逻辑再说人话"；胖东来、美团京东都是热点切口 |
| 6 | **制作质量是入场券**，不是加分项 | 半佛第一期就换设备；老蒋封面三代进化；小Lin 剪辑团队 |
| 7 | **不需要粉丝的人最安全** | 段永平零风险事件；老唐靠这个吃饭就有了 2023 |

## 二、失败模式（七种，每种至少一个有名有姓的样本）

| # | 模式 | 样本 | 发生了什么 | 结构原因 |
|:--:|---|---|---|---|
| **F1** | **荐股 / 实盘 → 监管封号** | **大蓝**（抖音千万粉）| 2024-10 "开盘直接进某股票""绝不可能诱导你们出货" → **无限期封禁**，同批 17 号 | 千万粉 × 具体标的 = 事实上的市场操纵 |
| | | **雪球 22 个大 V**（杭州新城路、轮回666、福禄娃爷爷等）| 2026-01-20 一日三份公告永久封禁；"游资战法""带队复盘"| 2026 证监会工作会议 + 网信办专项 |
| | | **金永荣**（雪球 10 万粉）| 荐股后反向交易（spoofing）→ **罚没 8,300 万 + 3 年禁入** | 粉丝 = 流动性提供者 |
| **F2** | **实盘 / 产品业绩崩 → 粉丝反噬** | **云蒙**（雪球 40 万粉）| 2014 三倍杠杆银行股十倍；2019 高位建仓港股银行 → 净值 **0.12–0.19**；公开道歉；与百亿私募互斥 | 极致持仓 + 能力圈固化 + 杠杆 |
| | | **但斌** | 2022-03 清仓至 10% 仓位 → 4 月反弹踏空 → 追高美股被套；30+ 产品亏 >40%；**微博禁言半年 + 雪球禁言** | 公开仓位后，每一次操作都被审判 |
| | | **老唐** | 见 1.1。布道十年，一轮熊市清零 | **粉丝跟单是不可避免的**，即使从不说"买" |
| | | 梁宏（希瓦）| 2022 大回撤，舆论围攻 | 同上 |
| **F3** | **预测型人设 → 一次大错即崩** | **任泽平** | "5000 点不是梦""一线房价翻倍""新 5% 比旧 8% 好"；2022-01 "印 2 万亿生娃" → **微博 + 公众号禁言两周**，"网友拍手叫好"| 靠预测成名的人，声誉 = 最近一次预测 |
| | | 李大霄 ⓒ | "婴儿底""地球顶"系列 | 同上，未核实 |
| **F4** | **内容诚信** | **巫师财经** | 2020 被指抄袭知乎回答，道歉 | 高产 + 无引用习惯 |
| **F5** | **平台博弈失当** | **巫师财经** | 2020 为西瓜千万合约退 B 站，B 站起诉；2022 合约到期回归，"爷青回"但数据"无法复刻" | 把观众当资产搬家，观众不跟 |
| **F6** | **变现反噬** | **老唐** 900 万星球 | 二手席位炒到 3,499；"圈钱"标签 | 免费布道十年积累的信任被一次性变现 |
| | | 券商首席卖课潮 | 2026-01 中国新闻周刊封面《10 万粉丝，被他"割韭菜"》| 知识付费 = 隐性投顾 |
| | | 收 15 万进群费带炒股 | **罚 1,500 万**（2026-03）| 有偿 + 建议 = 无牌投顾 |
| **F7** | **言论越界（非财经）** | **任泽平** | 2024-12 引汉武帝《轮台诏》→ 再次禁言 | 财经号的边界不只在证券法 |

### 2.1 失败的时间结构

**没有一个是慢慢衰落的。全部是"高点 → 单一事件 → 断崖"。** 大蓝一条视频、但斌一次清仓、任泽平一条微博、巫师一篇道歉。
**⇒ 对内容创作者，风险不是"内容不够好"，是"某一天说了一句不该说的"。** 防守比进攻重要得多。

### 2.2 谁没出事，为什么

| 人 | 为什么安全 |
|---|---|
| 段永平 | 不需要粉丝、不需要变现、不给具体建议、极少更新 |
| 小Lin说 | 从不讲个股、有团队审稿、不做实盘 |
| 温义飞 | 讲经济学不讲证券 |

**共同点：他们的内容里没有任何一句话能被翻译成"买 X"。**

## 三、映射到用户的计划

### 3.1 用户的设定
B 站长视频 · 业余 · 不变现 · 不荐股 · 不公开实盘 · 素材 = 已有研究库（30+ 份）

### 3.2 哪些失败模式结构性免疫

| 模式 | 免疫？ | 条件 |
|---|:--:|---|
| F1 荐股封号 | ✅ | **视频里没有价格、没有 verdict、没有仓位**。库内 `buy_below` / `observe line` / STARTER/CORE 全部不出现 |
| F2 实盘反噬 | ✅ | 不公开持仓、不谈自己买了什么 |
| F6 变现反噬 | ✅ | 不收费 |
| F5 平台博弈 | ✅ | 一个平台 |

### 3.3 哪些是真风险

| 模式 | 风险点 | 对策 |
|---|---|---|
| **F3 预测型人设** | 库里有**预注册预测**（SNOW 七条）、有腿五的概率表——这些**是预测** | 区别在**公开对账**：任泽平从不回头核对。预测 + 到期核对 + 错了写 CORRECTION，是 F3 的反面。**但必须真的对账**——SNOW 那份逾期未对账，公开了就是任泽平 |
| **F4 内容诚信** | 视频比文字更容易"顺口说"| 库已有 source_register 习惯，视频每期附来源页 |
| **F7 言论越界** | 电力/AI/中美/产业政策题材天然靠近边界 | 只讲数据和机制，不评价政策好坏 |

### 3.4 从头部学什么、不学什么

| 学 | 不学 |
|---|---|
| 小Lin：**先找逻辑再说人话**；长视频节奏；封面 | 追热点周更（业余做不到，也不必）|
| 半佛：**第一期就把设备弄好** | 表情包风格（与研究型内容冲突）|
| 段永平：**问答式、短、不需要粉丝的姿态** | — |
| 老唐：**财报方法教学**是他真正留下的东西 | 公开实盘、年度估值表（= 隐性买点）|
| 巫师：资本史叙事的电影感 | — |

### 3.5 用户独有、头部没有的

**公开纠错。** 库内 AZN CORRECTION、INC-001（价格是 52 周低点）、腿三 2,600 GW 更正、SNOW 预注册——**中文财经视频里没有人系统展示"我怎么发现自己错了"**。
这既是差异化，又是 F3 的解药：预测型人设崩于"不认错"，公开纠错型人设**靠认错攒 reputation**。
