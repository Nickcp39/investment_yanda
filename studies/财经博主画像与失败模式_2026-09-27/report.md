# 财经博主：头部画像、内容拆解、选题分析、失败模式

**日期** 2026-09-27（v2，同日 v1 的"画像 + 失败模式"已并入本文）
**目的** 用户计划做 B 站财经长视频：业余、不变现、不荐股、攒 reputation。先**模仿头部**，再**研究失败**。
**数据等级** 全部 B/C 级：WebSearch 转述，B 站 / 抖音 / 雪球 / 飞瓜 / 新榜都无法直接访问。粉丝数都标了日期，**很多是 2020–2022 年的旧数**；标 ⓒ 的是记忆，没核实过。

---

## 0. 结论先行

1. **百万粉以上的财经号，没有一个靠讲个股起家。** 全部在讲**故事、逻辑、框架**。讲个股的号也能做大（大蓝千万粉），但结局是封号。
2. **每一个爆发都挂在一个事件上。** 半佛靠瑞幸被做空，温义飞靠 2021 教育政策（一条涨粉 120 万），小Lin 靠稳定币（24 小时 500 万播放），老蒋靠孙杨。**事件是入口，逻辑是留存。**
3. **选题的底层公式是"人人都碰过的东西 × 一个没人讲清楚的机制"**：奶茶加盟、胖东来、美团京东、瑞幸。不是"宏观经济"，是"你昨天喝的那杯咖啡背后的资本"。
4. **制作有两条路，业余者只能走一条。** 小Lin 那条是团队 + 动画，"剪辑 B 站第一"；老蒋那条是 20 分钟露脸纯聊、画面很少、封面粗糙，**一年照样做到 60 万**。业余做法只能是老蒋 / 段永平 / 猫笔刀这一端。
5. **B 站的规则对长内容友好**：外显从播放次数改成了**播放分钟数**（2023）；推荐不看完播率；权重**分享 > 弹幕 > 投币 > 评论 > 点赞 > 收藏 > 播放**。这正好适合你"研究完了才讲、讲得长、讲得硬"的东西。
6. **失败不是慢慢衰落，是"高点 → 一句话 → 断崖"。** 七种失败模式里，有四种你靠"不荐股、不实盘、不收费、只做一个平台"就结构性免疫；剩下要防的三种是**预测型人设**、**内容诚信**、**言论越界**。

### 1.2 背景钩子这件事

**12 个人里有 9 个把一个可信度标签放在最前面：** 北大华尔街、LSE、银行风控、私募合伙人、步步高创始人。
观众点开之前先问的是"**凭什么听你的**"。

**你的钩子不在学历上，在库里：** 30 多份研究、公开的更正记录、预注册预测。这不能用一个标签说完，只能**每一期都展示一遍**。这是劣势（起步慢），也是优势（没法造假）。

### 2.8 唐朝（老唐）· "方法 + 实盘"

| | |
|---|---|
| **核心产品** | **老唐估值法**：三年后合理估值 = 第三年净利润 × (1 ÷ 无风险收益率)，高杠杆打七折；**合理估值的 50% 是买点**；"买点买入，卖点卖出，中间呆坐" |

| **选题** | 读财报教学 + 具体公司（茅台、腾讯、海康等）+ 公开实盘 |
| **他真正留下来的** | **读财报的方法**。《手把手教你读财报》到现在还在被引用 |
| **把他害了的** | **买点 = 合理估值 × 50%**。这是一个能直接算出价格的公式，粉丝拿来算完就会跟单 |
| **对照你的库** | 你的 `buy_below` 是同一类东西。**所以永远不能出现在视频里** |

### 2.9 猫笔刀 · "持续十三年"

| | |
|---|---|
| **形式** | 公众号，**每晚 22:30 一篇，13 年几乎没断过**，节假日也发 |
| **风格** | 大白话讲复杂的市场逻辑；**不荐股，不卖课**；不装专家；打比方很准（比如"GPT 和小米 AI 是高中生和五六岁小孩"）|

| **说明的问题** | 就算不荐股，**评论市场本身也会被禁言**。F7 这条线比想象的宽 |

## 三、选题分析

### 3.1 把所有代表作按选题类型分类

| 类型 | 代表作 | 流量 | 风险 |
|---|---|:--:|:--:|
| **A · 消费品背后的商业** | 奶茶加盟（800 万）、瑞幸（半佛最高）、胖东来、美团京东 | ⭐⭐⭐ | 🟢 |
| **B · 大事件复盘** | 瑞幸被做空、香港金融保卫战、硅谷银行 ⓒ | ⭐⭐⭐ | 🟢 |
| **C · "一口气了解"新概念** | 稳定币（24 小时 500 万）、ChatGPT | ⭐⭐⭐ | 🟢 |
| **D · 政策 / 国运解读** | 教育政策（+120 万粉）、十四五（1.7 亿）、5G 红利（249 万）| ⭐⭐⭐ | 🟡 F7 |
| **E · 资本史 / 人物** | 明星与资本、网红与资本简史（4 小时破百万）| ⭐⭐ | 🟢 |
| **F · 方法 / 框架** | 老唐估值法、段永平不为清单、林超跨学科 | ⭐⭐ 慢，但长期稳 | 🟢，**碰到具体价格就变 🔴** |
| **G · 平台 / 行业评论** | 老蒋《年轻用户是诅咒》 | ⭐⭐ | 🟡 容易吵起来 |
| **H · 个股 / 买点** | 大蓝、老唐估值表、雪球那 22 个号 | ⭐⭐⭐ | 🔴 |
| **I · 自曝失误** | 巫师《……以及我是怎么亏的》（107 万）| ⭐⭐ | 🟢 |

**读法：**
- 流量最高的是 **A / B / C / D**。四类里三类是绿的，**风险和流量并不挂钩**。H 的流量是高，可 A / B / C 也一样高。
- **F（方法）起量最慢，但只有它能长期积累。** 老唐、段永平最后留下来的都是方法，不是他们看对过哪只票。
- **I（自曝失误）刚刚开始出现。** 你的库在这一类的储备，比任何头部都多。

### 3.2 标题公式

| 公式 | 例子 | 谁在用 |
|---|---|---|
| **一口气了解 / 搞清楚 + X** | 一口气了解稳定币 | 小Lin |
| **X 是如何 Y 的？**（反讽问句）| 瑞幸咖啡是如何报答资本主义的？ | 半佛 |
| **你知道 X 有多 Y 吗？** | 你知道奶茶加盟有多坑人吗？ | 半佛 |
| **X，为什么 Y？** | 胖东来，为什么走不出河南？ | 小Lin |
| **X 简史 / 资本战争 / X 与资本** | 网红与资本简史 | 巫师 |
| **年轻人如何抓住 X 红利** | 5G 时代红利 | 林超 |
| **……以及我是怎么亏的** | 万字吃透科技国运 | 巫师 |

B 站**偏好**的词：干货、保姆级、实测、**一口气**、**手把手**。
**会被降权**的词："不看后悔""震惊"。

**你的研究最自然能套上的两个公式是"X，为什么 Y？"和"X 简史"。** 比如："电力需求涨了 15 倍，电力公司为什么跑输大盘 100 年？"、"铁路、光纤、AI：三次需求泡沫简史"。

### 3.3 时机

| 爆款 | 挂在哪个事件上 |
|---|---|
| 半佛《瑞幸》| 2020-02 浑水做空 |
| 温义飞教育政策 | 2021-06 政策发布当天 |
| 小Lin 稳定币 | 2025-07 稳定币立法热 |
| 老蒋第一条 | 2019 孙杨事件第一轮发酵 |
| 林超 5G | 2020 5G 商用 |

**每一次爆发都有事件。** 但你是业余的，没法当天出片。**解法是提前准备"常青底稿"，等事件来了挂上去。** 比如百年电力那份研究，任何一次"AI 缺电"的新闻出来都能挂。**研究是库存，事件是发货的时机。**

## 四、B 站平台机制（对你有利的部分）

| 机制 | 对你的含义 |
|---|---|
| 外显从播放次数改成**播放分钟数**（2023）| 长视频的数字更好看。20 分钟看完一次，等于 20 个一分钟 |
| 推荐**不看完播率** | 不用把 20 分钟硬压成 5 分钟 |
| 权重：**分享 > 弹幕 > 投币 > 评论 > 点赞 > 收藏 > 播放** | **能被转发的内容**最值钱，比如一张图、一个数、一个恒等式 |
| 偏好关键词：干货、一口气、手把手 | 标题可以用 |
| 发布时间：知识类工作日 20:00–21:00 | 和你下班后的时间刚好对上 |

## 六、失败模式（七种）

| # | 模式 | 样本 | 结构原因 |
|:--:|---|---|---|
| **F1** | 荐股 → 封号 | **大蓝**（2024-10 无限期封，同批 17 个号）；**雪球 22 个大 V**（2026-01-20 一天三份公告永久封：杭州新城路、轮回666、福禄娃爷爷等）；**金永荣**（10 万粉，荐股后反向交易，**罚没 8,300 万 + 3 年禁入**）| 千万粉 × 具体标的 = 事实上的市场操纵 |
| **F2** | 实盘崩 → 粉丝反噬 | **云蒙**（3 倍杠杆银行股，净值跌到 0.12–0.19，公开道歉）；**但斌**（2022 清仓后踏空，30 多个产品亏超 40%，微博禁言半年）；**老唐**（熊市后停更）；梁宏 | **只要公开仓位，每一次操作都会被审判；就算从来不说"买"，粉丝也会跟单** |
| **F3** | 预测型人设 | **任泽平**（"5000 点不是梦""一线房价翻倍" → 2022 年"印 2 万亿生娃"被禁言，网友拍手叫好）| 靠预测出名的人，声誉 = 最近那一次预测 |
| **F4** | 内容诚信 | **巫师**（2020 抄知乎，道歉）| 产量高 + 没有引用习惯 |
| **F5** | 平台博弈 | **巫师**（为西瓜的千万合约退 B 站，被起诉；回来后"无法复刻"）| 把观众当成可以搬家的资产，观众不跟 |
| **F6** | 变现反噬 | **老唐** 900 万星球（二手席位被炒到 3,499）；券商首席扎堆卖课（《中国新闻周刊》2026-01 封面《10 万粉丝，被他"割韭菜"》）；收 15 万进群费带人炒股（**罚 1,500 万**）| 十年免费攒下的信任被一次性变现；有偿 + 给建议 = 无牌投顾 |
| **F7** | 言论越界 | **任泽平**（2024-12 引《轮台诏》，再次禁言）；**猫笔刀**（不荐股也被禁言 14 天）| 财经号的边界不只在证券法 |

**时间结构：** 没有一个是慢慢衰落的，全部是"高点 → 一件事 → 断崖"。**对创作者，防守比进攻重要。**

**没出事的人的共同点：** 段永平、小Lin、温义飞、林超——**内容里没有任何一句话能被翻译成"买 X"**。
