# 回测：每年买上一年前十（2026-10-25）

**规则**：每年年初，从上一年年初的成分股（point-in-time）里选上一年涨幅前十，每只 10%，持有一年，年底换仓。起始 $100，不计成本和税。2026 只到 10-22。

**为什么不是 40 年**：免费可得的逐年成分股名单，标普500 从 1996 年开始，纳指100 从 2006 年开始。用今天的成分股往回推会有严重的幸存者偏差，所以只跑了标普 30 年、纳指 20 年。基准 SPY（1993 起）和 QQQ（1999 起）都覆盖得到。

**数据问题**：
- **早期缺口大。** 选股年里有回报数据的成分股，标普 1996 年只有 37%，纳指 2006 年只有 53%，到 2019 年后才超过 80%。缺的多是后来破产、被收购或改了代码的公司，所以早期结果偏乐观。图里早期那段用灰底标出。
- **对照线。** "同口径等权"是同一年所有有数据的成分股等权平均，它和策略带着同样的偏差，所以"策略 − 对照"才是买去年前十这个动作本身的效果。
- **剔除了 7 处错误。** 这些代码或年份里，Yahoo 的价格不是当年那家成分股（`backtest_top10.py` 的 `BAD`，由 `check_ticker_names.py` 查出）：
  - SNT：名单是 Sonat，Yahoo 是 Senstar；
  - WEN：2008 年前是 Triarc 的历史；
  - CB：2016 年前是 ACE 的历史；
  - EP：名单是 El Paso，Yahoo 是 Empire Petroleum；
  - BBT：名单是 BB&T，Yahoo 是 Beacon Financial；
  - IR：2020 年前是 Gardner Denver 的历史；
  - DLX：2001 年分拆造成的复权错位。
- **补不回来的缺口。** 比如 1998 年的 Dell（+248%）和 AOL（+585%），Yahoo 没有它们的旧数据。

| 段 | 纳指：策略 / QQQ / 对照 | 标普：策略 / SPY / 对照 |
|---|---|---|
| 早期，数据覆盖 < 80%（纳指 2007–2018，标普 1997–2018） | 10.7% / 12.2% / 13.1% | 9.5% / 7.6% / 11.2% |
| 数据覆盖 ≥ 80%（2019–2026） | 20.9% / 22.2% / 18.1% | **31.7% / 17.1% / 14.1%** |
| 2009 年以后 | 20.0% / 20.5% / 19.3% | 18.6% / 14.8% / 14.9% |

**读法**：
1. **纳指里不管用。** 20 年输给 QQQ，就连带着同样偏差的对照也没跑赢。纳指100 本身就是集中的成长股池，"去年涨得最多"不比"直接持有指数"更好。
2. **标普里管用，但主要靠最近 7 年**，即 2019 年以后的 AI 和半导体动量。1997–2018 年策略输给了同口径对照（9.5% 对 11.2%），能跑赢 SPY 主要是幸存者偏差造成的。
3. **代价是更大的回撤和"反转年"。** 大跌之后的反弹年，去年的赢家往往是防御股或已经见顶的板块，这时策略会大幅落后：
   - 2009 年：纳指 −34 个百分点，标普 −22 个百分点；
   - 2023 年：纳指 −32 个百分点（上一年的赢家是防御股）；标普 −28 个百分点（上一年的赢家是能源股）。
4. **2026 年跑得好**（标普 +55%、纳指 +45%，截至 10-22），主要是美光、西部数据、希捷和英特尔四只。
