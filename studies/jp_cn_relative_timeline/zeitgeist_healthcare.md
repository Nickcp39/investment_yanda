# 中日相对时间轴对比 · 思潮的走向与医疗的终局

- Topic: 以房价见顶为 T=0，对比中日两国**社会思潮/集体心态**在衰退后逐年的演变，
  并推演"老龄化 + 地产下行"这两个共同变量是否终将把中国医疗推上日本走过的路
- 对齐: 日本 T=0 = 1991（地价见顶）；中国 T=0 = 2021（房价见顶）；2026 = 中国 T+5 ≈ 日本 1996
- 前置逻辑链: **地产见顶 → 居民资产负债表受损 → 思潮转向（防御/低欲望/安全偏好）→
  财政与医保承压 → 医疗体系被迫控费 → 医疗产业的赢家结构被重塑**
- Last updated: 2026-07-25
- 姊妹篇: automation_semis.md（同目录）；医疗器械政策时间轴（本地，未入库）

## 0. 一句话结论

思潮层面中国在**预习过日本剧本**的前提下演进，所以每个心态节点都比日本**提前
5~10 年（相对时间轴）出现**——日本人花了 6 年才承认泡沫破了（1997 山一证券倒闭
才是心态崩塌点），中国的"躺平"在 T=0 之前就已经是年度热词。医疗的终局方向上
**会走日本的路（支付方永久性压价 + 银发经济扩张 + 赢家必须出海）**，但有一个
关键差异：日本是"先富后老、控费温和、器械放弃替代"，中国是"未富先老、控费
前置且更狠（集采比日本药价改定早了约 15 个相对年）、器械强行替代"。所以结论
不是"中国医疗会变成日本医疗"，而是：**中国医疗会以 2~3 倍速走完日本的支付
压缩阶段，然后在日本没走过的地方（器械出海、创新药 license-out）分岔。**

## 1. 思潮相对时间轴：集体心态在衰退后第几年转弯

### 1.1 日本：心态转变滞后于经济现实约 6 年

| 相对年 | 日本 | 心态关键词 |
|---|---|---|
| T=0~+5 (1991-96) | 普遍认为是"暂时调整"，土地神话未死；消费未明显收缩 | **否认期** |
| T+6 (1997) | 山一证券、北海道拓殖银行倒闭——**心态真正的断裂点** | 恐慌、安全偏好 |
| T+7~+14 (1998-2005) | "失われた10年"一词流行；就职冰河期世代定型；储蓄激增、现金为王；10年国债跌破2%(T+7) | **通缩心态固化** |
| T+14~+18 (2005-09) | 《下流社会》(T+14)、"格差社会"入选流行语(T+15)、"草食系"(T+15~18) | 阶层下滑焦虑 → 欲望退出 |
| T+19~+24 (2010-15) | "断舍离"(T+19)、极简主义；大前研一《低欲望社会》(T+24) | **低欲望定名** |
| T+23~+33 (2014-24) | NISA 推出(T+23)、新NISA(T+33)——储蓄向投资的转向**用了一代人** | 迟到的风险偏好修复 |
| T+28 (2019) | "老後2000万円問題"引爆——全民意识到养老金不够 | 老龄化焦虑大众化 |

### 1.2 中国：同样的心态节点，压缩甚至前置

| 相对年 | 中国 | 对应日本的第几年 |
|---|---|---|
| T-1~0 (2020-21) | "内卷"(T-1)、"躺平"(T=0) 成为年度热词——**低欲望话语在见顶前就出现** | 日本 T+15~+24 |
| T+1 (2022) | 居民存款单年多增 17.8 万亿；"最后一代"、"润学"；提前还房贷潮 | 日本 T+7 储蓄激增 |
| T+2 (2023) | "消费降级"主流化；拼多多市值超阿里；性价比崇拜（淄博/瑞幸/1688） | 日本 T+14 下流社会 |
| T+3 (2024) | 10年国债跌破 2%（日本用了 7 年）；存款定期化；"中国会不会日本化"成为经济学界公开辩论 | 日本 T+7 |
| T+3~+5 (2024-26) | 国九条/耐心资本/中特估——官方推动储蓄入市 | 日本 T+23 NISA |
| T+3 (2024) | 国务院首个"银发经济"文件 | 日本 T+9 介护保险 |

**读法**：心态指标上中国用 3~5 年走完了日本 7~24 年的路。两个原因：① 中国居民
**看过日本剧本**，预期自我实现得更快；② 移动互联网让"下流社会→低欲望"这类
话语的扩散速度比 1990s 的日本出版业快一个数量级。**但要警惕反向含义**：日本
心态修复（储蓄→投资）也用了 20+ 年，中国如果同样压缩，风险偏好的回归可能比
市场普遍预期的更早——官方在 T+3 就开始推"储蓄入市"，比日本的 NISA 早了 20 个
相对年。

## 2. 老龄化：中国唯一比日本更严峻的变量

| 指标 | 日本 | 中国 |
|---|---|---|
| 65+ 占比 14%→21%（老龄→超老龄） | 1994→2007，用 13 年 | ~2021→预计 2033 前后，**更快** |
| 房价见顶时 65+ 占比 | 1991: ~12.7% | 2021: ~14.2%（**起点更老**） |
| 房价见顶时人均 GDP（现价美元） | ~$29,000（全球前列） | ~$12,600（**未富先老**） |
| 劳动年龄人口见顶 | 1995 (T+4) | ~2011-2015 (**T-10~-6，先于地产见顶**) |
| 总人口见顶 | 2008 (T+17) | 2021 (**T=0，与地产同年**) |

**要点**：日本是"经济见顶 → 十几年后人口见顶"，中国是**人口与地产同年见顶**。
这意味着日本在 T+0~+10 还有人口惯性缓冲，中国没有。医保基金的压力测试因此会
比日本提前到来——这正是集采出现在 T-3（而非日本式的 T+10 之后）的根本原因：
**不是中国政策更有远见，是人口现实逼得更早。**

## 3. 医疗：日本走过的路 vs 中国正在走的路

### 3.1 日本医疗的四十年剧本（相对时间轴）

| 相对年 | 日本医疗发生了什么 |
|---|---|
| T-8 (1983) | 厚生省"医療費亡国論"——控费思想早于泡沫破裂就已埋下 |
| T+9 (2000) | **介护保险制度**上线——把养老照护从家庭移交社会化保险 |
| T+11~至今 | 药价改定（每两年强制降价，2021 起实质年度化）——**支付方永久性压价成为制度** |
| T+16 (2007) | 仿制药推广国策化（份额目标 80%，~T+29 达成） |
| T+17 (2008) | 后期高龄者医疗制度（75+ 单独成池） |
| T+20~+30 | 药企被压价逼向出海：武田、第一三共、安斯泰来收入重心转向欧美；**国内市场=现金牛，增长全在海外** |
| 全程 | 高端器械**放弃国产替代**：CT/MRI/手术机器人长期依赖 GE/西门子/直觉外科；本土只守住内镜(奥林巴斯)、导管(泰尔茂)等利基并全球化 |

**日本医疗股的裁决**（对投资最重要的一段）：失去三十年里日本医疗板块跑赢的
公司几乎全部符合一个条件——**收入主要来自日本之外**。泰尔茂、HOYA、奥林巴斯、
希森美康、朝日英泰克是赢家；纯内需的医院集团、药店、依赖国内药价的中型药企
是输家。**老龄化让医疗"需求"变大，但支付方控费让医疗"利润池"不在国内。**
"老龄化=买医疗股"在日本是被证伪的；被证实的是"老龄化=买能出海的医疗公司"。

### 3.2 中国：同样的路，但三处分岔

| 相对年 | 中国医疗 | 对应日本 |
|---|---|---|
| T-3 (2018) | **4+7 集采启动**——支付方压价制度化 | 日本 T+11 药价改定，**提前 ~14 个相对年** |
| T-2 (2019) | DRG 试点（支付方式改革） | 日本 DPC 2003 (T+12) |
| T+0~+3 | 集采扩到器械（支架/骨科/种植牙）——**日本从未做过的一步** | 无对应 |
| T+2~+4 (2023-25) | 创新药 license-out 爆发（对外 BD 金额连年翻倍）——中国药企的"出海"发生在 T+2，日本药企发生在 T+20 | 日本 T+20~+30 |
| T+3 (2024) | 银发经济文件、长护险扩面 | 日本 T+9 介护保险 |
| T+4~+5 | 医保基金部分省份当期承压，个账改革、丙类目录/商保创新药目录探索 | 日本 T+17 分池思路 |

### 3.3 回答你的问题：医疗终将走向类似的路吗？

**方向：是。三条日本铁律大概率重演——**

1. **支付方压价是永久制度，不是阶段性政策。** 老龄化数学决定了医保只能越收越紧，
   日本 30 年没有回头，中国也不会。任何"集采放松"的叙事都只是节奏，不是方向。
2. **国内医疗市场 = 以量补价的现金牛，利润增长必须来自海外。** 日本用 30 年证明
   了这一点；中国的 license-out 潮和迈瑞/联影出海就是同一剧本的中国版。
3. **照护/银发经济会成为大产业，但不一定是好投资。** 日本介护产业规模巨大、
   上市公司回报平庸（价格被介护保险管制）——银发经济里"被支付方定价的部分"
   要小心，赢家在支付方管不到的自费/设备/出海环节。

**分岔：三处中国不同——**

1. **压价来得更早更狠**（T-3 vs T+11），所以出清也更快：中国仿制药企的利润
   坍缩用 5 年走完了日本 15 年的路，幸存者转型创新的窗口也提前打开。
2. **器械做替代**（日本放弃了）：集采既是绞肉机也是国产替代加速器——外资退出
   带量市场，迈瑞/联影/微创系拿份额。这条线在日本剧本里没有对照组，是中国
   医疗里"政策做多"最明确的一段（与 automation_semis.md 的结论同构：这是
   "中国做了日本没做的事"）。
3. **创新出海发生在生命周期早期**：日本药企是被压价 20 年后才被迫出海（武田
   2011 年买 Nycomed，T+20），中国 biotech 在 T+2 就以 license-out 出海——
   因为中国有日本当年没有的东西：全球第二大的工程师/CRO 产业链和成本优势。
   这条线的终局更像"中国版第一三共"们提前 15 年出现。

## 4. 投资含义（挂到组合决策）

1. **"老龄化=买医疗"在日本被证伪，被证实的是"老龄化=买能出海的医疗"。**
   筛选标准从"国内需求受益"改为"海外收入占比/BD 能力"：创新药看 license-out
   与海外临床推进，器械看迈瑞/联影海外收入占比爬坡（对标泰尔茂 T+10~T+30 的
   海外化路径）。
2. **回避"被支付方定价的银发经济"**（养老院、被长护险覆盖的照护服务），
   关注支付方管不到的环节：康复/照护设备出海、自费医疗、脑机/手术机器人等
   新供给创造的自费需求。
3. **思潮时间轴的反向机会**：中国官方在 T+3 就开始推储蓄入市（日本 T+23 才做
   NISA）。如果心态修复同样以 2~3 倍速压缩，日本 2013-2024 那段"从通缩心态到
   资产再配置"的行情（日经从 8000 到 40000）在中国的相对时间轴上可能对应
   T+8~T+15（2029-2036）——比"日本化=永远躺平"的主流叙事更早。这是本研究里
   最反共识的一条推论，标记为待验证。
4. **证伪条件**：如果 T+5~+8 中国医保筹资改革（商保/丙类目录）真正做大了
   医保外支付池，则"利润池不在国内"的日本铁律松动，国内创新药定价逻辑要重估
   ——这是与日本剧本最可能分岔的政策变量，盯 2026-2027 商保创新药目录落地。
