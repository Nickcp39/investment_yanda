# 中日相对时间轴对比 · 自动化与半导体（对照医疗器械）

- Topic: 以房价见顶为 T=0 的中日产业政策相对时间轴 —— 自动化 / 科技（半导体为主）
- 方法: 房价峰值只作为"经济压力从何时开始"的对齐零点，**不比较地产本身**；主线是产业的政策推进与国产替代进程发生在"资产负债表衰退后的第几年"
- 对齐: 日本 T=0 = **1991**（地价见顶）；中国 T=0 = **2021**（房价/开发商见顶，恒大事件）
- 当前位置: 2026 = 中国 **T+5** ≈ 日本 **1996**
- Last updated: 2026-07-25
- 姊妹篇: 医疗器械国产替代相对时间轴（本地会话完成，尚未入库）

## 0. 一句话结论

在同一条"距房价高点第几年"的时间轴上，**半导体这条主线中日方向完全相反**：日本是
"泡沫前登顶 → 泡沫后被美国压制、份额一路流失"的**守擂衰退曲线**；中国是"泡沫前
已启动、泡沫后被制裁倒逼加速"的**攻擂上升曲线**。而**自动化是唯一一个中日同向的
行业**：日本泡沫后自动化（FANUC/基恩士/安川）反而成为失去三十年里最强的复利板块，
中国 T+3~T+5 的自动化国产替代正在复刻这条路径、且速度更快。医疗器械介于两者之间：
日本泡沫后基本放弃了器械国产替代（至今进口依赖），中国则用集采+审评改革强行推进
——这是三条主线里"中国不走日本老路"最明显的一条。

## 1. 半导体：同一时间轴，两条反向曲线

### 1.1 相对时间轴对照表

| 相对年 | 日本（T=0: 1991） | 中国（T=0: 2021） |
|---|---|---|
| T-15 | 1976 VLSI 联合研发计划（通产省牵头，追赶美国） | 2006"核高基"重大专项 |
| T-7~-6 | 1985 广场协议前后，日美贸易摩擦白热化 | 2014 大基金一期（1387亿）；2015《中国制造2025》 |
| T-5 | **1986 第一次日美半导体协定**（价格底线+外国份额20%目标）——美国压制在日本登顶时刻到来 | 2016 美国开始审查中资收购芯片资产 |
| T-3 | 1988 日本芯片全球份额 ~50%，NEC/东芝/日立霸榜 | **2018 中兴禁令**——第一记警钟；美对华科技战开打 |
| T-2 | 1989 股市见顶 | 2019 华为实体清单；大基金二期（2042亿） |
| T-1 | 1990 地价最后冲顶 | 2020 SMIC 实体清单 |
| **T=0** | **1991 地价见顶；第二次日美半导体协定** | **2021 房价见顶、恒大爆雷** |
| T+1 | 1992 三星 DRAM 反超，日本份额开始崩 | 2022.10 **美国全面出口管制**（先进制程+设备+人才） |
| T+2 | 1993 美国份额重回世界第一 | 2023 华为 Mate60 / SMIC 7nm 突围；日荷加入管制 |
| T+3 | 1994 日企开始退守利基（材料、设备除外） | 2024 **大基金三期（3440亿，史上最大）**；HBM 管制 |
| T+5 | 1996 半导体协定终止，但份额已失守 | 2026（现在）：设备/材料国产化率快速爬坡 |
| T+8 | 1999 NEC+日立合并 DRAM 成立尔必达（防御性整合） | → 待观察 |
| T+21 | 2012 尔必达破产，卖给美光 | — |
| T+31 | 2022 Rapidus 成立 + 补贴台积电熊本设厂（**日本自己开始"再国产替代"**） | — |

### 1.2 为什么方向相反 —— 结构差异，不是努力差异

1. **在压制到来时所处的位置不同**。日本被美国压制时是**在位冠军**（份额50%），
   压制的目标是"封顶"；中国被压制时是**追赶者**，压制的目标是"卡脖子"。封顶对
   在位者有效（守无可守），卡脖子对追赶者反而是最强的替代订单发生器——每一轮管制
   等于给国产设备/材料发一次强制采购令。
2. **能不能说"不"**。日本在安保上依附美国，只能接受协定（自愿限制出口、接受价格
   管制、开放20%份额）；中国不可能签"中美半导体协定"，所以压力无法通过谈判泄压，
   只能转化为替代投资。
3. **需求锚不同**。日本半导体是出口导向，美国市场被协定锁死后无处可去；中国是
   全球最大芯片进口国（峰值年进口 >4000亿美元），国产替代的需求锚在国内，政策
   （大基金、验证线、国产化率考核）可以直接指挥需求侧。
4. **泡沫后财政姿态不同**。日本 T+1~T+10 财政忙于救银行，产业政策缺位，半导体
   整合全是企业自救（尔必达式的失败合并）；中国 T+3 反而砸出史上最大的大基金三期
   ——**地产下行没有挤掉科技投入，而是让科技成为唯一的政策宠儿**。这是与日本
   相对时间轴上最大的分岔点。

### 1.3 日本真正留下的东西（对中国的镜子）

日本份额崩的是**逻辑/存储成品芯片**，但**设备（东京电子、Screen、Advantest）和
材料（信越、SUMCO、JSR、TOK）守住了全球寡头地位至今**——因为这两层靠工艺
know-how 复利，不受贸易协定管辖。含义：中国当前设备/材料国产化（北方华创、中微、
拓荆、沪硅等）如果做成，就是拿下日本当年"守得住的那两层"，这一层比先进制程本身
更耐久。

## 2. 自动化：唯一中日同向的主线

### 2.1 日本：泡沫后最强的复利板块

| 相对年 | 日本自动化发生了什么 |
|---|---|
| T-20~0 | FANUC(1972独立)/安川/基恩士(1974) 已是全球领先；1980s 日本机器人密度世界第一 |
| T=0~+5 | 国内制造业投资塌方，但**劳动力短缺+制造业外迁**让自动化出口需求接棒 |
| T+5~+15 | 中国世界工厂崛起，日本自动化吃到最大一波外需；FANUC/基恩士利润率不降反升 |
| T+15~+30 | 基恩士成为日本市值前三、人均薪酬第一的公司；自动化成为失去三十年里罕见的长牛板块 |

**要点**：自动化是日本泡沫后"活得最好"的行业，原因有二——需求是全球的（不被
国内衰退绑架），且产品是"帮别人降本"的（衰退环境反而催化采购）。

### 2.2 中国：T+3~T+5 正在复刻，且更快

| 相对年 | 中国自动化发生了什么 |
|---|---|
| T-10~0 | 汇川从变频器打到伺服；埃斯顿、绿的谐波等补链 |
| T=0 (2021) | 房价见顶；同年**中国机器人密度首超美国** |
| T+2 (2023) | 中国机器人密度超过日本（IFR: ~470 vs ~419 台/万人）；汇川伺服份额登顶国内第一（~28%），超越安川/松下 |
| T+3 (2024) | 国产工业机器人国内份额首次过半；人形机器人写入政策（工信部揭榜挂帅） |
| T+5 (2026, 现在) | 国产替代从零部件（谐波/RV减速器、伺服）向整机+具身智能延伸 |

**与日本的同与异**：
- **同**：都是衰退期逆势成长的"降本卖铲人"；都以制造业外迁/劳动力约束为需求引擎。
- **异（更快的三个原因）**：① 中国自动化替代的是**日本/欧洲在位者**的存量份额，
  有明确的靶子和价格武器；② 国内新能源车/锂电/光伏的资本开支周期提供了日本当年
  没有的本土超级需求；③ AI/具身智能让这一轮自动化有"第二曲线"，日本当年只有第一曲线。
- **风险对照**：日本自动化的长牛靠的是**出海**（外需占比极高）。中国自动化目前
  内需占比仍高，若制造业资本开支随地产链继续收缩，必须像 FANUC 当年一样完成
  出海切换——观察指标：汇川/埃斯顿海外收入占比能否在 T+5~T+10 从 <15% 拉到 >40%。

## 3. 三条主线并排：政策发力落在衰退后第几年

| 主线 | 日本（衰退后） | 中国（衰退后） | 方向 |
|---|---|---|---|
| **半导体** | T+1 起份额流失，政策缺位到 T+31（Rapidus）才反攻 | T+1 遭全面管制 → T+3 史上最大产业基金，替代加速 | **反向** |
| **自动化** | T=0 起靠外需走出长牛，政策基本没管（市场自发） | T+2~+3 密度超日、份额过半，政策+市场双轮 | **同向，中国更快** |
| **医疗器械** | 泡沫后未做国产替代，至今高端器械依赖进口（GE/西门子/美敦力） | T-6 起审评改革，T+0~+5 集采+国产优先采购强推替代（迈瑞、联影） | **反向（中国补了日本没做的课）** |

**读法**：日本泡沫后的产业结局 = "市场自发全球化的行业活（自动化、设备材料），
被贸易协定锁死的行业死（成品芯片），政策没管的行业原地踏步（器械）"。中国的
不同在于：政策在 T+0~T+5 就同时押注了三条线，且外部压制反而成为助燃剂。**如果说
医疗器械是'中国做了日本没做的事'，那半导体就是'中国在做日本被禁止做的事'，
自动化则是'中国在重跑日本做成过的事'。**

## 4. 投资含义（挂到组合决策）

1. **相对时间轴上最像"日本赢家"的中国资产是自动化龙头**（汇川≈FANUC 路径）：
   衰退期利润率韧性 + 替代份额 + 潜在出海第二曲线。当前处于日本对应的 T+5 ≈ 1996
   ——FANUC/基恩士的长牛主升段发生在 T+5~T+25，即"现在到未来二十年"。
2. **半导体设备/材料 > 成品芯片**：日本经验证明衰退与贸易战里最耐久的是设备材料层。
   中国对应标的（北方华创、中微、拓荆、沪硅产业等）的国产化率爬坡是政策强度最高、
   需求确定性最高的一段。
3. **反面清单**：日本教训里"防御性整合"（尔必达式的落后产能合并）是价值陷阱信号
   ——中国若出现"拼凑式芯片合并救亡"，按日本剧本应回避。
4. **速度差校准**：此前医疗器械时间轴的结论"中国速度更快"在自动化与半导体同样
   成立，中国用 T+5 走完了日本 T+15~+20 的替代里程碑；但**出海**这一步中国三条线
   都还没证明，是相对日本剧本最大的缺环，也是下一个验证点。
