## 结论速览

1. **口径**：本轮的顶 = **2025-08-12（$123,366）**；2025-10-05（$124,720）只是比它高 1.1% 的回测，不作锚点。底 = **2026-06-30（$58,586）**。顶→底 322 天、-52.5%（前两轮 364 / 378 天，-84% / -77%）。
2. **四轮检验（2013 / 2017 / 2021 / 2025）**：本轮每个阶段都比上一轮更快、更小；幅度退火 12 个比例全部成立；时间上最稳的是顶→顶每轮少 50 天（1,473 → 1,423 → 1,373 天）。
3. **下一个顶**：价格 **$16.3 万–$24.8 万**（中位约 $21.3 万）。时间分两派：市场时钟 **2029-01 下旬 ～ 03 底**（中心 2029-03-27）；减半时钟 **2029-08-02 ～ 2029-12-30**（下次减半约 2028-04-10）。
4. **减半与暴涨**：减半在前四轮牛市里都落在正中间（48–52%），但本轮底离下次减半有 650 天（以前 405–542 天），所以「顶→顶每轮少 50 天」和「减半居中」下一轮不能同时成立。突破前高从「减半后 3–8 个月」变成了 2024 年的「减半前 47 天」；最猛的 90 天 ×16.9 → ×5.3 → ×3.6 → ×1.85，下一轮约 ×1.5，四轮里三轮在它结束后 8–10 个月才见顶。
5. **以后用来确定顶的路标**（报告 §5.6）：① 什么时候重新突破 $123,366（2027 下半年 → 偏市场时钟；2028 初或减半之后 → 偏减半时钟）；② 2028-04 减半当天价格在不在 $123k 以上；③ 最猛的一个季度什么时候出现。
