# 铲子百年实证 · PLAN

**日期**: 2026-09-23 · **状态**: 完成（report.md 已产出）

## 触发

百年实证（`studies/电力需求与电力公司盈利_百年实证_2026-09-16/`）证明"卖那个东西的人"（生产者）
九次需求暴涨、九次零超额回报。用户追问："那卖铲子的赚钱吗？"（航空支持者、to B 卖飞机零件的）。

## 命题

验证：把"卖铲子的人"作为一个整体，长期到底赚不赚钱？

## 方法

1. 从百年实证 11 案例（铁路/石油/钢铁/电力/汽车/航空/光纤/光伏/航运/页岩/AI电力）提取"上一级铲子"
   （给商品生产者卖工具/设备/服务的人），映射到可查股价标的（36 个）。
2. Yahoo Finance chart API 抓取复权月线（adjclose），`period1=0` 拿完整历史。
3. 计算全期 CAGR + 相对 ^GSPC 超额 + 关键分段（Cisco 建设期前后、发动机 vs 结构件）。
4. 按"锁类型"分组对比：售后锁定 / 寡头专利 / 监管牌照 / 转换成本 / 窗口稀缺 / 裸铲子。

## 核心结论

不是"卖铲子的赚钱"，是"卖带锁的铲子的人赚钱"。
判据：客户明天能不能换一家买。换不了（带锁）→ 长期超额；换得了（裸铲子）→ 和生产者一样不赚钱。
窗口稀缺是裸铲子的前半段（Cisco 建设期 948 倍 → 建设期后 26 年 2.1 倍）。

## 已知局限

- 国际股本币口径，相对美股基准含汇率偏差（方向性不受影响）
- Spirit AeroSystems 等已退市标的用定性（被收购结局）
- 锁类型是主观分类，但判据可证伪
- 幸存者偏差：能查到股价的往往活下来了，缓解（已消亡的裸铲子只会让结论更强）
