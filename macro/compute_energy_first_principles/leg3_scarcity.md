# 腿三 · 稀缺性归宿 —— 20 年后什么还稀缺

**方法：对链条每一环只问一个问题——**

> ## **20 年时间尺度上，它能不能被造出来 / 建出来 / 复制出来？**
> **能 → 没有持久价值。不能 → 价值在这里。**

这一问来自腿四的基率②：**价值只归于不可复制的卡点和最终用户，中间的重资本建设者被榨干。**

---

## 稀缺性表

| 环节 | 能被复制吗 | 20 年后还稀缺？ | 证据 |
|---|---|---|---|
| **GPU / 加速器** | ✅ **能造** | ❌ **不稀缺** | 制程有限制但产能可扩；多家竞争（NVDA/AMD/自研 ASIC/TPU） |
| **数据中心建筑** | ✅ **能建** | ❌ | 钢筋水泥，无壁垒 |
| **模型权重** | ✅ **几个月就折旧** | ❌ | 今天的"便宜档"就是 2023 的"前沿档"——2–3 年滞后 |
| **发电容量（燃气）** | ✅ **能建，联合循环约 2 年** | ❌ | Aschenbrenner 自己算过：~1200 口页岩井 ≈ 100GW |
| **土地** | ✅ 美国不缺 | ❌ | |
| 🟡 **HBM / 先进封装（CoWoS）** | ⚠️ **能扩，但周期长** | 🟡 **中期稀缺，长期不** | 产能可建，但 2–3 年爬坡 |
| 🔴 **燃气轮机** | ❌ **全球只有 3 家能造** | 🟡 **已售罄到 2030** | 见下 §2 |
| 🔴 **并网点 / 输电容量** | ❌ **受审批与物理线路限制** | ✅ **可能是最硬的一格** | 见下 §3 |
| 🔴 **既有无碳基荷（存量核电）** | ❌ **一代人没按时按预算建成过** | ✅ **不可新建** | CEG 那张卡赌的就是这一格 |
| 🔴 **EUV 光刻** | ❌ **目前独家** | ✅ | 腿四的对照组已验证这类卡点会捕获价值 |

## 2. 🔴 燃气轮机 —— 一个正在验证中的卡点

| | |
|---|---|
| 能造的厂商 | **全球 3 家**（GE Vernova / Siemens Energy / 三菱重工） |
| **交期** | 从 2–3 年拉长到 **5–7 年**；**2030 年前基本买不到** |
| GE Vernova 在手 | **116 GW**（Q2），已在接 **2031 年**交付的预订 |
| Siemens / MHI | 69 GW / 35 GW |
| **价格** | **自 2019 年以来接近翻三倍** |
| 行业口径 | **"约束在产能，不在需求"** |

> **这一格符合"不可复制"的定义：不是钱的问题，是全世界只有三条产线。**

⚠️ **但要注意两件事：**
1. **产能正在扩**：GEV 计划从 ~20 GW/年 → 2028 年 24 GW → 2030 年 30 GW；MHI 在翻倍。
   **⇒ 这个卡点有明确的到期日。** 不是永久稀缺，是**窗口稀缺**。
2. **价格已经反映**：GEV 在 ~46–51× 清洗后 fwd EBITDA（库内 2026-06-19 卡）。
   **卡点是真的，但它被定价成了软件公司。**

## 3. 🔴 并网点 —— 目前看最硬的一格

| | |
|---|---|
| **美国并网排队** | **2,600 GW 积压**（2026） |
| 明细（2025 年底） | 8,200 个项目，**1,312 GW 发电 + 749 GW 储能** |
| **中位等待** | **接近 5 年**；仅"研究阶段"就 18–36 个月 |
| **数据中心** | 部分情形可能等 **12 年** |
| 行业口径 | **"已从可管理的项目风险，变成美国部署新能源与数据中心产能的单一最大结构性障碍"** |
| PJM | 因积压暂停多年后，2026 年才重开排队 |

> **为什么这一格最硬：它不是资本问题，也不是产能问题，是审批与物理线路问题。**
> **钱解决不了排队。多建一条产线也解决不了排队。**

**⇒ 这一格的含义是反直觉的：**
**不是"谁能发电"值钱，是"谁已经有并网点"值钱。**
既有的、已并网的存量资产，比任何新建项目都稀缺 —— **因为新建的要排 5 到 12 年队。**

## 4. 从表里读出来的三条结论

### ① 本表把"AI 基建"清晰地切成了两半

| 被复制的一半（→ 资本被毁） | 不可复制的一半（→ 价值留存） |
|---|---|
| GPU、数据中心、模型、发电容量、土地 | 并网点、既有核电、EUV、（窗口期内）燃气轮机 |

**而 2026 年 $7,200 亿的四大厂 capex，绝大部分花在左边那一列。**

### ② 卡点的两种寿命，必须分开

| | 例子 | 性质 |
|---|---|---|
| **窗口稀缺** | 燃气轮机、HBM/CoWoS | 产能在扩，有到期日。**价值是周期性租金** |
| **结构稀缺** | 并网点、既有核电、EUV | 没有明确到期日。**价值是永续租金** |

> **把窗口稀缺按结构稀缺定价，是这一轮最可能的错误。**
> **GEV 46–51× 和 VRT 48× 正是这个形状。**

### ③ 与库内 CEG 那张卡的接口

CEG 的 STARTER 论点是 **"存量无碳基荷不可新建"** —— **它赌的正是本表里"结构稀缺"那一格。**

本腿的分析**支持**这个论点的**结构部分**，但附一个条件：
> **它的价值取决于"新建到底有多难"。若小型模块化反应堆（SMR）在 20 年内跑通，这一格会从结构稀缺退化为窗口稀缺。**
> **⇒ 新增监控项：SMR 的首堆按期按预算投产记录。**

## 5. 本腿的 OPEN

- **L3-1**：并网排队的积压，有多少是"僵尸项目"（重复申请、投机占位）？真实积压可能远小于 2,600 GW
- **L3-2**：输电线路建设的实际速率（英里/年），以及它是否在加速
- **L3-3**：SMR 的实际进度 —— 这决定既有核电是结构稀缺还是窗口稀缺
- **L3-4**：燃气轮机产能扩张的兑现率（GEV 承诺 2030 年 30 GW/年，历史兑现记录如何）
- **L3-5**：端侧推理若大规模迁移，会不会把"并网点"这个约束整体绕开
