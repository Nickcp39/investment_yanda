## 1. 它的结论（直接引用，本腿全盘采纳）

> **需求增长是真的，几乎每一次都是真的。生产者的股东照样不赚钱，几乎每一次都不赚。**
> **原因不是需求预测错了 —— 恰恰是因为需求预测对了，资本才会涌进来把回报打到资本成本以下。**

**五条硬结论里，最重要的两个数：**

| | |
|---|---|
| **百年总账** | 1926-07 → 2026-07：公用事业 **9.22%/yr** vs 全市场 **10.35%/yr**；90 个滚动十年窗口只跑赢 **33 个（37%）** |
| **🔴 相关系数** | **需求增速 与 公用事业超额收益：r = −0.38**（8 个时代） |

> **r = −0.38 是这两份研究里最有价值的单个数字。**
> **需求增长越快，电力公司股东的超额收益越低 —— 而且是负相关，不是无关。**

**九个案例，九次需求兑现，零次生产者股东作为一个群体赚到超额回报。**

**四种价值捕获者**（该研究 §19）：① 不可复制的稀缺资产 ② 瓶颈环节 ③ 有保护的工具供应商 ④ 使用者。
**"卖那个东西的人"不在表里，除非他同时是 ①②③ 之一。**

## 2. 本腿补充的三样（该研究没有覆盖的）

### 补充 ① · 美国铁路 1873 / 1893（该研究用的是英国 1843–50）

| | |
|---|---|
| **1873 恐慌** | 11 月 **55 家**铁路倒闭，次年 9 月**再 60 家**；**1876 年约一半公司进入破产管理，控制全国一半里程**；1873–78 铁路股**跌近三分之二** |
| **1893 恐慌** | **近 200 家**进入破产管理，涉 **4.1 万英里**；**1895 年全国 1/3 里程在破产中** |
| 股东回报 | 1890s **只有 30–40% 的铁路股付过任何股息**；债券收益率 6%→3.3% |

**意义**：英国样本是**一次**狂热，美国样本证明**同一个行业在二十年内被消灭了两次**。

### 补充 ② · 美国页岩 2010–2020（该研究完全没有）

| | |
|---|---|
| 需求/供给预测 | ✅ 对 —— 十年新增 **750 万桶/日** |
| **资本毁灭** | 十年累计净自由现金流 **−$3,000 亿**；减值 **>$4,500 亿**；**190+ 家破产** |
| 机制 | 管理层被激励追求**增长**而非回报 |
| 价值归宿 | **消费者**（低油价）+ 中游管道与矿权 |

**意义**：这是**最近的一个完整周期**（2020 年才结束），而且发生在现代资本市场、现代披露制度下。
**不能用"那是一百年前"来打折。**

### 补充 ③ · 一个可操作的观测量（该研究给了规律，没给指标）

光纤样本里最精确的一条：

> **WorldCom 宣称流量每 100 天翻倍。实际是每年翻倍。**
> **每年翻倍 = +100%/年 —— 真实且惊人。而资本仍被毁，因为供给按 3.65 倍于真实速率建。**

> ## **⇒ 该盯的从来不是"需求增速"，是：**
> # **供给增速 ÷ 需求增速**

**这个比值目前没有任何一方在公开跟踪，而它是整件事的核心变量。**
详见 `synthesis.md` §7 的跟踪设计。

## 3. 两份研究的独立收敛（值得记一笔）

| | 本研究（腿一–三） | 百年实证研究 |
|---|---|---|
| 方法 | 物理恒等式 + 稀缺性拆解 + 五个样本 | **百年回报数据 + 九个案例 + 相关性分析** |
| 数据 | Koomey / Masanet / IEA / 并网队列 | CRSP 类回报序列 / EIA 需求史 |
| 结论 | 价值归于不可复制的卡点与用户 | **价值归于四类捕获者，"卖东西的人"不在其中** |

**两个会话、不同方法、不同数据源，结论一致。**
**这不是互相抄，是独立收敛——这比任何一份单独的研究都更有说服力。**
