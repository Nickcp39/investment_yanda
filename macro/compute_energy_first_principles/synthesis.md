# 汇总 · 这套研究在百年实证之上多说了什么

**as_of 2026-09-17** · 本文**不是**四条腿的并排陈列，而是**接到 `studies/电力需求与电力公司盈利_百年实证_2026-09-16/report.md` 之后**的增量。

---

## 0. 先认账：主结论不是我这边产出的

那份百年实证（另一会话，2026-09-16）已经给出这件事的主结论，而且比我做得硬：

> **需求增长是真的，几乎每一次都是真的。生产者的股东照样不赚钱，几乎每一次都不赚。**
> **原因不是需求预测错了 —— 恰恰是因为需求预测对了，资本才会涌进来把回报打到资本成本以下。**

支撑它的两个数，本研究全盘采纳、不再重做：

| | |
|---|---|
| 百年总账 | 1926-07 → 2026-07：公用事业 **9.22%/yr** vs 全市场 **10.35%/yr**；90 个滚动十年窗口只跑赢 **33 个（37%）** |
| 🔴 **相关系数** | 需求增速 与 公用事业超额收益：**r = −0.38**（8 个时代）——**不是无关，是负相关** |

以及它的四种价值捕获者（§19）：
**① 不可复制的稀缺资产 · ② 瓶颈环节 · ③ 有保护的工具供应商 · ④ 使用者。**
**「卖那个东西的人」不在表里，除非他同时是 ①②③ 之一。**

**⇒ 本研究（腿一–腿三）的角色，是给这张表补三件它没做的事。**

---

## 1. 🔴 三件增量，一句话各一

| 增量 | 来自 | 一句话 |
|---|---|---|
| **A · 约束在哪一格** | 腿一 + 腿三 | **不是"发多少电"，是"从哪接进去"——而且这个约束是 2020 年才出现的** |
| **B · 这张牌桌有多大** | 腿二 | **成熟态年收入上限 $2.4–4.9 万亿；四家公司一年 capex 已经等于其中 10% 情景的三成** |
| **C · 稀缺要分两种** | 腿三 | **窗口稀缺 ≠ 结构稀缺。把前者按后者定价，是这一轮最可能的单一错误** |

---

## 2. 增量 A · 约束是新出现的，而且不在总量上

这一条**修正**了一个常见的、连百年实证也没必要处理的前提："电不够用"。

| | |
|---|---|
| 2010–2018（Masanet, *Science* 2020） | 全球数据中心算力 **+550%（6.5×）**，用电 **194 → 205 TWh（+6%）**。**效率吸收了 97%** |
| 2020 之后 | Koomey 周期从 **1.57 年 → 2.6 年 → 2.29 年**；效率只能吸收 **20–25%** |
| **⇒ 交叉点** | **≈ 2020 年** |
| 但总量 | IEA：2030 年数据中心 **945 TWh = 全球发电的 3.1%** |

> ## **总量根本不紧。紧的是接入：2,600 GW 的并网排队、5–12 年的等待。**

**这一条对那份研究的用处**：它解释了为什么 2023–26 是 **VST 6.43x / CEG 3.22x（既有资产重定价）** 而不是 **XLU（跑输 12pp/yr）**。
**稀缺不在"电"这个商品上，稀缺在"已经接好的那个点"上。** 商品端没有稀缺，所以卖商品的人拿不到钱 —— 这正是 r = −0.38 的物理解释。

---

## 3. 增量 B · 牌桌尺寸 —— 一个百年实证没算的刻度

九个历史案例都没有这个数，因为钢/电/带宽的需求上限不好定义。AI 可以，因为它替代的是**有工资单的知识工作**。

| | |
|---|---|
| 全球知识工作年薪总额 | **~$24 万亿**（量级刻度，非精算） |
| 替代 10–20% 且全部货币化 | **$2.4–4.9 万亿/年** ← **成熟态收入天花板** |
| 四大厂 2026 年 capex | **$7,200 亿** |
| **比值** | **capex 一年 = 10% 情景成熟态年收入的 30%** |

> **读法：这个天花板不低 —— 它比全球云计算市场大一个量级。**
> **但支出是现在发生的，收入是成熟态的。腿二的 OPEN 就是这个时序差有多长。**

**这一条对那份研究的用处**：它把「外推」变成可证伪的。
第 3 段思潮（"需求会永远这样增长"）在历史上从来无法被当场证伪，因为没人知道上限。**这次有上限，而且能算。**

---

## 4. 🔴 增量 C · 窗口稀缺 vs 结构稀缺 —— 对那张四类表的切分

那份研究的 ①（不可复制的稀缺资产）和 ②（瓶颈环节）在**时间维度上是混的**。腿三把它切开：

| | **结构稀缺** | **窗口稀缺** |
|---|---|---|
| 定义 | 20 年尺度上**造不出来** | **能造出来，只是现在还没造完** |
| 判据 | 产能扩张计划是否存在、是否可测 | 同上 |
| 例 | **并网权/输电**、**既有核电**、**EUV** | **燃气轮机**、变压器、HBM、施工人力 |
| 定价应当 | 长期租金 | **折现一个会关闭的窗口** |

**当前最具体的一个质疑：**

| | |
|---|---|
| 燃气轮机是真卡点吗 | ✅ 全球三家、售罄到 2030、价格自 2019 近三倍 |
| 但产能在扩吗 | ✅ **GEV 20 → 24 → 30 GW/年** |
| 所以是哪一种 | **窗口稀缺** |
| 市场怎么定的价 | **GEV 46–51× / VRT 48× fwd EBITDA** |

> ## **把窗口稀缺按结构稀缺定价 —— 这是本研究给出的最具体的一个可证伪判断。**

**它正好对上那份研究的 K-4**（GEV 交付周期从 4 年降到 2 年内 → 商业发电商护城河消失）。
**⇒ K-4 不只杀发电商，同时杀 GEV / VRT 自己的估值。那份研究的 kill 表里这一格可以补上。**

**反向的一条**：CEG 赌的「既有无碳基荷不可新建」目前在**结构稀缺**格里，成立。
**但若 SMR 在 20 年内按期按预算跑通，它退化为窗口稀缺。**
→ **新增监控：SMR 首堆的实际投产日期与预算偏离。**

## 5. 两份研究的独立收敛（值得记一笔）

| | 本研究（腿一–三） | 百年实证 |
|---|---|---|
| 方法 | 物理恒等式 + 稀缺性拆解 | 百年回报序列 + 九案例 + 相关性 |
| 数据 | Koomey / Masanet / IEA / 并网队列 | CRSP 类回报 / EIA 需求史 / Yahoo |
| 结论 | 价值归于不可复制的卡点与用户 | 价值归于四类捕获者，"卖东西的人"不在其中 |

**两个会话、不同方法、不同数据源，结论一致。这不是互相抄，是独立收敛。**

**但也要说清楚收敛的局限**：两者都在**同一个先验**下工作 ——「重资本投入品的生产者不赚钱」。
**如果这个先验本身是错的，两份研究会一起错。** 见 §8。

## 6. 🔴 一个两份研究都指向、但都还没建的东西

光纤样本给出的最精确的一条：

> **WorldCom 宣称流量每 100 天翻倍。实际是每年翻倍。**
> **每年翻倍 = +100%/年，真实且惊人。而资本仍被毁 —— 因为供给按 3.65 倍于真实速率建。**

> ## **⇒ 该盯的从来不是"需求增速"。是：**
> # **供给增速 ÷ 需求增速**

**这个比值目前没有任何一方在公开跟踪。**

**能落地的最小版本（季度，四个分子四个分母）：**

| | 分子（供给） | 分母（需求） |
|---|---|---|
| 算力 | 四大厂 capex 同比 + NVDA 出货同比 | AI 相关收入同比（云 AI 分部 + API + 订阅） |
| 电力 | 新增并网容量（MW） | 数据中心实际用电（EIA / ISO） |
| 轮机 | GEV+SIE+MHI 年产能 | 新签订单 |
| 空间 | 新建机架容量 | **利用率**（← 光纤的 2.7% 就死在这一格） |

**触发规则（不是买卖信号，是叙事状态机）：** 比值 > 1.5 连续两季 → 那份研究思潮弧线的**第 4 段**；出现利用率公开下修 → **第 5 段**。

## 7. 对本库既有判断的回喂（只列本研究新增的，不重复那份研究 §22）

### ① 给"AI 公司算不算基建"一个答案
四大厂 capex/营收：**AMZN 27.5% · GOOGL 39.4% · META 56.8% · MSFT 61.3%**，其中三家**高于受监管公用事业的 15–25%**。

> **但它们没有 9.5% 的允许 ROE，没有费率基础，没有成本转嫁机制。**
> ## **结论不是"应该按能源股 16–18× 估值"，是"连能源股的保底都没有"。**

**同时必须记下反面**：那份研究的第 ④ 类（使用者）历史上最终最赚，而这四家正是使用者。
**⇒ 它们同时坐在最赚的椅子（④）和最危险的椅子（无保底重资本）上。这两件事不互相抵消，要分开定价。**

### ② 补两个那份研究没有的历史样本（详见 `leg4_base_rates.md`）
- **美国铁路 1873 / 1893**：1876 年约一半公司进入破产管理；1893 年近 200 家、4.1 万英里。**同一行业二十年内被消灭两次。**
- **美国页岩 2010–2020**：十年净自由现金流 **−$3,000 亿**，减值 **>$4,500 亿**，**190+ 家破产**，而产量预测**是对的**（+750 万桶/日）。**这是 2020 年才结束的周期，不能用"那是一百年前"打折。**

## 8. 这套研究**不**产出什么，以及它最可能错在哪

**不产出：** ❌ 任何买卖建议 · ❌ AGI 时间表 · ❌ 电价 / GPU 价格 / 标的价格预测

**产出的是四条先验，以后所有 AI 相关的卡都应带着它们：**

1. **"需求会涨"不构成投资依据**（r = −0.38，九案例零次）
2. **约束在接入点，不在总量**（腿一 + 腿二）
3. **只投不可复制的环节，且必须区分窗口稀缺与结构稀缺**（腿三）
4. **盯「供给增速 ÷ 需求增速」，不盯需求增速**（§6）

**最可能错的地方，按严重性排：**

| # | 风险 | 为什么不能一句"AI 不一样"带过 |
|:--:|---|---|
| **1** | **两份研究共享同一先验**，会一起错 | 若要主张不同，必须指出**具体哪个结构变量**变了 —— 候选：需求方是自有现金流的巨头（不是靠融资的运营商），风险已部分转移给买方 |
| **2** | 历史样本全是**同质化商品**；算力可能不是 | 但 2024–26 的实盘显示算力正在商品化（价格三年 −1,000×）—— **这条反而支持先验** |
| **3** | 腿二的 $24 万亿是**量级刻度**，不是精算 | 上下差两倍不改变结论（$1.2–9.8 万亿仍是量级） |
| **4** | **零条 A 级一手来源**（INC-004 未解除） | 全部为同行评审论文 / IEA / 史料的二手转述。**任何用到这些数字的卡不得标 CLEAN** |

> **最后一句，给未来的自己：**
> ## **需求增长是文明的红利，不是生产者的红利。**
> **每一代投资者都要重新学一遍，因为每一次的需求都是真的。**
