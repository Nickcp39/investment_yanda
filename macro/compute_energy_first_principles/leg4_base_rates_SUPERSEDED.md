# 腿四 · 历史基率 —— 同构事件的实际结果

**这一腿不做类比修辞，只提取两个数：**
**① 在"需求确定会涨"的建设周期里，资本被毁掉多少？**
**② 幸存的价值最后落在链条哪一环？**

**入选标准（结构，不是行业）**：需求确定会涨 + 资本大量涌入 + 重资产/长周期建设。

---

## 样本一 · 美国铁路（1870s–1890s）

| | |
|---|---|
| 需求预测 | ✅ **完全正确** —— 铁路运量此后半个世纪持续增长 |
| **1873 恐慌** | 11 月 **55 家**铁路倒闭；次年 9 月**再 60 家**；**到 1876 年约一半公司进入破产管理，这些管理人控制全国一半里程**；1873–78 铁路股**跌近三分之二** |
| **1893 恐慌** | **近 200 家**进入破产管理，涉及 **4.1 万英里**；**1895 年全国 1/3 里程在破产中** |
| 股东回报 | 1890s **只有 30–40% 的铁路股付过任何股息**；债券收益率 6% → 3.3%，股息 7% → 3.5% |
| 机制 | 竞争线路抢占最好的路权，投机驱动建设 → 过度建设 |

> **需求对了半个世纪，而两代股东被消灭了两次。**

---

## 样本二 · 电信光纤（1996–2001）—— **与 AI 最像的一个**

| | |
|---|---|
| **需求预测** | ✅ **对，而且是大幅增长** —— 互联网流量确实在**年年翻倍** |
| 投入 | **$5,000 亿**铺设跨洋跨洲光缆 |
| **资本毁灭** | 2000–2002 全球电信股市值蒸发 **> $2 万亿**；**60+ 家大公司破产**；WorldCom **$1,070 亿**（雷曼之前美国最大） |
| **利用率** | **2002 年 97.5% 的光纤是暗的**；**2005 年底仍有 85% 是暗的** |
| 价格 | 带宽成本 **−90%** |
| **价值归宿** | **用户**。Google / Amazon 后来以极低价买下暗光纤，成为自己的骨干网 |

### 🔴 这个样本里最重要的一个细节

> **WorldCom 当年宣称"互联网流量每 100 天翻倍"。**
> **实际是每年翻倍。**
>
> **每年翻倍 = +100%/年 —— 这是一个极高的、真实的增长率。**
> **而资本仍然被毁掉了，因为供给是按 3.65 倍于真实速率建的。**

**⇒ 教训不是"需求是假的"。需求是真的、巨大的。**
**教训是：供给按被夸大的需求速率建设，即使真实需求同样惊人，也会全面过剩。**

## 样本三 · 太阳能（2000s–今）—— **与 AI 的"成本崩塌"最像**

| | |
|---|---|
| 成本曲线 | **Swanson 定律**：累计出货量每翻倍，组件价格 **−20%**；约每十年 **−75%** |
| 实际 | **$76.67/W（1977）→ $0.36/W（2014）= 213 倍** |
| 需求预测 | ✅ 对 —— 装机量爆炸式增长 |
| **制造商** | **Suntech**（2011 年全球第一大组件厂）2013 年破产；**SunEdison** 2016 Ch11 |
| **下游** | **2023 年以来 100+ 家美国太阳能公司破产**，含 SunPower、Sunnova、Freedom Forever 等全国性安装商 |
| 根因 | **制造商之间竞争过度，把价格压到不可持续** |
| 价值归宿 | **用户**（便宜的电） |

> **⇒ 这是"学习曲线驱动的成本崩塌"的标准结局：**
> **成本每翻倍降 20%，需求因此爆炸，而降价的执行者自己被降价杀死。**
>
> **对照 AI：固定能力的推理单价三年降约 1,000 倍。结构完全同形。**

## 样本四 · 美国页岩（2010–2020）

| | |
|---|---|
| 需求/供给预测 | ✅ 对 —— 十年新增 **750 万桶/日**供给，改变了全球能源格局 |
| **资本毁灭** | **净自由现金流 −$3,000 亿**（十年累计）；**减值 > $4,500 亿**；**190+ 家破产** |
| 机制 | 管理层被激励追求**增长**而非回报，季复一季把全部现金流再投入 |
| **价值归宿** | **消费者**（低油价）+ 部分**中游管道与矿权持有者** |

> **一个技术革命，产量兑现了，投资人被消灭了，消费者赢了。**

## 样本五 · 半导体（对照组 —— 为什么这个不一样）

**上面四个样本里资本都被毁掉了。半导体是同样重资本、同样需求确定，但价值被捕获了。为什么？**

| | 被毁掉的四个 | 半导体 |
|---|---|---|
| 环节数量 | 多个可替代的建设者 | **少数不可替代的卡点** |
| 进入壁垒 | 资本（可筹措） | **资本 + 累积工艺知识 + 设备垄断** |
| 结果 | ASML（EUV 独家）、TSMC（先进制程）捕获了大部分价值 | |

> **⇒ 这是全腿最重要的对照：**
> **决定资本会不会被毁的不是"行业好不好"，是"这一环能不能被复制"。**
> **可复制 → 资本被竞争掉。不可复制 → 价值留下。**

## 五个样本的共同结构

| | 需求预测 | 资本结局 | 价值归宿 |
|---|---|---|---|
| 铁路 | ✅ 对 | 两次近半数破产 | 托运人/经济体 |
| **光纤** | ✅ **对（年翻倍）** | **$2 万亿蒸发，97.5% 闲置** | **用户（Google/Amazon 捡便宜）** |
| 太阳能 | ✅ 对 | 全球第一大厂破产，100+ 家倒闭 | 用户 |
| 页岩 | ✅ 对 | −$3,000 亿 FCF，190+ 破产 | 消费者 |
| 半导体 | ✅ 对 | **未被毁** | **卡点（ASML/TSMC）** |

## 🔴 提取出来的两个基率

### 基率 ①：**需求预测正确，与投资人赚钱，是两件几乎无关的事**
**五个样本里，需求预测五次全对。资本四次被大规模毁掉。**

### 基率 ②：**价值归宿只有两个地方——不可复制的卡点，和最终用户。中间的重资本建设者是被榨干的那一环。**

---

## 对 AI 的直接含义（不是预测，是先验）

1. **"AI 需求会涨"这个判断即使 100% 正确，也不构成任何投资依据** —— 五个样本都证明了。
2. **要问的唯一问题是：哪一环不可复制。** GPU 可造、数据中心可建、模型几个月折旧、发电可建 —— **这些全部对应"被毁掉"的那一类**。
3. **成本崩塌（推理单价三年 −1000×）在太阳能上的对应结局是：执行降价的人自己死掉。**
4. **"供给按被夸大的速率建"是光纤的死因，而不是"需求没来"。**
   **⇒ 对 AI，该盯的不是"需求增速"，是"供给增速 ÷ 需求增速"。**
