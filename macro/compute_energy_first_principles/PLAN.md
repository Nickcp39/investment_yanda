# 算力与能源 · 第一性原理研究 — 运行计划

**批次 ID** `compute_energy_first_principles` · **开始** 2026-09-17
**性质**：**结构研究，不是公司研究。** 不产出 buy/sell，产出**以后所有 AI 相关的卡该用什么先验**。

---

## 0. 为什么这个研究存在

用户给的前提是：*「我们知道的唯一标准是电力和 AI 的需求都会上涨」*。

**这句话是真的，但信息量接近零——因为所有人都同意它。**
所有人都同意的事已经在价格里。历史上「需求预测对了、资本照样被毁掉」的案例不是少数，是常态。

> **⇒ 研究的起点不是"需求会不会涨"，而是：**
> **在需求确定会涨的前提下，什么决定了钱最后落在谁手里。**

## 1. 四条腿

| 腿 | 问题 | 必须产出 |
|---|---|---|
| **一 · 物理恒等式** | 电力到底是不是真约束 | **一个交叉点**：算力需求增速 vs 每焦耳算力改进率，谁快 |
| **二 · 经济天花板** | 算力支出的上限在哪 | **一个上限 + 一个拐点年份** |
| **三 · 稀缺性归宿** | 20 年后什么还稀缺 | **一张表**：每一环「能否被造/建/复制」 |
| **四 · 历史基率** | 同构事件的实际结果 | **两个数**：资本毁灭率、价值归宿 |

## 2. 铁律

- **每条腿的验收标准相同：产出一个可证伪的数字或一张可查证的表，不是一段推理。**
- **类比放宽**：不要求完全吻合，只要底层结构相通就收（用户明确要求）。
  结构定义 = **需求确定会涨 + 资本大量涌入 + 重资产/长周期建设**。
- 一手优先；全部数据标 tier；本环境 INC-004 仍未解除，行情类数据一律 `unverified_secondary`。
- **禁止用"AI 不一样"作为跳过历史基率的理由。** 若要主张不一样，必须指出**具体哪个结构变量不同**。

## 3. 执行顺序

```
腿一（物理）  ← 先跑。若"每焦耳算力改进 > 需求增长"，整个电力叙事塌，后三条不用跑
腿四（基率）  ← 同时跑。它给另外三条腿的乐观程度定标
腿三（稀缺）  ← 依赖腿四的"价值归宿"结论
腿二（天花板）← 最后，因为它需要腿一的效率曲线做输入
```

## 5. 进度

| 腿 | 状态 | 产出的那个数 |
|---|---|---|
| 一 · 物理 | ✅ | **交叉点 ≈ 2020 年**（2010–18 效率吸收 97% 需求增长；现在只吸收 20–25%） |
| 二 · 天花板 | ✅ | **$2.4–4.9 万亿/年**；2030 数据中心仅占全球发电 **3.1%** |
| 三 · 稀缺 | ✅ | **并网点 / 既有核电 / EUV** 不可复制；燃气轮机是**窗口稀缺** |
| 四 · 基率 | ✅ | **五个样本需求五次全对，资本四次被大规模毁掉** |

**汇总见 [synthesis.md](synthesis.md)。** 一句话：
**电力确实是约束，但约束在"从哪接进去"，不在"发多少电"；
而 $7,200 亿 capex 绝大部分花在可被复制的那一半。**
