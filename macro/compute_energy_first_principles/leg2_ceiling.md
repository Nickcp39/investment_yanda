# 腿二 · 经济天花板 —— 算力支出的上限在哪

**恒等式：**
```
算力总支出  ≤  它做掉的那部分工作的价值
```

这一腿的作用是**给所有指数外推装一个上限**——Aschenbrenner 那篇 165 页全文**没有这个上限**。

---

## 1. 天花板的量级

| | 金额 |
|---|---:|
| 全球 GDP | ~**$115 万亿** |
| 劳动报酬（约 53%） | ~**$61 万亿** |
| **其中知识/白领工作（约 40%）** | ~**$24 万亿** ← **理论天花板** |

**⇒ AI 能替代的工作，其全部价值的上限大约是 $24 万亿/年。**

**但这是"替代 100% 且价值全部归 AI 供应商"的荒谬上限。现实的刻度：**

| 情景 | 年收入上限 |
|---|---:|
| 替代知识工作的 **20%** | **$4.9 万亿** |
| 替代 **10%** | **$2.4 万亿** |

---

## 2. 🔴 把现在的支出放进这个刻度

| | |
|---|---:|
| 四大厂 2026 capex | **$7,200 亿/年** |
| 占"替代 10%"情景年收入上限的比例 | **30%** |

> ## **也就是说：在 AI 收入还没出现之前，光是四家公司一年的资本开支，
> ## 已经相当于"AI 替代掉 10% 全球知识工作"这个成熟态年收入的三成。**

**而且 capex 是流量，不是存量——它每年都要花。**

⚠️ 这个对比不能直接当成"过剩"的证明（capex 建的是多年期资产，收入是永续流量），
**但它足以说明一件事：现在的建设速率，隐含的是"AI 会很快替代远超 10% 的知识工作"。**

---

## 3. 另一个刻度：电力占比

| | |
|---|---:|
| 全球总发电 | ~**30,000 TWh** |
| 2030 数据中心（IEA） | **945 TWh** |
| **占全球** | **3.1%** |

> **全球看只有 3%，一点都不吓人。**
> **吓人的是集中度** —— 它挤在少数几个电网节点上，而并网排队要 5–12 年（腿三）。
>
> **⇒ "AI 会耗尽全球电力"是错的。正确的说法是"AI 会挤爆几个特定的电网接入点"。**
> **这两句话导向完全不同的投资结论：前者指向发电，后者指向并网权与既有资产。**

---

## 4. Jevons：为什么"降价"不必然降低总支出

已实测的推理成本崩塌（见本库 2026-09 会话记录）：

| | |
|---|---|
| 固定能力单价三年 | **~1,000×** 下降 |
| Epoch AI 测算 | 2024 年起中位数 **每年 200×** |
| 前瞻 | 2027 前 3–5×/年，之后 1.5–2×/年 |

**但同期 token 消耗量在暴涨**：agent、长推理链、长上下文，单任务的 token 量比 2023 年的一次对话高 2–3 个数量级。

```
单价 ↓ 1000×   ×   每任务 token ↑ 100–1000×   ×   任务数 ↑   ×   用户数 ↑
```

> **⇒ 总支出可升可降，取决于四项的乘积。这正是 Jevons 悖论的标准形态。**
> **历史上照明、钢铁、交通都验证过：效率提升导致总消耗上升，而不是下降。**

**本腿因此不给"总支出会涨还是会降"的结论——给的是那个上限：$2.4–4.9 万亿/年。**

---

## 5. 🔴 一个必须记下的时序问题

**天花板是成熟态的，capex 是现在的。两者之间隔着采纳曲线。**

历史上通用技术（电力、计算机、互联网）的采纳曲线都是 **S 形，且比乐观者预期慢**：
- 电力：1880 年代商业化，到 1920 年代才真正改造工厂生产率（Paul David 的经典研究）
- 计算机：Solow 悖论 —— "到处都看得到计算机，就是生产率统计里看不到"

> **⇒ 本腿最大的风险不是天花板太低，是到达天花板的时间比 capex 的折旧周期长。**
> **GPU 折旧 3–5 年（NBIS 已从 4 年延到 5 年）。如果采纳曲线是 10–15 年，
> 那么第一轮建的东西会在收入成熟之前就报废。**

**这一条把腿二和腿四的光纤样本直接连上了：光纤的问题从来不是"互联网没起来"，
是"光纤在互联网起来之前就铺完了，而它的经济寿命等不到那一天"。**

## 6. 本腿的 OPEN

- **L2-1**：知识工作可替代比例的实证估计（不是调研问卷，是已发生的替代率）
- **L2-2**：AI 收入的实际口径 —— 全球 AI 相关软件/服务年收入现在到底是多少
- **L2-3**：采纳曲线的斜率 —— 对照电力（约 40 年）与互联网（约 20 年）
- **L2-4**：**GPU/数据中心的真实经济寿命 vs 采纳曲线长度**（本腿最关键的一条）
