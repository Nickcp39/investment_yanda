## 0. 唯一的一条硬规则

```
下单前先填 §2 的 order ticket。
「触发条款」一栏写不出来 → 不下单。
```

这一栏是整个文件的全部意义。**它不靠意志力，靠一个必填字段。**

合法的条款只有这些（出自 `single_name_discipline.md`）：

| 代码 | 含义 |
|---|---|
| `BUY` | verdict ≥ STARTER **且** 价格 ≤ buy-below 带 **且** 完整度未封顶 |
| `S1` | monitor 变量 2 项转 🔴 |
| `S2` | 价格 ≥ Trim / no-chase zone |
| `S3` | 机会成本（需 `trading_plan_2026_2030.md`，**未写**） |
| `TAX` | 税务收割（仅 BTC，见 `tax_residency_exit_plan.md` §4） |

**填不进上表 = 违约。** 违约不是禁止，是必须走 72 小时冷静 + 写进 §4 记录。

**归因的四象限**（这才是专业和业余的分界）：

| | thesis 对 | thesis 错 |
|---|---|---|
| **赚钱** | ✅ 可复制 | ⚠️ **运气 —— 最危险，会强化错误流程** |
| **亏钱** | ⚠️ 可接受（概率的代价） | ❌ 要改流程 |

> **右上角那格是最需要警惕的。** 因为 thesis 错了还赚钱，会让你误以为当时的做法是对的，
> 下次照做就会亏。**只看盈亏，永远学不会投资。**
