> **这份文件只管一件事：什么时候卖 BTC 才不用交税。**

## 0. 一句话总纲

> 2026 / 2027 一股不卖（美国税务居民）；2028 起转为非居民外国人；
> **在 2029 顶部窗口卖出**——那一年既是模型顶部，也是完整的非居民年度，
> 美国联邦 + 纽约州税双零。

## 1. 前提事实（变了要重审全文）

| 项 | 值 |
|---|---|
| 身份 | 非移民签证，**无绿卡** |
| 报税州 | 纽约 |
| 工资 | ~$30,000/年 |
| 持仓 | **Robinhood Crypto 的真 BTC**（非 ETF），**普通应税账户**，非 IRA |
| 持仓税务定性 | **property，不是 security** → **wash sale (§1091) 不适用** |
| 预计持仓 | ~1.5 BTC 等值，成本基础 ~$70,000 |
| 预计卖出价 | BTC ~$200,000 → 利得 ~$230,000 |
| 税务居民年份 | 2026 ✅ / 2027 ✅（预计）/ **2028 起 ❌** |

**关键结论：没有绿卡 = §877A 退出税完全不适用。** 无需 Form 8854、无 covered
expatriate 判定、无视同出售、无净资产门槛。人走 + 天数不够 = 自动脱离居民身份。

## 2. 时间轴（核心表）

| 年份 | 税务身份 | 能否卖 | 理由 |
|---|---|---|---|
| 2026 | 税务居民 | ❌ **不卖** | 按居民征：联邦 15% + NIIT 3.8% + NY 最高 6.85%（+NYC 3.876%） |
| 2027 | 税务居民（很可能是**离境的 dual-status year**） | ❌ **绝对不卖** | 最危险的一年，见 §3 |
| 2028 | 非居民外国人 | ⚠️ 可以但没必要 | 免税成立，但 BTC 大概率未到顶 |
| **2029** | **非居民（完整年度）** | ✅ **在此卖出** | 模型顶部窗口 + 零税，两者同时拿到 |

**为什么 2029 是答案**：`trading_plan` 的顶部窗口是 2029-08 开启，而 2029 是
离境后的第二个完整非居民年度——顶部择时和税务最优在同一年重合，不用二选一。

### 免税的法律依据

- **联邦 $0**：非居民外国人的资本利得，美国原则上不征税（§871）。
  加密资产按 property 处理，动产处置所得按**卖方居住地**定源（§865）→
  人在境外卖 = 外国来源。BTC 不属于 USRPI，FIRPTA 不适用。
- **纽约 $0**：纽约对非居民只征 NY 来源所得；无形资产处置利得对非居民而言
  不算 NY 来源。
- **两种持仓形态结论相同**：无论真 BTC 还是 BTC ETF，NRA 卖出均不被美国征税；
  §871(a)(2) 的 183 天规则也是两者通吃。**持仓形态只影响 wash sale（见 §4），
  不影响本计划的时间轴与铁律。**

## 3. 两条铁律（违反任何一条，$0 变 $46,000～$69,000）

### 🔴 铁律一：2026 和 2027 一股不卖

尤其 2027。若那是实际离境年份，属 **dual-status year**：

- 离境前的处置 → 按居民征税
- 更致命的是 **§871(a)(2)**：即使离境后才卖，只要**当年在美停留满 183 天**，
  资本利得按 **30% 单一税率**征 → $230,000 × 30% = **$69,000**，比当居民卖还惨

**2027 年的规则最简单：不管什么时候走、走没走，那年就是不卖。**

### 🟡 铁律二：离境后盯住回美天数

实质存在测试（SPT）是加权的：

```
当年天数 + 前一年 ÷ 3 + 前两年 ÷ 6 ≥ 183  →  重新变成税务居民
```

稳态下每年回美 **≥122 天就会被拉回居民身份**。

- **安全线：每年在美 < 100 天**（留缓冲）
- **卖出当年（2029）额外守：当年在美 < 183 天**，避开 §871(a)(2)

#### 回美天数追踪表（每次入境后填）

| 年份 | 在美天数 | 加权值（当年 + 前1年/3 + 前2年/6） | 是否 < 183 | 备注 |
|---|---:|---:|---|---|
| 2026 | | | | 居民年，不适用 |
| 2027 | | | | 居民年（预计），不适用 |
| 2028 | | | | |
| 2029 | | | | **卖出年，必须 < 183** |

## 4. 收割类方案的判定（**别再重新讨论，理由在此**）

### ⚠️ 亏损收割（tax loss harvesting）—— **条件性推荐，待两个前提确认**

> **2026-08-05 修订**：本节原判定为"不做"，理由之一是 ETF 适用 wash sale。
> 经核实持仓为 **Robinhood Crypto 的真 BTC（property，非 security）**，
> **wash sale 不适用**，可卖出后立即买回。判定随之改变。

**不要为了"明年多退税"做——那部分很小：**

| 年份 | 可用抵扣 | 价值 |
|---|---|---:|
| 2026（有 $30k 工资） | $3,000 | **+$525** |
| 2027（若已无美国收入） | $3,000 | **$0**——低于标准扣除，抵扣浪费 |

**真正的理由是：结转亏损是一张对冲"退出计划落空"的免费期权。**

本计划全部建立在"2028 起不再是税务居民"之上。若计划有变，2029 需以纽约居民
身份卖出，税负约 **$46,000**。届时手里的结转能省：

| 结转额 | 联邦 | 纽约 | 合计 |
|---:|---:|---:|---:|
| $30,000 | $5,640 | $1,800 | **$7,440** |
| $60,000 | $11,280 | $3,600 | **$14,880** |

**且这张期权会过期**：BTC 涨向 $200k 时高成本批次转为浮盈，亏损消失。
**现在是唯一一次捕捉窗口。**

**成本**：Robinhood crypto 无佣金但吃点差（单边 ~0.35%）。往返 $80,000 约 **$560**。

```
EV = -$560(点差) + $525(2026抵扣) + p × $14,880
  p=10% -> +$1,453      p=15% -> +$2,197      p=25% -> +$3,685
```

→ **只要"计划有变"的概率 > ~5%，即为正期望。三年期的人生计划，5% 是很低的门槛。**

#### 🔴 执行前必须确认的前提（未确认前不得执行）

1. **Robinhood Crypto 是否支持指定卖出批次（specific ID / HIFO）？**
   - 1.5 BTC 平均成本 ~$46,667，现价 ~$64k，**整体浮盈**；亏损藏在接近顶部买入的高成本批次
   - **若强制 FIFO，会先卖最早最便宜的批次 → 实现盈利而非亏损 → 凭空造出税单，方向完全相反**
   - Robinhood 对股票支持选批次，**对 crypto 历史上是 FIFO 默认**
   - 查法：发起卖单看有无 Tax lot / Cost basis method 选项；或问客服
     "Does Robinhood Crypto support specific identification of tax lots?"
   - **只能 FIFO → 本方案作废，什么都不做**
2. **2027 年是否仍有美国工资收入？**（决定直接收益是 $525 还是 $1,050）

#### 若前提成立，执行细则

1. 选 **HIFO**，只卖成本最高的批次，累计亏损**取到上限**（期权价值与亏损额线性相关，
   不要只做 $30,000）
2. 卖出后**隔一段时间再买回**。wash sale 不适用、当日买回亦合规，但间隔个把小时、
   承担一点真实价格风险，对 economic substance 更稳妥
3. **净 BTC 数量必须回到原位**，不得借机减仓
4. 登记该笔操作（日期 / 数量 / 确认亏损额），并在 BTC 计划 v3 补写税务收割例外条款：
   > **税务收割例外**：允许为确认资本损失而卖出并回补，**净 BTC 数量不得减少**。
   > 须登记，不计入违约记录。任何导致净敞口下降的卖出仍属违约。
5. 报税走 Schedule D / Form 8949；Robinhood 出 1099-B / 1099-DA

### ❌ 获利收割（tax gain harvesting）

**联邦 0% 长期资本利得档在纽约不存在**——纽约对 LTCG 无优惠税率，全按普通
收入征。每年收割 $35,500 利得：联邦 $0，但**纽约多交 $1,952/年**，三年白交
$5,858。而它买到的"联邦免税额"，在最终以 NRA 身份卖出的前提下**本来就是零**。

### ❌ "为了明年退税更多"这个动机本身

退税额 = 预扣 − 应缴。真实变量只有那 $525 的应缴减少。
若目标是提高退税额本身，调 W-4 预扣即可，与卖不卖 BTC 无关。

**§4 的收割若要做，理由必须是"对冲退出计划落空"的期权价值，不是退税。**
动机记错，下次就会在错误的前提下重做一遍决策。

## 5. 从现在到 2029，税务上要做的事

**除下面这一件待确认的事之外，什么都不做。**

- ⏳ **待定**：亏损收割（见 §4）——**先确认 Robinhood 能否指定卖出批次**。
  能 → 做一次，取满亏损额，净 BTC 不减；只能 FIFO → 放弃，不做
- ✅ 继续定投（买入不是应税事件）
- ✅ 离境当年正常报纽约 part-year / final return
- ✅ 不留纽约公寓、不留 domicile 尾巴
      （NY 有 statutory residency：保留永久住所 + 当年在 NY 满 183 天 =
       不论 domicile 均按居民征）
- ✅ 记录回美天数（§3 表格）
- ✅ 2029 顶部窗口卖出

**这与 `btc_investment_plan_2026-07-17_v2.md` 的"建完转长期持有、核心仓一股
不卖、2029 顶部窗口才动"完全一致。原有的纪律设计凑巧就是税务最优解。**

## 6. 唯一未决变量：落地国

美国这边 $0 已锁定。但 $230,000 的利得，**落地国还有一次征税机会**：

| 落地 | 大致后果 |
|---|---:|
| 香港 / 新加坡 / 阿联酋 | **$0** |
| 中国 | 财产转让所得名义 20% ≈ **$46,000**（加密定性仍属灰区，CRS 下在收紧） |

**这是本计划金额最大的未决项。** 不必现在定，但 2028 年前应作为一个正式变量
纳入决策，而不是等到卖之前才想起来。

## 7. 找 CPA 时要问的问题清单

找**做跨境 / expatriation 的 CPA 或税务律师**，不是普通报税会计。

1. 我的实质存在测试在哪一年正式中断？residency termination date 如何确定？
2. 离境年是否需要按 dual-status 报？要不要附 residency termination statement？
3. 纽约的 part-year / final return 怎么报？如何证明 domicile 已切断？
4. 无绿卡是否确认完全不触发 §877A？（预期：是）
5. 卖出年若回美探亲，§871(a)(2) 的 183 天如何计算（含入境当日？过境日？）
6. 落地国与美国是否有税收协定影响该笔利得的征税权归属？
7. 券商（Robinhood）在我转为 NRA 后的申报与预扣如何处理？需提交 W-8BEN 吗？
8. Robinhood Crypto 能否做 specific identification（HIFO）？若只能 FIFO，
   有无其他合规方式指定批次？（决定 §4 收割做不做得成）
9. 卖出后立即回补同一资产，是否有 economic substance 风险？建议间隔多久？

## 8. 重审触发条件

以下任一发生，本文件必须重写：

- 拿到绿卡（→ §877A 判定重新适用，整个逻辑改变）
- 2027/2028 的居民身份判定与预期不符
- 在 2029 年之前需要动用这笔钱（→ 被迫在居民年卖出，需重算税负）
- 落地国确定，且该国对资本利得征税
- 美国税法变动：NRA 资本利得征税规则、183 天规则、或加密资产定性
- 持仓规模或成本基础大幅变化（±30% 以上）
