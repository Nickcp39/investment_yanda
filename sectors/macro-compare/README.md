## 核心结论

1. **普适规律**:凡崩盘 → 老龄化 + 财政承压 → 政府转向**控费**;但总医疗开支**都照涨**(老龄刚需)。六国无一例外。
2. **形式取决于体系类型**(三簇):
   - **① 社会保险 + 快速老龄**(日/韩/**中**):直接砍价格——药价点数(日)、正面清单+降价(韩)、**集采 −52~93%**(中,最狠)+ 长护险补位。
   - **② 税收单一支付**(英/加):没价可砍 → **排队/缺人**配给(英候诊 775 万;加候诊 30 周)。
   - **③ 私营/混合**(美):**反向**——先扩覆盖(ACA 2010)后温和控费(药价谈判仅 10 款)。
3. **中国属①簇 → 日本/韩国是最准的镜子**。中国已复现其节点:2016 医保并轨(↔韩 2000 NHIS 整合)、2018+ 集采(↔韩 2006-07 正面清单/日药价)、2016 长护险试点(↔日 2000/韩 2008)。
4. **三面镜子的教训**:
   - 日/韩(主路径):控费→长护险→创新药械**被逼出海**(武田/安斯泰来海外占比 60–90%)。**= Nick 出海主线的历史依据**。
   - 加拿大(看对扳机):真正决定紧缩的是**支付方财政**,不是房价本身——**盯医保基金结余率 + 地方债**,不只看地产。
   - 英国(最脆弱环节):老龄化下**长期照护最先爆缺口**;中国长护险未全国铺开=最像英国短板处。

## 中国下一步(大概率,读自日/韩)

长护险全国强制(↔日 2000/韩 2008)· DRG/DIP 常态化(↔日 DPC/韩正面清单)· 集采持续扩面 · **创新药械出海成主战略** · 供给端(医生/药企)剧烈反弹(↔韩 2000 医生罢工 / 中 2023 医疗反腐)。
