# UBER — M2 主题 / 机制

| 项 | 内容 |
|---|---|
| Theme | 出行 + 外卖的需求聚合平台；自动驾驶（AV）到来时，**谁拥有乘客** |
| Why now | 股价距高点 −31%，而生意在加速（GB cc +22%、Non-GAAP EPS +35%、TTM FCF 首次 >$10B）。**价格与基本面反向** |
| 市场叙事 | Robotaxi 会绕过 Uber：Waymo 2028 起在两城直营，Tesla Cybercab 9/8 上线；Uber 被迫花 >$10B 买 AV 入场券 |
| 市场可能高估的 | AV 规模化的速度与地域广度（BofA 估 2029 年美国 >10 万辆 AV —— 对 Uber 208M 月活、全球 70+ 国的盘子，是局部而非全局） |
| 市场可能低估的 | ① 外卖（GB 占 47%）几乎不受 robotaxi 影响；② AV 车队的利用率取决于需求密度，而需求密度正是 Uber 的资产；③ 公司在**缩股**（−2.6%/年）且 CEO/COO 用自己的钱在 $71–76 买入 |
| 资金流证据 | 公司 H1 回购 $3.53B；CEO $10.0M + COO $5.3M 公开市场买入（Form 4） |
| 稀缺资源 / 瓶颈 | **需求密度**（同一城市里足够多的乘客与订单，让空驶率低）——这是车队所有者买不到、只能租的 |
| 谁付钱 | 乘客与食客（GB $58B/季），平台抽成 → 分部利润/GB：Mobility 7.6%、Delivery 3.8% |
| 价值单位 | 每单分部利润；成本单位：司机/车辆成本（AV 后变为车队折旧 + 运维） |
| 利润池 | 撮合费。AV 后利润池在「车队」与「需求入口」之间重新分配 —— **本卡的核心不确定** |
| 为什么是它 | 最大的跨品类需求入口（出行+外卖+货运共用一个账户与支付） |
| 迫使市场更新的一个指标 | **Mobility GB 增速（cc）**：若在 Waymo/Tesla 扩张城市仍 ≥15%，"绕过"叙事被证伪；若连续两季 <10%，被证实 |
| 催化剂 | Q3 2026 财报（约 11 月初）；Waymo 合同续约/到期消息；AV 合作城市的单量披露 |
| Kill condition | 见 `inversion_trap_test.md` K-U1 |
| **context_label** | **`structural_decline_trap` 测试框**（M3/M4/M5 主导；典型错误 = 把低倍数当安全边际）。结论：**测试未证实为结构性衰退**，但未排除 |

**M2 信号：0** —— 主题两面都成立：AV 可能缩小 Uber 的利润池，也可能扩大（更低的单位成本 → 更多出行）。本模块不给方向。
