## 3. (a) 三条口径的分叉——为什么 GAAP 利润 ≠ 现金

同一段 TTM，三个"盈利"数字：

| 口径 | $M | 相对营收 |
|---|---:|---:|
| 经营利润（GAAP） | 14,354.5 | 29.7% |
| 净利（GAAP，**含 $2.8B 一次性**） | 13,649.6 | 28.2% |
| 净利（GAAP，**剔一次性税前 $2.8B**） | ~10,850 | 22.4% |
| **报告 FCF（含一次性）** | **11,152.0** | 23.1% |
| **报告 FCF（剔一次性税前 $2.8B）** | **8,352.0** | **17.3%** |

**桥（TTM，从经营利润走到剔一次性 FCF）：**

```
经营利润 GAAP                        +14,354.5
+ 内容摊销（非现金费用加回）          +17,296.2
− 内容现金支出（真实现金流出）        −19,485.5   ← 缺口 −2,189.4
+ PP&E D&A                            +   372.4
− PP&E capex                          −   818.8
− 利息（现金）                        −   ~740
− 现金税、营运资本、其他非现金净额      −   ~2,827（倒挤）
= FCF 剔一次性                          ≈ 8,352
```

**结论（(a) 的答案）：报告 FCF 不是被会计"美化"或"惩罚"的失真数字——它是干净的。
被扭曲的是 GAAP 经营利润率。** 因为：

1. 内容资本化只影响**损益表**（用慢变量"摊销"替代快变量"现金支出"），**不影响 FCF**
   （现金支出全额已在 OCF 内）。
2. 因此当现金支出增速 > 摊销增速时，**GAAP 利润率被系统性抬高，而 FCF 如实反映现金**。
3. H1'26：现金支出 **+32.3%**，摊销 **+11.4%** ⇒ 经营利润率创纪录 33.4%，
   而 Q2'26 FCF **同比 −32.7%**。**同一个季度，两个方向。**
4. 反向证明：FY2023 罢工年现金支出被迫压到摊销的 **0.884x**，当年 FCF $6,926M 相对当时的
   盈利能力是**被美化**的——这是 Netflix 唯一一次 FCF 明显优于经济现实的年份。

⇒ **锚必须用现金口径（FCF），不能用 GAAP 净利。** 但 FCF 有两个污染源必须剔除：
(i) $2.8B WBD 终止费；(ii) 内容支出的**增长部分 vs 维护部分**无法拆分（公司从未披露）。
后者是本 dossier 最大的 OPEN。

## 4. 内容现金/摊销比的历史（判断 1.1x 是不是"新常态"）

| 期间 | 比率 | 背景 |
|---|---:|---|
| FY2023 | **0.884x** | WGA/SAG-AFTRA 罢工，被迫少花 |
| FY2024 | 1.060x | 补库存 |
| FY2025 | 1.041x | |
| H1'26 | **1.146x** | 直播/体育/NFL 扩张 + 补罢工缺口 |
| TTM Jun-26 | **1.127x** | |
| **FY2026 指引** | **~1.1x** | 公司明说 |

> 十年恒等式：**内容现金支出与内容摊销在长周期里必然收敛**（进去的最终要摊完）。
> 所以 1.1x 只有两种解释：(i) 内容库在**真实扩张**（增长性支出，未来会转成营收）——bull；
> (ii) 维持同样的参与度需要**越来越贵的内容**（跑步机，维护性支出上升）——bear。
> **H1'26 观看小时只 +2%，是偏向 (ii) 的证据，但不是决定性的**（价格/广告在涨，
> 而公司明说"not all hours are equal"、直播占 5% 支出只换 1% 小时但换来拉新）。

## 5. (c) 回撤分解——倍数 vs 盈利

**两个时点：**

| | 2025-06-30（ATH 收盘） | 2026-08-06（as_of） |
|---|---:|---:|
| 股价（拆股调整后） | **$133.91** | **$73.69** |
| 流通股数（M） | ~4,252（Q2'25 加权基本股） | **4,163.94**（10-Q 封面页） |
| 市值 | ~$569.4B | **$306.8B** |
| TTM FCF（干净，剔一次性） | **$8,500.7M**（Q3'24–Q2'25，无一次性） | **$8,352.0M**（Q3'25–Q2'26 剔 $2.8B） |
| **TTM FCF / 股** | **$1.999** | **$2.006** |
| **P / TTM FCF** | **67.0x** | **36.7x** |

（起点 TTM FCF 算式：FY2024 FCF 6,921.8 − H1'24 FCF 3,349.4 + H1'25 FCF 4,928.3 = **8,500.7**）

**分解恒等式：** 股价变化 = 每股 owner earnings 变化 × 倍数变化

```
每股 FCF:   $1.999 → $2.006   =  +0.3%
倍数 P/FCF:  67.0x → 36.7x    = −45.2%
乘积:        1.003 × 0.548    =  0.5497   →  −45.0%
实际股价:    133.91 → 73.69   =  −45.0%   ✓ 完全对上
```

> **结论：45% 的回撤里，约 100% 是倍数压缩，0% 是每股 owner earnings 下降。**
> 但这不等于"市场错了"。**真正的失望是二阶的**：营收 TTM 从 $41.69B 涨到 $48.37B（+16.0%），
> 每股营收 +18%，而**每股 owner earnings 一年零增长**。市场不是在为盈利下滑杀估值，
> 是在为**"增长不再转化为现金"**杀估值——把 67x 这种"高增长高转化"倍数
> 降到 36.7x 这种"高增长低转化"倍数。

**交叉验证（GAAP 口径也对得上）：**
起点 TTM 稀释 EPS ≈ (8,711.6 − 4,479.5 + 6,015.8)/4,360 = $2.35 → P/E **57.0x**
终点 TTM 稀释 EPS 剔一次性 ≈ (13,649.6 − 2,282)/4,290 = **$2.65** → P/E **27.8x**
EPS **+12.8%** × 倍数 **−51.2%** = 1.128 × 0.488 = 0.550 → **−45.0%** ✓

⇒ 两套口径都给同一个答案：**盈利没塌（GAAP +13%，现金持平），全部是 de-rating。**

## 6. (c) 回撤的时间分解——哪几天跌掉的

**财报反应日（次日收盘对前一日收盘）：**

| 财报 | 发布日 | 反应日 | 前收 → 收 | 单日 |
|---|---|---|---:|---:|
| Q2'25 | 2025-07-17 | 2025-07-18 | 127.42 → 120.92 | **−5.10%** |
| Q3'25 | 2025-10-21 | 2025-10-22 | 124.14 → 111.64 | **−10.07%** |
| Q4'25 | 2026-01-20 | 2026-01-21 | 87.26 → 85.36 | **−2.18%** |
| Q1'26 | 2026-04-16 | 2026-04-17 | 107.79 → 97.31 | **−9.72%** |
| Q2'26 | 2026-07-16 | 2026-07-17 | 74.35 → 68.95 | **−7.26%** |

五个财报日复合：0.9490 × 0.8993 × 0.9782 × 0.9028 × 0.9274 = 0.6990 ⇒ **−30.1%**
总回撤 −45.0% ⇒ 财报日之外的漂移 = 0.5497 / 0.6990 = 0.7865 ⇒ **−21.4%**

⇒ **约 2/3 的回撤（−30.1%）发生在 5 个财报反应日**——这是"每次公布都比预期差一点"的
典型 de-rating 形态，不是单一事件冲击。剩下 −21.4% 是区间内的持续下移（含 WBD 悬顶）。
