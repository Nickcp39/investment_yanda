# AB — M4 财务现实

## 1. 分配是真现金吗
| 检验 | 结果 |
|---|---|
| 分配 vs 收益 | 每单位分配 = 每单位调整后收益（Q2 均为 $0.82），**派息率 100% 是合同机制，不是管理层选择** |
| Holding 层资产负债表 | 总资产 $1.246B ≈ 对 AB LP 的权益法投资 $1.246B（XBRL）；**无债务** |
| AB LP 利润率 | 调整后营业利润率 33.0%（+70bp YoY），Nashville 迁址等结构性降本已在账上 |
| 收入质量 | 基础费 $860.3M/季为主；业绩费 $46.6M（5%），Q4 季节性偏高 → base 情景把 TTM $3.47 下调到 $3.40 |
| 费率 | 40.3bp，年降 1.9bp —— **收入增速 = AUM 增速 − 约 5pp** |

## 2. 周期位置
分配对市场水位高度敏感：按支付年，2023 年 $2.62（2022 熊市的回声）→ 2025 年 $3.47（+32%）。
**当前在周期高位附近**（AUM 新高、标普 Q2 总回报 +15.2%）。bear 情景（分配回落至 $3.00 并持平 10 年）正是按此设定。

## 3. 倍数 vs 基数
12 个月单位价 −5.6%（$37.90 → $35.76）；同期季度分配 Q2'25 $0.76 → Q2'26 $0.82（+7.9%，均为 8-K 一手）。
```
价格 −5.6%  ≈  倍数 −12.6%（价格 / 年化季度分配 12.5x → 10.9x）  ×  基数 +7.9%
```
跌的是倍数：市场把更高的分配按更高的风险折现（主动流出 + 私募信贷新闻）。

**M4 信号：+1** —— 现金流机制干净、无杠杆、利润率稳；扣分项是分配的周期性与费率下行。
