# AB — M2 主题 / 机制

| 项 | 内容 |
|---|---|
| Theme | 资管行业的"杠铃"：被动与私募/财富管理在长，主动公募在缩。AB 是**主动管理人向杠铃两端迁移**的样本 |
| Why now | 单位价格贴近 52 周低点（+2.4%），分配率 9.7%；而 AUM 创新高（$919B）、Q2 重回净流入 |
| 市场叙事 | ① 主动股票持续流出；② 2026 年私募信贷负面新闻；③ 被 Equitable 控制、流动性差、K-1 麻烦 |
| 市场可能高估的 | 私募信贷冲击：10-Q 无减值/gating 披露，另类/多资产**连续 6 季净流入** |
| 市场可能低估的 | 分配 = 收益的机械关系：只要 AUM 不大跌，现金就按季到手；市政债 SMA 与私人财富是粘性业务 |
| 资金流证据 | Q2 净流入 +$0.8B（此前四季净流出）；机构管线 $25.8B |
| 稀缺资源 | 超高净值客户关系（Bernstein Private Wealth）、市政债管理规模、Equitable 保险总账户的**被捕获资金** |
| 谁付钱 | 基金持有人与机构客户，按 AUM 收费（~40bp，且在降） |
| 价值单位 / 成本单位 | 费率 × AUM / 人力（薪酬占净收入约一半，未逐项取数） |
| 利润池 | 资管费；**利润池规模主要由市场水位决定**，不是由 AB 自己决定 |
| 迫使市场更新的一个指标 | **季度分配**：连续两季 ≥$0.85 → 9.7% 收益率被证明可持续；跌破 $0.75 → 市场的担心被证实 |
| 催化剂 | Q3 财报（约 10 月底）；月度 AUM（每月约 10 日） |
| **context_label** | **`yield_or_balance_sheet_trap` 测试框**（M4/M5/M6 主导；典型错误 = 忽视分配脆弱性）。结论：**Holding 层无杠杆，分配由收益机械决定，测试通过**；风险在市场 beta，不在资产负债表 |

**M2 信号：0** —— 没有顺风主题；它是一台跟着市场水位出现金的机器。本模块不加分也不扣分。
