# H2 · Financial Quality — IREN

## 三个必须拆开看的地方

### 1. adj EBITDA 在这门生意里是误导性指标
```
Q3 FY26:  adj EBITDA  +$59.5M
          GAAP 净亏损 -$247.8M
          差额         ~$307M
```
差额主要是折旧 / 减值 / SBC。
**但这些不是"非现金所以不重要"** —— ASIC 和 GPU 是真在损耗，
而且 IREN 正在**主动淘汰矿机**（decommissioning）。
**折旧在这里是真实的经济成本，adj EBITDA 系统性高估盈利能力。**

### 2. 净利润被 BTC 公允价值重估污染
Q1 FY26 净利 **+$384.6M**，Q2 **−$155.4M**，Q3 **−$247.8M**。
如此剧烈的摆动不可能来自经营。
**⚠️ OPEN：Q1 那 $384.6M 里 BTC 重估占多少，未拆开前净利润不可读。**
（与 NBIS 卡 C008 的 ClickHouse 重估是同一类陷阱）

### 3. 营收下滑的构成
```
Q1 $240.3M → Q2 $184.7M → Q3 $144.8M   (−40%)
其中 Q3: BTC $111.2M (−33% YoY) + AI $33.6M (+833% QoQ)
```
**下滑是主动的**（算力从挖矿转 AI），但**替代速度不够快**。
这是 J 曲线，问题在于**谷底有多深、多长**。

## 现金流质量
- Q3 adj EBITDA +$59.5M，但**资本开支远超**（480MW/150k GPU 的建设）
- **经营现金流不足以自筹扩张** → 全靠资本市场
- **这是本案最重要的财务事实**：生意的增长不由生意的现金流驱动
