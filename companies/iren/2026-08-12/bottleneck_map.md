# H4 · Bottleneck / Chokepoint — IREN

## 结论：瓶颈不是电，是"电 → AI-ready"的转化工程

### 证据链
1. IREN 手握 **~3GW 已电网连接**，2026 只做到 **480MW = 16%**
2. 在建清单里明写"**改造 250MW 存量风冷**"——不是新建，是**改造**
3. 转型期营收 **连续两季下滑 −40%**，Q3 miss 34%
4. AI Cloud 只占营收 **23%**

**若"有电就能转 AI"，以上四条都不会发生。**

## 转化链的每一环及其卡点

```
土地 ✅ 有  →  电网接入 ✅ 有(3GW)  →  ⛔【液冷/冗余/光纤/机架密度改造】
  →  ⛔【GPU 到货与调试】  →  ⛔【SLA 级运维能力】  →  客户验收付款
```

| 环节 | 卡点强度 | 说明 |
|---|---|---|
| 土地 / 电网接入 | 🟢 已解决 | **IREN 的真实优势** |
| **机房改造（风冷→液冷）** | 🔴 **主卡点** | 重资本、长周期。Childress 250MW 改造是当前主战场 |
| GPU 供应 | 🟡 | NVIDIA 合作缓解，但 NVIDIA $0.7B 那批是**风冷 Blackwell** ← 暗示改造进度受限 |
| **运维 / 软件层** | 🟡 | 矿工不会做企业级 SLA。**Mirantis 收购正是买这个能力** |
| 资本 | 🔴 **共同主卡点** | 缺口 ~$21.1B = 市值 1.5× |

## 对 NBIS 的反向读数
NBIS 说瓶颈是"变压器和燃气发电机"（长交期设备）。
IREN 证明**即使跳过这一段（已有电网接入），后面还有一整条改造链**。

→ **NBIS 的护城河期限比"并网排队周期"长，但比"永久"短。**
→ 应回填 NBIS `bottleneck_map.md`：把瓶颈从"电"改为"电→AI-ready 的转化工程与资本"。
