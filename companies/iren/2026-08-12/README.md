# IREN — 2026-08-12（新标的开题）

**为什么跑**：IREN 是 NBIS 卡上「供给响应」变量的活答案——BTC 矿工转 AI 云，
手握 ~3GW 已电网连接电力，正是 NBIS 说的稀缺资源。

## 先读

**`cross_read_nbis.md`** ← 本次首要产出

## 一句话结论

**真正稀缺的不是「电」，是「把电变成 AI-ready 机房」的工程与时间。**
IREN 手握 3GW 却只在 2026 做到 480MW（16%），且转型期营收连续两季下滑
（$240.3M → $184.7M → $144.8M，累计 −40%，Q3 miss 34%）。

→ 这**同时削弱** NBIS 的 bear 论点（"供给随时涌入"）**和** bull 论点
（"电力是硬瓶颈"）。修正后的瓶颈定义要写回 NBIS 的 `bottleneck_map.md`。

## ⚠️ 两个必须解决的发现

1. **单 MW 定价差 2.4–5.4 倍**：NBIS 新签 $40–50M/MW vs IREN $8.33M/MW。
   **数量级差距，不解释清楚两边估值叙事都站不住。**
2. **MSFT 双重敞口**：它同时是两家最大客户。同时持有 ≠ 分散。
