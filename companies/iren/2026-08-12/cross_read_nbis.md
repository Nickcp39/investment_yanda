## 2. LEAD 问题的答案（初步）

> **已电网连接的存量电力，能不能快速变成 AI-ready 产能？**

**初步答案：能，但慢且贵——所以"随时能转"这个 bear 论点是错的。**

证据（I010）：IREN 的在建清单里，Childress 一项就是
**「改造 250MW 存量风冷容量」** ＋ 新建 100MW **液冷**。

**BTC 矿场的电 ≠ AI 数据中心的电。** 缺的是：
液冷、供电冗余（矿机可以断电，训练任务不行）、
低时延光纤、SLA 级运维、机架密度与承重。
**这些是重资本改造工程，不是配置变更。**

而 IREN 连续两季营收下滑（$240.3M → $184.7M → $144.8M，累计 −40%）
正是这个改造期的财务表现：**挖矿收入先掉，AI 收入后补，中间是 J 曲线的谷。**

### 对 NBIS 卡的两条修正

| 对象 | 修正 |
|---|---|
| **bear 论点**（"矿工有几 GW 存量电，供给随时涌入"） | ⬇️ **削弱**。IREN 手握 3GW 却只能在 2026 做到 480MW（**16%**），且转型期营收腰斩 |
| **bull 论点**（"电力是硬瓶颈，NBIS 先发不可复制"） | ⬇️ **也削弱**。3GW 存量说明**电本身没那么稀缺** |
| **修正后的 bottleneck** | **不是电，是"电 → AI-ready 机房"的转化工程与时间。** NBIS 的 `bottleneck_map.md` 应据此细化：护城河的期限 = 同业改造周期，不是并网排队周期 |

## 3. ⭐⭐ 未解冲突：单 MW 定价差 2.4–5.4 倍（I015）

```
NBIS  成交均值 >$20M/MW ；新签 $40–50M/MW
IREN  480MW / $4B ARR   = $8.33M/MW
      480MW / $3.1B 已签 = $6.46M/MW
```

**这不是小数点问题，是数量级问题。必须解释，否则两边的估值叙事都站不住。**

### 候选解释（需证据判定）

| # | 假设 | 判定需要什么 |
|---|---|---|
| a | **口径不同**：IREN 的 480MW 是**总容量**，$4B ARR 只对应**已部署**部分 | IREN 的 ARR/已通电 MW 分子分母对齐 |
| b | **GPU 代际**：NBIS 上 GB300/Vera Rubin（液冷、高密度）；IREN 有大量**风冷 Blackwell**（I006 明写 NVIDIA $0.7B 是风冷） | 两家的机架功率密度与 GPU 型号构成 |
| c | **合同结构**：NBIS 的"$/MW"可能含 take-or-pay 预付，IREN 是纯 ARR | 合同条款 |
| d | **其中一方数字有问题**（含二手源转述失真） | **一手源**——两边都还没取到 |
