# NVO — 财务现实（M4）

## 1. 表面在恶化，账上在改善 —— 两件事同时为真

| | 值 | 读法 |
|---|---:|---|
| 销售（固定汇率） | **+3%** | 差 |
| **调整后销售** | **+7% CER** | 一般 |
| **调整后经营利润** | **+11% CER** | **好 —— 利润增速 > 销售增速** |
| 美国 Wegovy 针剂 | **−22% CER** | **很差，且在加速** |
| FY26 指引 | **0% ~ −6%**（自 −5%~−13% **上调**） | **在变好** |

> **利润增速快于销售增速，说明成本端真实改善。**
> **指引被上调，说明二月的恐慌定价过头了。**
> **⇒ "NVO 完蛋了"这个叙事，账上不支持。它支持的是"NVO 增长没了"。**

## 2. 估值：这才是重点
| | **NVO** | **LLY** |
|---|---:|---:|
| P/E | **11.45（TTM）** | **~31.6（fwd）/ 38.6（TTM）** |
| P/S | **4.28x** | **11.91x** |
| 市值 | **$206.8B** | **$1,024B** |
| | | **LLY = NVO 的 4.95 倍** |

**P/E 11.45 被称为较历史均值低 55%。**

## 3. 三锚 owner earnings（TTM 净利润 ≈ 市值 ÷ P/E）
| 锚 | OE | 市值/OE |
|---|---:|---:|
| A 公司/市场口径（TTM 净利） | **~$18.1B**（derived: 206.77/11.45） | **11.45x** |
| B 若净利率降到 30%（降价后） | ~$14.5B | 14.3x |
| **C 若净利率降到 25%（价格战全面传导）** | **~$12.1B** | **17.1x** |

> **即使假设降价把净利率从 37% 打到 25%，NVO 也只有 17.1 倍。**
> **对照 LLY 的 31.6 倍 —— 而 LLY 的净利率假设是"维持 32%"。**
>
> ### 这是本卡最锋利的一句
> **市场给赢家 31.6 倍并假设它不降价；给输家 11.45 倍并假设它一直降价。
> 而降价是同一个人（NVO）宣布的，它对两家的成本结构影响是对称的。**

## 4. 缺口
GAAP 口径全缺（O-N3）；分产品分地区只有一个数（O-N2）；股数/股息序列缺（O-N4）；
**净价阶梯（O-N1）与 LLY 的 O-L3 是同一个缺口 —— 补一次，两张卡同时受益。**

## M4 打分：**0**
正面：利润增速 > 销售增速、指引上调、估值极低、三锚温和。
