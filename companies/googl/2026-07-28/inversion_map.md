## 0. 一句话（更新）

6/19 最致命路径 = **F1×F3 合流**（AI 侵蚀搜索变现 + capex 军备竞赛 → 收入增而 owner earnings 永久稀释）。**Q2-2026 把这条合流路径拆成两半**：**F3（capex 黑洞）兑现了**（FCF 转负、指引上调），但**F1（搜索侵蚀）被证伪**（Search +17%、AI 增益查询），**F2（监管结构性救济）缓和**。永久减值需要搜索那条腿，而它在走强 → 这是一个**被 7/28 regime 加剧的 capex/估值陷阱，不是特许经营死亡螺旋**。故 M5 = **−1（haircut/size driver，非 veto）**。

## 2. 7/28 Regime 如何具体打到 GOOGL

| Regime 因子 | 对 GOOGL 的传导 | 净方向 |
|---|---|---|
| **半导体暴跌**（SOX −25%、SK 海力士腰斩、KOSPI 第 8 次熔断） | GOOGL **非**存储/韩国/卖芯片股。作为 AI 硬件**买方**，若崩盘持续压低 GPU/HBM/内存价，其 $195–205B capex **单位算力成本或下降**（略利好） | 基本面**中性偏正**；情绪面偏负 |
| **轮动：撤 AI-硬件 → 进价值/防御 + 苹果 $5T** | GOOGL 被贴"AI-capex 重仓"标签 → 多重压力；但它也在向"价值/现金流/股息"桶靠（刚派息 $0.22）——两面拉扯。负 FCF 削弱其"防御性现金流"吸引力 | 多重压缩**略负** |
| **AI-capex 审计年** | GOOGL 是这条命题的 **Exhibit A**；Q2 给了最差读数（FCF 转负 + 指引上调）→ 市场对其 capex **更不宽容**，−7% 财报反应即审计在起作用 | **强化 M6/M4 卡点** 🔴 |
| **CXMT（长鑫）+466% IPO，新 DRAM 供给打"稀缺溢价"** | 冲击的是**存储/AI 硬件卖方**；GOOGL 是买方 → 直接 P&L 无损，甚至受益于内存降价 | **中性偏正** |
| **FOMC 周三（Warsh 记者会）** | GOOGL 长久期（起始 OE yield ~1.67%，价值全在终值）→ higher-for-longer/鹰派抬折现率、压高倍数长久期股，抬高 8% hurdle 达成难度 | 近期波动**偏负**（非论点变量） |

> 净：regime **加剧** F9（估值/多重）与 F3（capex 审计聚光），但**不**制造 kill——GOOGL 非存储/韩国/卖芯片敞口，特许经营 Q2 反而更强。regime 也可能是**最终送出可买价格的催化**（见 K-REGIME）。

## 3. 永久减值 vs 短期波动（Q2 后重判）

- **F3 capex**：仍是"可永久（若 ROIC 结构性下降）/可短期（若投资期错配）"。Q2 使**近端现实恶化**（FCF 负），但 **Cloud 35.5% 利润率 + $513.9B backlog 是"增量 ROIC 撑得住"的首个实证** → 尚未判永久。核心待证矛盾未决。
- **F1 搜索**：Q2 +17% **削弱**了"范式迁移导致永久减值"的近端证据。
- **F2 监管**：DOJ 搜索**无拆分**结案 → 最坏的永久情形（强拆）概率下降。
- **F9 估值**：买入即永久锁定回报——现价仍锁定负 base IRR，是**价格风险**，靠估值纪律对冲（= 封 WATCH 的根因）。

## 4. Kill Criteria（三态，更新自 6/19 K1–K9 / 决策卡 K-A~K-E）

- [ ] **K-A [F1]**：Search & other 连 2 季 ≤+8% 且归因 AI 迁移。**当前 +17% 🟢**（离触发远；自 +19% 略降需留意但未破线）。
- [x] **K-B [F3]**：FCF/share 连降 且 capex/OCF >70% 且无 incremental-ROIC 回升。**机制层触发中 🔴**：Q2 FCF −$5.9B；TTM FCF/share ~$4.36 vs $6.06 FY25（−28%）；TTM capex/OCF ~71%（单季 115%）；回购 $0 股数升。**逃生阀**：Cloud 35.5% 利润率 + $513.9B backlog = incremental-ROIC 证据；严格"连续两财年"时钟形式上到 FY2026 年末才闭合。
- [ ] **K-C [F3 资本配置]**：连 2 报告周期无 ROI 门槛 或 数据中心/TPU 减值。**🟡/🟠**：Q1'26 与 Q2'26 均加/持 capex（$195–205B）仅给"attractive return"定性——两周期无门槛；尚无减值。
- [ ] **K-D [F2]**：法院下**结构性**救济（剥离 adtech/禁默认分销）而非罚款。**缓和 🟢/🟡**：DOJ 搜索行为救济、adtech 待裁法官偏行为、EC 罚款上诉；窗口内无新不利裁决。
- [x] **K-E [F9 估值]**：买入价隐含 10y IRR <8%（base ~价 > $139）。**现价 $333.71 严重违反 🔴 ACTIVE 卡点**，唯 ~$117 解除 STARTER 讨论。
- [ ] **K-REGIME [新, 7/28]**：若 AI-capex 轮动把价拖向 ~$250–280 → **提前**重开 panel（改善入场 IRR 而非破论点，特许经营完好）；反之，半导体通缩期出现**数据中心/TPU 资产减值** → K-C 升 🔴。

## 5. Disconfirming Evidence（Q2 兑现了哪些空头证伪）

- **驳 F1**：Search +17% + AI 增益查询 → AI 是变现增量而非威胁（K-A 🟢）。
- **驳 F5**：Cloud 二度维持 35.5% 利润率 + backlog $513.9B + op income 翻三倍 → 利润率结构性而非一次性。
- **驳 F2**：DOJ 搜索**无拆分**结案 → 监管可吸收（最坏永久情形概率下降）。
- **仍未被驳的 F3/F9**：capex 兑现为负 FCF + 现价负 base IRR——这正是本轮 **verdict 停在 WATCH** 的两根支柱。

## 6. 模块结论（一句话）

**Q2 拆散了 6 月最怕的 F1×F3 永久合流（F1 走强、F3 兑现），把它降级为一个被 7/28 AI-capex-审计 regime 聚光的 capex/估值陷阱**：特许经营更强、监管缓和，但 capex 吃光 FCF 已从警告变事实，且现价无安全边际。M5 = **−1**（size/haircut，非 veto）；真正的卡点在 M6（价格）。
