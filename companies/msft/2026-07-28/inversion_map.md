## regime 专项:半导体暴跌对 MSFT 是**两面**的
- **成本面(偏正)**:MSFT 是内存的**买方**不是生产方。CXMT(长鑫)+466% 上市这一新 DRAM 供给若打掉"存储稀缺溢价"、内存价格回落,则 $190B capex 里的 ~$25B 组件涨价压力**缓解 → capex 账单下降 / FCF 改善**。这与 SK 海力士/美光/三星(卖方,价格跌=毛利崩)方向**相反**。
- **需求面(偏负/待观察)**:若这轮暴跌是"AI capex 泡沫开始泄气"的信号,则 Azure/AI-run-rate 需求增长承压——这才是对 MSFT 真正的风险点(不是 CXMT 本身)。RPO $627B 契约积压是缓冲。
- **一句话**:CXMT/内存崩本身不威胁 MSFT 利润池;真正的传导是"暴跌=AI 需求裂缝吗?"——7/29 Q4 Azure 实际 + FY27 指引会给出第一手答案。

## 永久减值测试(资产负债表能否存活?)
- **能,稳健**:净现金 ~$47B、债务下降、OCF ~$170B TTM、持续 dividend。即便 bear(全 capex 当维护 + Azure 减速),IRR ~breakeven 而非永久亏损。**无硬 veto。**

## Kill 标准(搬入 monitor;含 regime 新增 K-F)
- **K-A [F1]**: capex/OCF >70% 连两年 + FCF/股连续下降 + 无 incremental ROIC 证据 + 管理层仍无 ROI 框架 → capex 黑洞坐实,不加/减。(现 ~57% 🟡;7/29 看全年)
- **K-B [F3]**: Azure 增速连续两季 ≤ +25% 且归因需求(非汇率/产能)→ 增长引擎熄火。(Q4 指引 +39-40% cc 🟢;看 7/29 实际)
- **K-C [F4]**: OpenAI 关系/经济学重大负面变化或减值;或 $250B Azure 承诺出现反悔/延期。(4/27 重组偏正 🟢/🟡)
- **K-D [F2]**: AI run-rate 增速塌 + Copilot 续费/attach 走弱。(现 $37B/+123% 🟢)
- **K-E [估值]**: 价格隐含 10y IRR <8%(≈ 价格 >$436)。(现 $393.35 ≈9.1% 🟢,变薄)
- **K-F [regime,新增]**: 若半导体暴跌被 7/29 print 证实为 **AI 需求裂缝**(Azure/AI-run-rate 实际显著减速),或 FY26 capex 大超 ~$190B 且仍无 ROI 框架 **且** Azure 同时减速 → capex-strand thesis 正在兑现 → 不加仓、重审。反向提醒:内存降价对 MSFT 是**成本顺风**,勿把它误读成威胁。
