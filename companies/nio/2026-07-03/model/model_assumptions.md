# Model Assumptions

This is a placeholder for the next pass. Current work is evidence organization, not a full DCF.

## Required inputs

- Current diluted ADS count and ADS-to-ordinary-share ratio.
- Q2 2026 revenue, margin, cash flow, and balance sheet.
- Brand-level ASP or revenue proxy.
- Capex and swap network investment.
- Working capital trend.
- Consensus estimates if used, clearly tagged as secondary.

## Initial modeling principle

For NIO, model through gross profit and operating cash flow, not only revenue growth. Revenue can grow while equity value stagnates if margins and cash conversion are poor.
