## 1. 市场已经相信什么（反推隐含预期）—— 本节是 M6 的核心

Owner earnings 定义（本 dossier 一律用现金口径，**不用 non-GAAP EPS**）：

```
OE = TTM 经营现金流 − TTM 资本开支 − TTM 股权激励
   = $10,481M − $201M − ~$2,050M
   = $8,230M ≈ $8.20B
```
> 为什么扣 SBC：SBC 在 OCF 里被加回，是真实的股东成本。Adobe 的回购（FY2025 $11.28B）远超 SBC（$1,942M），**稀释已被完全覆盖且股本实质缩减 16.4%**，所以扣 SBC 是保守而非双重计算。

**EV / OE₀ = $106.65B / $8.20B = 13.0x。**

反推：在 $265.74 买入、退出倍数不变（13x）、10 年期，要恰好挣到 8% 门槛，需要 owner earnings 年化增长：

| 退出倍数假设 | 达到 8% IRR 所需 OE 年化增速 |
|---|---:|
| 10.0x（再压 23%） | **+1.95%** |
| **13.0x（不重估）** | **+0.29%** |
| 16.0x（部分修复） | **−1.09%** |

> **市场当前对 Adobe 的定价 ≈「owner earnings 未来十年横盘」。**
> 而公司当下：收入 +12.7% YoY（且在加速）、non-GAAP EPS 指引 $24.35–24.45（vs FY2025 的 $20.94，**+16~17%**）、ARR 指引 +10.2%、订阅收入占比 97.0%。
> **这条缺口——「市场付的价 vs 公司报的数」——就是本轮论点的全部。**

## 2. −61.40% 的拆解：崩的是倍数还是生意

峰值 **$688.37（2021-11-19）** → **$265.74** = **−61.40%**。三种口径互相校验：

### 2.1 GAAP 稀释 EPS 口径
| | 峰值（FY2021） | 现在（TTM） | 变化 |
|---|---:|---:|---:|
| 每股收益 | $10.02 | **$17.48** | **+74.5%** |
| 尾随 P/E | **68.70x** | **15.20x** | **−77.87%** |

恒等式：1.7445 × 0.22128 = **0.38602** → **−61.40%** ✓（零残差）

### 2.2 FCF / 股口径
| | 峰值（FY2021） | 现在（TTM） | 变化 |
|---|---:|---:|---:|
| FCF/股 | $14.31 | **$24.86** | **+73.7%** |
| P/FCF | **48.10x** | **10.69x** | **−77.78%** |

恒等式：1.737 × 0.2222 = 0.3860 ✓

### 2.3 市值 / 收入口径（与股价口径之差 = 回购）
| | 峰值 | 现在 | 变化 |
|---|---:|---:|---:|
| 市值 | $331.1B（481M × $688.37） | **$105.63B** | **−68.1%** |
| 收入 | $15,785M | $25,198M | **+59.6%** |
| P/S | **20.98x** | **4.19x** | **−80.0%** |
| 稀释股数 | 481M | 402M | **−16.4%** |

恒等式：1.596 × 0.1998 = 0.3189 → −68.1% ✓
> 股价跌 61.4% 而市值跌 68.1%，**差的 6.7pp 全部来自回购缩股**——Adobe 用四年半买回了 16.4% 的股本。

### 2.4 运营基数（非价格口径）
| | FY2021 | 最新 | 变化 |
|---|---:|---:|---:|
| Digital Media ARR | $12.24B | $19.20B（FY2025 末，末次披露） | **+56.9%** |
| Total Adobe ARR | — | **$27.10B**（Q2 FY26） | 口径不可比，仅供规模参照 |
| RPO | $13,990M | **$22,270M** | **+59.2%** |
| 营业利润率（GAAP） | 36.8% | 36.6%（FY2025） | **持平** |

### 2.5 归因结论（对数分解，唯一无残差分法）
ln(0.38602) = **−0.9520**
- 盈利项 ln(1.7445) = **+0.5566** → **占总变动 −58.5%**（抵消项）
- 倍数项 ln(0.22128) = **−1.5086** → **占总变动 +158.5%**

**答案：跌幅的 158% 来自倍数压缩；盈利基数贡献 −58%，即盈利一直在往回拉股价。**

反事实两条：
- 倍数守在 68.7x → 今天应是 **17.48 × 68.70 = $1,201**
- EPS 停在 FY2021、只压倍数 → **10.02 × 15.20 = $152**
- 实际 **$265.74**

> **这是本 lab 迄今最干净的「倍数崩了而非生意崩了」样本。** 比 BSX 更干净：BSX 至少有一条可量化的生意恶化证据（PFA 美国份额 100% → 41%，2.5 年）解释它的 −58%；**Adobe 到 as_of 为止，没有任何一条对应的可量化侵蚀证据**——收入在加速、ARR 净新增美元额三年持平、利润率持平、指引上调。

## 3. 为什么尾随倍数在这里是可用的（与 SYK 相反）

SYK 那份 dossier 的方法论决策是「尾随 P/E 被一次性事件扭曲，必须用前瞻」。**Adobe 相反：尾随口径是干净的，前瞻口径才需要小心。**

| 指标 | 值 | 读法 |
|---|---:|---|
| 尾随 P/E（GAAP，TTM EPS $17.48） | **15.20x** | 干净。唯一扰动是 Q2 FY26 的 $70M 商誉减值（$0.17/股），还原后 P/E ≈ 15.05x |
| 尾随 P/FCF | **10.69x** | 最干净的一条：FCF 无需任何调整 |
| **EV / OE（扣 SBC）** | **13.0x** | 本 dossier 的主口径 |
| 前瞻 P/E（FY2026 non-GAAP $24.40 中值） | **10.9x** | 谨慎使用：non-GAAP 加回了 $1.9B+ 的 SBC，不是现金口径 |
| 前瞻 P/E（FY2026 GAAP $17.95 中值） | **14.8x** | 与尾随几乎相同——**说明 Adobe 没有「靠明年拯救估值」的成分** |
| TTM FCF 收益率（对股价） | **9.36%** | |
| TTM FCF 利润率（FCF / 收入） | **40.8%** | $10,280M / $25,198M |
| capex 占收入 | **0.80%** | $201M / $25,198M —— **与 GOOGL 的 capex/OCF 71% 是两个物种** |

**一句话**：Adobe 的估值不依赖任何「明年会好」的假设。尾随和前瞻的 GAAP 倍数几乎重合（15.2x vs 14.8x），意味着当前价格是在给**已经发生的现金流**定价，不是在给故事定价。

## 5. Buy-below 与价格阶梯

以 base 情形（OE +6%、退出 13x、10 年）反解价格：

| 目标 IRR | 对应价格 | vs 现价 $265.74 |
|---|---:|---:|
| 8%（门槛） | **$406** | +53% |
| 10% | **$352** | +32% |
| **12%（buy_below 主锚）** | **$306** | **+15%** |
| 15% | **$252** | −5% |

**为什么 buy_below 取 12% 而不是 8%**：本 dossier 有五条 blocking OPEN（facts.md O1/O2/O3/O7/O8），其中最要命的是 **O1——公司撤掉了能证伪本论点的指标**。当一个论点的**监控成本被公司主动抬高**时，要求的回报率必须相应抬高。12% 的锚 = 在 base 假设上多留 4pp 的垫子，专门补偿「我可能验证不了自己错在哪」这个风险。

### 价格阶梯

| 档位 | 价格 | 动作 |
|---|---|---|
| **no-chase 线** | **~$352** | base 10% IRR。高于此价，买入等于要求 base 之外的条件成立 → **不追** |
| **buy_below（新钱上限）** | **~$306** | base 12% IRR |
| **现价 $265.74** | **$265.74** | **STARTER 3%**——已在 buy_below 之下 13.2%，base 10y IRR +14.15% |
| **ADD 区（→6%）** | **≤ $252** | base 15% IRR；**或**价格不变但 O1/O7 关闭 |
| **最大确信区** | **$193–225** | 2026-06-25 收盘低点 $193.41 / 2026-07-24 收盘 $225.11 |
| **bear 下行锚** | **~$137** | bear 情形下仍能挣 8% 的价格 = **「如果 AI 真赢了，Adobe 值多少」** |
| bull 8% 上限（仅参照） | ~$672 | 即使 bull 全对，$672 才是 8% 的临界 |

**下行的两个独立读数**
1. **模型口径**：bear 8% 锚在 **$137**（现价再跌 48%）。
2. **市场口径**：2026 年的实际最低收盘是 **$193.41**（2026-06-25），即现价再跌 27% 就回到本轮真实底部。
> 两者相差很大。诚实说法：**$137 是"AI 真赢了"的估值，$193 是"市场最悲观时给的价"。** 现价 $265.74 位于两者之上 37%–94%，意味着**市场已经不再按最坏情形定价了**——这正是它从 6 月底反弹 37% 的含义。**不要把这张卡讲成"抄在地板上"。**

## 6. 这个估值最可能错在哪（自我攻击）

1. **OE₀ = $8.20B 可能高估。** 如果 Adobe 签了大额多年 AI 算力承诺（facts.md **O3**，本 run 未提取 10-K purchase obligations），真实的维持性现金支出会高于 $201M 的 capex。软件公司的"capex 只占 0.8%"在生成式 AI 时代可能是个正在失效的假设。**这是本估值最大的单一未知项。**
2. **6% 的 base 增速可能不够保守。** 它假设 ARR 有机增速稳在 7–8%。但 FY2026 隐含有机增速已经是 ~8.3%，且趋势是每年 −1~1.5pp。若线性外推，第 5 年就到 2–3%。用 6% 的 OE 增速隐含了「回购缩股 + 利润率扩张」补上差额——**这个补法在收入减速时不一定成立**。
3. **13x 的退出倍数可能仍然偏高。** 如果市场最终认定 Adobe 是「有现金流的衰退资产」（类似 2015 年后的 IBM），7–9x 才是终值。bear 情形已用 7x 测过，年化 −2.4%。
4. **反方向的错**：如果 AI 反而**扩大**了内容生产总量（每个企业都要生成 10 倍的素材），Adobe 的企业端 Experience/GenStudio 可能是净受益方，bull 的 +10% OE 增速偏低。本 run 没有能力给这条定价（facts.md O8）。

**一句话**：这份估值对「Adobe 的现金流质量」很有信心（M4 = +2），对「这些现金流能持续多久」信心一般（M3 = 0）。**因此约束项写的是 COMPLETENESS，不是 PRICE。**
