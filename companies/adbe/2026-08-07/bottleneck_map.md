## 1. 正向卡点 #1：PDF / ISO 32000 —— **唯一有硬数字支撑的结构性卡点**

**结构**：PDF 由 Adobe 创造，2008 年成为 ISO 32000 国际标准。格式开放，但 Acrobat 是事实上的参考实现。企业法务、合规、政府归档要求的是**跨十年、跨系统、逐像素保真且可审计**的文档载体。

**为什么模型变强绕不过去**：这个需求与「模型有多聪明」正交。更好的语言模型让你**更会读**一份合同，不会让你**不需要**一份法律上不可篡改的合同文件。AI 在这里是增强件（Acrobat AI Assistant），不是替代品。

**证据等级：A（有收入线）**
- Business Professionals & Consumers 订阅收入：FY2025 **$6.50B（+15%）**、Q2 FY26 **$1,853M（+16.2%）**
- **这是全公司增长最快的部分**，且增速在加速（FY2025 +15% → Q2 FY26 +16.2%）

**攻击面**：不攻击格式（打不动），攻击**免费阅读/签署入口**——浏览器内置 PDF、Google Workspace、Edge/Copilot。这确实在侵蚀免费层，但侵蚀不了需要审计轨迹的企业签署。
**未闭合**：Acrobat 与 Express 被合并披露在 BP&C 里，**无法分离**（facts.md O1 的一个子项）。所以 +16.2% 里有多少是 Acrobat 的结构性增长、多少是 Express 在战场上的进退，**外部不可知**。

## 2. 正向卡点 #2：未完成态文件格式在团队流水线中的交换地位 —— **逻辑最强，证据为零**

**结构**：一个人的**成品**可以被 AI 替代；一条 12 人流水线的**中间态**不行。
- .psd 的图层与蒙版、.ai 的矢量路径、.prproj 的时间线与素材引用、.aep 的合成树
- 这些不是"文件"，是**尚未完成的工作在人与人之间传递的协议**
- 加上 Frame.io（2021 收购）的评审/版本/时间码批注、Creative Cloud Libraries 的共享资产

**为什么这可能是最深的卡点**：切换一个人的工具是一个**决定**；切换一整条已经跑通的流水线是一个**项目风险**。片厂、代理商、游戏工作室的交付截止日不允许在项目中途换栈。**这与 SYK dossier 里 Mako「外科医生受训 + 手术室流程重构」的切换成本机制同构。**

**证据等级：F（零）**
Adobe **从不披露**席位数、团队/企业席位占比、协作产品收入、Frame.io 使用量。这是本 dossier 最想要而拿不到的一块数据，**与 SYK 的「implant pull-through 无法量化」是同一类缺口**。

> **本 run 的最高优先级后续研究项**：任何能量化「团队席位 vs 个人席位」的数据。它会直接决定 M3 是 0 还是 +1。

## 3. 正向卡点 #3：企业数据驻留 + 多年合同

**结构**：Adobe Experience Platform / Real-Time CDP / Analytics / AEM——客户数据驻留在 Adobe 侧，与 CRM、广告栈、身份图集成，实施周期以年计。
**证据等级：A（有硬数字）**
- **RPO $22,270M、cRPO 67%**（Q2 FY26）→ 约 $14.9B 在 12 个月内确认，约 $7.4B 在其后
- RPO 轨迹：$19.96B（FY24 末）→ $22.52B（FY25 末）→ $22.27B（Q2 FY26）
**弱点**：Digital Experience FY2025 增速 **+9%**，**慢于公司整体 +11%**。这一层粘性高但增长弱，且与 Salesforce/微软正面竞争。**是护城河，不是增长引擎。**

---

## 4. 反向卡点（对 Adobe 不利）：入口层的默认选择正在被重置

**结构**：Photoshop 的地位建立在**受训的人**和**默认选择**上——这两样都可以被一代人换掉。
**机制（三条，按危险程度排序）**：
1. **需求池收缩（最危险）**：如果「生成 + 轻量修改」成为主流路径，需要专业编辑器的**场景数量本身**萎缩。这不是份额战，比份额战更难防——你无法通过赢竞争对手来解决。
2. **免费入口被占**：竞争者从免费/模板层起步往上打（正是 Adobe 当年从桌面出版往下打的镜像）。**Adobe 用 Adobe Express + freemium 应战，这本身就是承认这条攻击是真的。**
3. **价格**：Creative Cloud 订阅价长期是行业抱怨点，攻击者从 $0 起步。

**证据等级：C（不可直接观测）**
**这正是问题所在**：能观测这条卡点是否正在失守的指标（净新增 Digital Media ARR、Creative ARR），**Adobe 已经分两次撤掉了**。
- FY2025：撤净新增 ARR + Creative/Document Cloud 拆分
- FY2026：撤 Digital Media ARR 本身 + 三个报告分部合并为一个

> **这是本 dossier 的核心不对称**：**Adobe 最强的卡点（PDF）有硬数字；最受威胁的卡点（创意工作流入口）恰好是唯一被撤掉披露的那个。**

## 5. 潜在反向卡点：算力承诺（**未知，blocking**）

Adobe 自身 capex 只占收入 0.80%，说明它租算力。**但租算力如果签的是多年最低采购承诺，支出走经营性现金流，不进 capex**——"capex 只占 0.80%" 这个核心安慰性数字就会低估真实的维持性资本消耗。
**本 run 未提取 10-K 的 purchase obligations 章节（facts.md O3）。这是 owner earnings 桥的最大单一未知项。**

## 6. Repricing path（价格如何反应）

| 触发 | 方向 | 机制 |
|---|---|---|
| Q3/Q4 FY2026 有机 ARR 增速守在 8%+ | **上** | 「AI 侵蚀」在两年窗口内都没出现在数字上，13x 的倍数需要重估 |
| **Adobe 恢复任何一条分层 ARR / 席位披露** | **上（最大单一催化剂）** | 直接解除本 dossier 的 binding_constraint |
| 正式 CEO + 正式 CFO 到位且战略不转向 | 上 | 解除 K-D |
| 有机 ARR < 7% 连续两季（K-A） | **下** | 缓冲只有约 1.3pp，**最可能先到的一条** |
| 任何 BSX 量级的份额/席位流失硬数据 | **下（重）** | M3 从 0 掉到 −1，bear 情形被激活 |
| 第三次披露退化（K-E） | 下 | 自动降级 |

## 7. What could prove this wrong（本卡自己的错法）

1. **「PDF 是结构性护城河」可能被高估**：如果企业文档工作流整体迁移到「AI 原生的、非 PDF 的」结构化格式（例如模型直接读写的语义文档），PDF 的地位是被绕过而非被攻破。**这条本 run 无法评估。**
2. **「团队流水线锁定」可能是一厢情愿**：如果 AI 工具的产出质量高到流水线本身被压缩（12 人变 3 人），中间态交换的需求就消失了。**卡点 #2 的整个逻辑依赖于"流水线继续存在"。**
3. **收入加速可能是滞后指标**：ARR 是期末存量、收入是过去 12 个月的流量。「ARR 减速 + 收入加速」既可以是良性（涨价先进 ARR），也可以是恶性（存量流失、收入未跌）。**没有 NRR、没有席位数、没有净新增 ARR，本 run 无法区分——这是 M2 只给 +1 的唯一原因。**
4. **反方向**：如果 AI 让内容总产量爆炸（每个企业要生成 10 倍素材），L3 企业编排层可能是净受益方，bull 情形的 +10% OE 增速偏低。**本 run 没有能力给这条定价（O8）。**
