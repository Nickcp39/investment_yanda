# BE — M2 主题 / 机制

| 项 | 内容 |
|---|---|
| Theme | 电网并网排队以年计，数据中心要"表后"现场电源；固体氧化物燃料电池（SOFC）可按模块快速部署 |
| Why now | Q2 收入 +166%、首次单季破 $10 亿、经营现金流转正；FY26 指引上调至约 +100% |
| 市场叙事 | "Bloom 已成为 AI 现场供电的标准"（CEO 原话）；积压 ~$20B；进入标普 500 |
| 市场可能高估的 | 护城河：34% 毛利率说明它**没有**瓶颈定价权；竞争者是燃气轮机、往复式发动机，以及其他燃料电池 |
| 市场可能低估的 | 执行与供应链风险：产能扩张 + 做空报告指向的原料依赖 |
| 稀缺资源 | "时间"：能在 12–18 个月内交付几十到几百 MW 的现场电源 |
| 谁付钱 | 超大规模云厂商、neocloud、托管商（Oracle 为具名合作方） |
| 利润池 | 设备 + 服务；毛利率 34% 是**工业设备**水平，不是瓶颈水平 |
| 迫使市场更新的一个指标 | **non-GAAP 毛利率**：扩产期能否守住 ~34% |
| **context_label** | **`exceptional_bottleneck`（声称）** —— 检验后：需求端是瓶颈，**但 BE 不拥有瓶颈**（毛利率证据） |

**M2 信号：+2** —— 需求机制强、兑现快。
