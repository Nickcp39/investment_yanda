# MRK — 护城河（BSX 式检验）

| 候选 | 类别 | 判定 |
|---|---|---|
| **Keytruda 化合物专利** | ✅ 结构性 —— **但 2028 到期** | **一个带倒计时的护城河**，2028 后归零 |
| **皮下剂型（QLEX）的独立保护** | ⚖️ **正在建设中，进度 5.5%** | 若建成是真锁定；**没建成就什么都不是** |
| 肿瘤临床数据与适应症广度 | ✅ 结构性，**但可被生物类似药搭便车** | 生物类似药沿用原研的适应症 |
| 医生与医院处方惯性 | ❌ **在位惯性** | 生物类似药进医保目录即被替换 |
| Winrevair（罕见病） | ✅ 结构性但小 | 年化 ~$2.4B vs 悬崖 $240 亿量级 |
| mRNA 疫苗平台（Moderna） | ⚫ **太早，无法判定** | O-M4 |

## 判定

> **MRK 的护城河在 2028 年有一个已知的失效日期，
> 而替代护城河（皮下剂型）目前完成度 5.5%。**

这是本库此前没有的第五种形态：

| 形态 | 案例 |
|---|---|
| 护城河**被证伪** | BSX、NVO |
| 护城河**被变成不可证伪** | ADBE |
| 护城河还在但**公司靠别的东西增长** | XYZ |
| 护城河完好但**保护的维度不是被攻击的维度** | LLY |
| **护城河有已知失效日期，替代品在建、进度可测** | **MRK（新）** |

> **第五种的好处是：它是本库唯一一种可以用一个数字追踪进度的。**
> **QLEX 渗透率就是那个数字。**
