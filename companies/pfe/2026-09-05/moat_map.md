# PFE — 护城河（BSX 式检验）

| 候选 | 类别 | 判定 |
|---|---|---|
| **Seagen 的 ADC 平台** | ✅ **结构性（若整合成功）** | ADC 是当前肿瘤最热的技术平台。**但它是买来的，不是长出来的** |
| 全球商业化网络（销售、准入、生产） | ✅ **结构性，且是 PFE 最被低估的资产** | **这正是小药企卖给它的理由** —— 它们有分子，没有渠道 |
| 各在售药的专利 | ✅ 结构性，各有到期日 | |
| 规模与资产负债表 | ⚖️ **既是护城河也是负担** | 能买得起 $530 亿，也意味着必须背着它 |
| COVID 时期的品牌 | ❌ **已经不是资产** | |

## 关键判定

> **PFE 真正的护城河不是分子，是「把分子变成收入」的那套全球机器。**
> 这条护城河**没有到期日**，而且是它能持续当买家的原因 ——
> **小药企卖给它，买的正是这个。**

**⇒ 这改变了对「被迫买家」的读法**：
如果 PFE 付的溢价 < 它的商业化机器能额外榨出的价值，**并购就是价值创造而不是转移**。

> ⚠️ **本轮无法验证这一点**（O-P2 / O-P3）。
> **但这是本卡对批次 T3 命题最重要的一句限定：
> 「被迫买家一定吃亏」这个直觉，在拥有独特商业化能力的买家身上不一定成立。**

## 与本批其他家对照
