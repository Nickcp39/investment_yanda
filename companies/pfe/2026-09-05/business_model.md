# PFE — 生意模型

## 1. 它的处境：三件事同时发生
```
COVID 收入退潮（结构性、不可逆）
        +
自有专利悬崖
        +
必须在两者之间买到新的增长
```
**⇒ 于是有了 $530 亿的收购账单 = 当前市值的 33%。**

## 2. 「被迫买家」这个角色的经济学

| | |
|---|---|
| **买方视角** | 我的现金流在退潮，我必须用**现在的钱**买**未来的收入** |
| **卖方视角** | 我知道你必须买 —— **所以我要溢价** |
| **结果** | 溢价从买方股东转移到卖方股东 |

> **本批 T3 命题问的就是：这个转移，有没有对应的价值创造？**

**本轮的诚实回答是：拿不到干净的归因。** 原因：
- Seagen 2023 年交割（有时间兑现），Metsera 很新（没时间）
- **COVID 产品的下滑同时在压总数**（+3% 总额 vs **+5% 除 COVID**）
- 没有分部/分产品收入桥（O-P3）

**能说的只有量级**：花了市值的 33%，FY26 营收指引仍是**个位数增长**。

## 3. 但有一条是清楚的：成本端
**到 2029 年净节约 $97 亿。**
在营收增长个位数的情况下，**利润的改善主要要靠这一条**。

> ⚠️ **成本节约是一次性的**（`business_model` 里 XYZ 卡同一条教训）。
> **削到底之后，增长必须回到收入端 —— 而收入端要靠那 $530 亿买来的管线。**
> **这两件事在时间上必须接上，否则中间有一个坑。**

## 4. 与本批其他四家的关系
PFE 是**产业链的另一端**：
- LLY / NVO / MRK / AZN 讲的是「**谁有资产**」
- **PFE 讲的是「没资产的人要花多少钱买」**

> **而 PFE 付的价格，就是整个小型药企板块估值的锚。**
> ⇒ 这也是为什么本批把 **SMMT / RVMD / CGEM 那一层排除在外**却仍然覆盖了它们：
> **不用给每家小药企建卡，看买方付了多少就够了。**
