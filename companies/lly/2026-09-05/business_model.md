# LLY — 生意模型

## 1. 钱从哪来
本质是**一个分子的专利期租金**：tirzepatide（Mounjaro 糖尿病 / Zepbound 减重）。
Q2 Mounjaro 一个品牌 **$9.9B = 全公司营收的 43%**（derived）。

**⇒ LLY 的集中度接近 MRK。** 这一点被"增长股"的叙事掩盖了 ——
本批的 MRK 卡在讲「单品占 50.6% 有多危险」，
而 **LLY 的单品占 43%，只是到期日更远。**

## 2. 增长的三层与各自的寿命

```
第一层 存量适应症放量（糖尿病+肥胖）  ← 现在的引擎，+91%
第二层 适应症扩张（睡眠呼吸暂停、心衰、MASH…）
第三层 口服（Foundayo）—— 把可及人群从"愿意打针"扩到"只愿吃药"
```

第三层是真正的规模跃迁：**口服解除了给药方式这个天花板**。
分析师预计 Foundayo 在 **2028 年前**拿下美国口服减肥药大部分市场。

## 3. 🔴 但增长的**定价**正在被对手主动破坏

`facts.md` §4 那条外部事实是本卡的核心：

> **NVO 自 2027-01 起下调美国标价：Wegovy 约 −50%、Ozempic 约 −35%。**

这不是猜测，是**已公告的**。含义：

| | |
|---|---|
| 一个 40% 份额的对手 | **主动把品类标价砍半** |
| 它这么做的原因 | 它的美国 Wegovy 针剂已经 **−22% CER 且在加速**（Q1 −12%）—— **它在用价格换量** |
| 对 LLY 的含义 | **LLY 可以不跟，但会丢份额；跟了，就是自己砍自己的每单位利润** |

> ### 一句话
> **LLY 现在的定价（P/S 11.91x、fwd P/E ~31.6x）隐含的是"这个利润池是持久的"。
> 而池子里另一个玩家已经公告要把水位砍一半。**
>
> **这两件事不能同时成立。本卡的全部分歧集中在这一点上。**

⚠️ 本轮**无法量化**这条：净价 vs 标价的折扣阶梯（PBM 返点）没有披露（**O-L3**）。
标价砍 50% ≠ 净价砍 50% ——**很可能标价降是把已有的暗返点摆到明面上**，
真实净价影响远小于 50%。**这是最可能推翻本卡谨慎立场的一条，且我没有数据。**
