## 2. 批次 T1 直答：已知日期的坏消息该怎么定价？

**MRK 是本批的方法论产出。** 它把一个叙事变成了一张配速表：

| | |
|---|---:|
| Keytruda 占季度营收 | **50.6%**（$8.4B / $16.6B） |
| 美国核心专利到期 | **2028** |
| 防线 = 皮下剂型 QLEX，**当前渗透** | **5.5%**（$463M / $8.4B） |
| 剩余时间 | **约 10 个季度** |
| **达 40% 渗透需每季** | **+3.45pp** |
| **达 60% 渗透需每季** | **+5.45pp** |

> **"皮下改造能不能救 Keytruda"从一个无法证伪的叙事，
> 变成了一个每季度财报里都能读到的、有目标线和剩余时间的数字。**
> **这个转换本身就是本批最有复用价值的产出** ——
> 以后任何专利到期、大合同到期、监管日落，都能套这个结构：
> **`(目标 − 当前) ÷ 剩余期数 = 必需配速`**。

### 那个矛盾也有了答案
**MRK 52 周低 $77.58 → 现价 $150.33（+93.8%），而 2028 又近了一年。**
**本卡算出的 8% 观察线是 $72.44 —— 与 52 周低点只差 6.4%。**

> ⇒ 结论不是「MRK 很贵」，而是
> **「MRK 一年前处在合理起点，然后在一年里把未来十年的钱提前赚完了」。**

> ### ⇒ 规则应改为两问：
> **① 损伤是真的吗？**（ORCL / NFLX / NVO = 是）
> **② 损伤定价够了吗？**（ORCL 高 29%、NFLX 高 4.3% = 不够；**NVO 高 19% = 接近**）
>
> **原规则只问了第一问就下了"别接"，那是把「倍数崩得有理由」
> 当成了「崩够了」。这两件事不是一回事。**
