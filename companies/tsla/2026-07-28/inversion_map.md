## 永久减值 vs 可恢复
- **永久减值（对今天 $307.44 买入）主要来自 F1+F3 合流**: NARRATIVE 落空 + 估值向 DELIVERED 回归。即便给 DELIVERED OE 慷慨 35–45x，base 5y IRR 仍 **−12%**（bear −23%）。**这不是破产**（净现金 fortress ~$35B、交付创记录），而是"为故事付的溢价"的永久损失。
- **6/19→7/28 的位移**: F3（de-rate）的一部分**已实现**（−23%），但 **F2（利润率塌 1.4%）+ F5（FCF 转负）+ regime（AI capex 审计逆风）接棒**，把腾出的空间填回。净风险读数不变。

## 硬 veto 判定
- **仍不触发硬 veto**: 生意未结构性破裂（**Q2 交付 +25% 记录、收入 +26%、TTM 首破 $100B**、能源 +40%、服务创利润率记录、资产负债表 fortress）。robotaxi/Optimus 前瞻不确定 = **haircut，非 veto**（修好的老规则）。
- **但**: 与 NVDA 相反，价格 + 利润塌 + regime 构成 **verdict ceiling**（GOOGL 式，但由"利润质量塌 + regime 逆风"主导，而非纯价格）。现价对 base DELIVERED 基本面**仍无 MOS**。
- **三重 binding 合流（重心已从价格转向利润池）**: ①利润池塌缩（营业利润率 1.4% + 积分断 + FCF 转负，**本次最锋利**）②base 无 MOS（价格改善但不够，仍 ~2× buy_below）③Musk key-man/12% 稀释。任一是 haircut；合流压到 WATCH。

## Kill 标准（→ decision_card）
- **K1**: robotaxi/Optimus 时间表再重大延后 **或** 单位经济披露为不经济 → NARRATIVE 证伪。现状: 仍小/产前，Q2 无进展披露。
- **K2**（利润池）: 汽车营业利润率 <4% **或** 交付两位数下滑。**读数: 利润率半边已触发（公司口径 1.4%<4%）；交付半边反转（+25%）** → 结构性利润率压缩**确认**（封顶更紧、存量更偏 TRIM），但非量的 EXIT。
- **K3**: Musk 离任/失能/重大声誉事件 → narrative 溢价最快崩。
- **K4**: $1T 包里程碑解锁触发大额稀释 → 每股摊薄（O7 股数口径需盯）。
- **K5**（新，regime）: **FCF 连续 ≥2–3 季为负且 capex 不转化为 robotaxi/Optimus 收入** → "AI capex 审计"对 TSLA 证伪 → 封顶更紧/存量 EXIT 候选。
- **K6**（建仓纪律）: base 口径无 MOS（现价即如此，~2× buy_below $160）→ 不追、不在 narrative 高位建仓；<~$200 才进入 STARTER 讨论、深 MOS ~$110–130。
