# META Inversion / Trap Test (M5) — as_of 2026-07-28（叠加 2026-07-28 regime）

> 反过来想：什么会让在 **$593.41** 买入 META 变成永久减值或大错？（6/19 失败路径结构未变，此处叠加当前 regime + 待发的 Q2/FOMC。）

## 2026-07-28 regime 如何打到 META 这个具体名字
- **半导体暴跌 / SOX −25% / SK 海力士腰斩 / KOSPI 第 8 次熔断**: META **不是** memory/AI-硬件厂（它是买芯片的 capex 支出方 + 数字广告双寡头）→ **利润池无直接冲击**。但作为大盘科技，META 被卷入 tech 全线 de-rate：从 7/15 的 ~$681 回落到 7/28 的 $593.41（约 −13% 两周）。属**多重压缩 + 情绪**，非生意破裂。
- **"AI capex 审计年" + 资金轮出 AI capex → 价值/防御/苹果（$5T 反超 NVDA）**: 这是对 META **最直接的一击**——市场当下集中拷问的"$125–145B capex 多久转 FCF"**正是 META 6/19 就标出的唯一未决胜负手（O4）**。regime 不改变 thesis，但**抬升了近期风险溢价 / 压低了市场对 capex 的估值容忍度**，且 META 站在"被轮出"的一侧（AI-capex 支出方），而非苹果那侧（防御/现金回报）。
- **CXMT（长鑫）+466% 上市 / ~$488B**: 新 DRAM 进入者打**存储**"稀缺溢价"——**对 META 护城河无威胁**（META 不卖存储）。二阶反而是**温和利多**：capex 上调（$115–135B→$125–145B）的原因之一是 memory/networking 元件涨价；若存储因 CXMT + 韩国腰斩而降价，**META 未来单位算力的 capex 账单可能下降 → 边际改善 capex-ROI（O4）**。近端指引已定死，此为中期非对称的一个小正项。
- **Q2-2026 财报（7/29 盘后）+ FOMC（7/29 + Warsh 记者会）同日**: as_of 之后**一天**的双二元事件。共识营收 ~$60.2B（+27%，从 Q1 +33% 减速）、EPS ~$7.18（调整后同比仅 ~+1%——capex/折旧拖累已现）。**capex 是否再上调 = 最可能引爆的单点**（Q1 上调 capex 曾致盘后 −6%）。

## 永久减值 vs 可恢复
- **资产负债表死亡风险 = 无**：净现金仍在、OCF ~$32B/季强劲 → 即便 bear（~$332，−44%）也是 **de-rate + 减值，非破产**。
- **唯一可升硬 veto = F2**（流量入口结构改写）。当前无证据 → **不触发硬 veto**。
- F1（capex 黑洞）仍是**最可能的价值毁灭路径**，regime 把它推到聚光灯下；但它降的是 owner earnings/耐久性（→ haircut + size + kill 监控 + 价格控制），**不是资产负债表存活** → 按修好的规则**不是 veto，是 size + 价格控制**。前瞻不确定性 = haircut，不复发"不确定性当 veto"的老病。

## 假便宜陷阱测试
- META 现价 **不便宜**：base IRR +3.4% < 8%，FCF yield 3.3%，高出保守公允价 ~24%。真正的陷阱仍是**反向的**——被"广告满血 + AI"叙事带跑而忽视 FCF 被 capex 吃、base 不过门槛；如今再加一层"事件前一天在无 MOS 位置追入"的择时陷阱。

## kill / 升级标准（搬入监控；含 7/29 事件条款）
- **K0（新增，7/29 触发）**: Q2-2026 印证——(a) 若 **capex 再上调 且 单价/impression 增速明显减速** → O4 转负、F1 走强 → **REJECT 候选 / 下修耐久性**；(b) 若 **营业利润率在 capex 高位下仍扩张（capex 复利首证）** → 上修锚、base ~+10% → **STARTER-eligible（解 blocking O4）**。
- K1: 营收增速跌到个位数 **且** 单价转负（广告引擎质量证伪）。
- K2: capex 继续上调但营业利润不增（F1 黑洞坐实）→ ROIC 跌破资本成本。
- K3: DAP 连续下滑 + 时长下降（F2 流量入口改写早期信号）。
- K4: 新的 OS/隐私或监管冲击实质削广告归因（F3/F4）。
- K5: 买入价隐含 base IRR < 门槛（现价即触发，故价格封顶）。

## M5 signal
**−1（警告，非 veto）**: 失败路径真实（F1 最可能、regime 正集中定价它；F2 唯一可升 veto 但无证据），无结构性破裂、无资产负债表死亡。**regime + 7/29 双二元事件把近端风险抬高**，但按修好的规则处理为 haircut + size + 价格 + 事件择时控制，不是硬 veto。
