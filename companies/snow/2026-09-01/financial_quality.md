# SNOW — 财务现实（M4）

## 1. 一张表说完

| FY2026 口径 | 值 |
|---|---:|
| 总收入 | $4.68B |
| 非 GAAP 经营利润 | **+$489.7M（+10%）** |
| GAAP 经营利润率 | **−31%** |
| GAAP 净亏损 | **−$1.329B** |
| **SBC（四项明细加总）** | **$1.5996B** |
| **SBC / 收入** | **34.2%** |

> **GAAP 净亏损 $1.329B ≈ SBC $1.60B。**
> 也就是说：**把发给员工的股票算成成本，这家公司就是亏的；不算，就是赚 10%。
> 整个「盈利与否」的答案，取决于你怎么对待这 $1.6B。**

## 2. 三锚敏感性（批次 PLAN §1 T3-2 强制项）

FY2026 调整后 FCF 以 **~$1.17B** 估算（derived，⚠️ O-S3 未验证）。

| 锚 | owner earnings | 市值 / OE | 评价 |
|---|---:|---:|---|
| **A 公司口径**：调整后 FCF，SBC 全部加回 | **+$1.17B** | **98x** | 这是卖方用的口径 |
| **B 全额扣 SBC**：FCF − $1.60B | **−$0.43B** | **无倍数（负）** | 这是「股票也是钱」的口径 |
| **C 折中**：FCF − 50% SBC | **+$0.37B** | **310x** | 假设一半 SBC 是真实留才成本 |

> **META 教训的极端版本。** META 那张卡上换个锚是 0% → +10%（跨过门槛）。
> **SNOW 换个锚是 98x → 负数。这不是敏感性，这是同一家公司的两个不同物种。**
>
> ⚠️ 而且**三个锚没有一个能支持当前价格**。A 锚 98 倍已经是极端乐观口径了。

## 3. 空头在赌的正是这一条
空头仓位 **$6.18B / 18.8M 股，接近历史高位**，公开归因是
**「GAAP 亏损 + SBC 稀释」**。

> 这不是一个信息不对称的赌注 —— **多空双方看的是同一张表，
> 分歧在于「$1.6B 股票算不算成本」。** 这是估值哲学分歧，不是事实分歧。

## 4. 稀释方向（对照项，本批最干净的一条）

| | **SNOW** | **XYZ（同批）** |
|---|---|---|
| SBC / 收入 | **34.2%** | ~11%（$1.36B / $12.51B GP，derived） |
| 股数方向 | ⚠️ **未知 O-S4**（只有 346.6M 一个点） | **−3.54% YoY** |
| 回购 | 未取到 | $701M YTD，另有 $5B 授权 |

> **一家在回购，一家在发。这是本批最锋利的一条对照，
> 且它与「谁跌得更凶」完全无关 —— 跌 71% 的那家在回购。**

## 5. 增长质量：加速是真的，但毛利在薄
- 产品收入 +29%（FY26）→ **+34%（Q1 FY27）加速**，NRR 125% → **126%**
- 同期产品毛利率 **76% → 75%**，且公司明说 **AI 产品毛利更低**
- RPO **环比下降**（$9.77B → $9.21B），同比自 +42% 减速到 +38%

> 收入加速 + 毛利压缩 + RPO 减速，三者同时出现。
> **这不是「崩了倍数没崩生意」，这是「生意在变化，方向未定」。**

## M4 打分：**−2**
理由：SBC 占收入 34%、GAAP 深度亏损、三锚全部不支持当前价格、稀释方向未知。
（对照：GOOGL 卡 M4 = −2 的理由是 FCF 转负；SNOW 是**从来没有过 GAAP 盈利**。）
