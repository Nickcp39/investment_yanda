## regime 的名字级细读（AMZN 特有，不是一刀切）
- **半导体/存储暴跌对 AMZN 是"混合偏中性/略有隔离"，不是纯利空**：AMZN 是内存/算力的**买方**——CXMT 冲击 DRAM 稀缺溢价 → **更便宜的内存反而降低 AMZN 的 capex 单位成本**；自研 Trainium 进一步降低对 NVDA GPU 的依赖。这与"内存/GPU 生产端"名字（利空）方向相反。
- **轮动方向 AMZN 半身在场**：作为 hyperscaler（AI-capex 花钱方）身处审计年靶心，但庞大的**消费/零售引擎**又落在轮动偏好的消费/防御桶——这解释了它 −5.5% 的相对抗跌（vs 半导体腰斩）。
- **净判断**：regime 对 AMZN 的**基本面**冲击是"放大既有弱点（FCF 转化）+ 情绪面承压"，但**未新增结构性破裂路径**；名字级看反而比纯 AI-硬件名有更多缓冲。

## 永久减值 vs 可恢复
- **可升 veto 的唯一路径 = F1（capex 价值毁灭）**，capex-审计年抬升其 salience，但仍需连续几年 ROIC 证据，当前无法证伪（O4）→ 现在是 haircut + size 控制 + 监控，不是 veto。
- **资产负债表不会死**：OCF $148.5B、净现金（金融债）仍正 ~+$24B → 不触发"资产负债表无法存活"的硬 veto。
- **F6（估值无 MOS）仍是封顶而非 veto**：生意没破裂，是价格不对 → verdict 封在 WATCH（同 GOOGL），不是 REJECT。

## Kill / 升档标准（→ 更新）
- **K1（capex-审计核心）**：7/30 及后续财报——capex 续增但 AWS 增量营收/利润与 FCF 释放不匹配（ROIC 恶化）→ F1。
- K2：AWS 增速结构性回落到 <15% 且份额走弱 → F2。
- K3：零售营业利润率从 13.1% 显著回吐（<9%）→ F3。
- **K4（regime 新增）**：FOMC/利率鹰派冲击（Warsh）或净债务恶化 + OCF 停滞 → 杠杆模型 + 贴现率双杀 → F4。
- **K5（regime 新增）**：hyperscaler capex-ROI 全行业 re-rate——市场按 FCF 转化维度压 AMZN 多重估值（与基本面无关）→ 或把价格推向/穿过 buy-below（**升档触发**，非 thesis 破裂）。
- **K6**：价格跌破 ~$178（MOS 出现、base IRR 回中个位数、贴 52 周低）→ 解封顶、可评 STARTER。
- K7：Anthropic 公允价值反向失真 → 估值口径项（监控）。

## 结论
- **无硬 veto**（thesis 未结构性破裂、资产负债表能存活）。
- **实际卡点 = F6 估值无 MOS**（价格封顶 WATCH），叠加 F1 capex ROI 前瞻不确定（haircut，capex-审计年 salience 抬升）+ **Q2-2026 财报 2 天后才出、无法并入**。这是"好生意 + 错价格 + 重投资期 owner earnings 模糊 + 临财报窗口"，与 GOOGL 同构、与价格友好名相反。
