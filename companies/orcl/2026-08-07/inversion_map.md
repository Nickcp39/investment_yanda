# ORCL Inversion Map — as_of 2026-08-06

**M5 信号：−2**（risk，med-high confidence）

> 反演问题：**这笔投资如何永久性亏钱？**
> ORCL 与本库 GOOGL/AMZN/META/MSFT 四张卡的关键差异就在这一节——

## 1. 失败路径（按概率 × 严重度排序）

### F1 — 交易对手违约 / 重议（**最高优先级**）
```
机制：OpenAI（>50% RPO，>$319B）无法履约 → 递延/重议/取消
     → RPO 大幅缩水 → 已建成的算力找不到同等价格的替代买家
     → 折旧与利息照常发生 → 亏损 + 评级再降 → 融资成本上升 → 被迫贱卖资产
严重度：★★★★★（永久损失）
概率：  ❓ 无法估计 —— OpenAI 财务数据本轮未取得（O1）
可观测前兆：C8；OpenAI 融资新闻；Oracle RPO 绝对下降（K-F）
为什么它是 blocking：Oracle 承担的是**投资级公司债的确定负债**，
     承接的是**一家未上市公司的八年期承诺**。两侧确定性完全不对称。
```

### F2 — 资金链收紧（评级跌破投机级）
```
机制：FY2027 FOCF 缺口 −$42B（S&P 预测）→ 融资需求超过 $40B 计划
     → S&P 再降一档进入投机级 → ①融资成本非线性上升
       ②部分投资级基金被动减持 ③capex 被迫放缓 → backlog 转化延后
     → 收入不及指引 → 杠杆比率进一步恶化（负反馈闭环）
严重度：★★★★☆
概率：  中（已在 BBB−，一档之遥）
可观测前兆：C7 / C10 / C12；K-B / K-D
```

### F3 — 单位经济证伪（AI 算力从稀缺变过剩）
```
机制：全行业 capex 同时到位 → 算力供给过剩 → 租金下行
     → OCI 毛利率进一步压缩 → 已投入的 $130B PP&E 回报率永久低于资金成本
     → 减值 / ROIC 长期低于 WACC
严重度：★★★★☆
概率：  中
可观测前兆：GPU 利用率跌破 95%（现 97.5%）；C5 毛利率；C6 ROIC；K-E
反证：  当前 97.5% 利用率 + 92% GPU 续约率，说明**目前尚未过剩**
```

### F4 — 折旧追赶（会计的时间炸弹）
```
机制：$129.6B 的 PP&E 全面进入折旧期 → D&A 从 $9.3B 成倍上升
     （若按 6 年直线，仅现有净 PP&E 的稳态折旧就是 ~$21.6B = 当前 2.3 倍）
     → EPS 被压缩，而市场今天用的是折旧尚未到位的 EPS
严重度：★★★☆☆（不致命，但会证伪"24.6x 很便宜"）
概率：  高（这是会计必然，不是风险）
可观测前兆：C11（D&A/capex 现为 16.7%）
⚠ OPEN-O2：Oracle 实际折旧年限未从 10-K 确认。上述 6 年是**情景假设，不是指控**。
```

### F5 — 老机器加速萎缩
```
机制：Software −1% 转为 −5%/−10%（客户借云迁移之机脱离 Oracle 数据库）
     → 现金牛熄火 → 新机器失去内部资金来源 → F2 提前发生
严重度：★★★☆☆
概率：  低–中
可观测前兆：Software 分部增速；M-B（Multicloud DB）能否对冲
反证：  Multicloud AI Database +404% 表明 Oracle 正在把特许权带到别人的云上，
       这条路线**同时**缓解 F5 并绕开 capex
```

### F6 — 稀释吃掉回报（慢性失血，最容易被低估）
```
机制：FY2027 起每年 ~$40B 融资中约一半是股权 → 年化稀释 1.5–2%
     → 即使企业价值兑现，每股价值被持续摊薄
     → 本卡 base 已建模（2,880M → 3,250M），bear 建模至 3,500M
严重度：★★☆☆☆（可量化，已入模型）
概率：  高（已在发生：FY2026 由净回购转净发行）
可观测前兆：C4 / C7
```
