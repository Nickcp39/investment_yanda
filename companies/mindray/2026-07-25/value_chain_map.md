# Value Chain / Bottleneck Map

上游核心零部件、试剂原料、芯片与传感器
→ 迈瑞研发、注册、生产与质量体系
→ 海内外经销/直销、本地子公司与服务
→ 医院科室、实验室、手术室与基层医疗
→ 设备数据、试剂耗材、维保和升级复购

## 真正瓶颈

1. 不是制造产能，而是高端临床验证、监管注册和医院信任。
2. 国际化瓶颈是本地服务、供应链与合规，因此 64 家境外子公司和本地制造比单纯出口更重要。
3. IVD 的利润池取决于仪器装机后试剂菜单、检测量和留存，而非一次性卖仪器。
4. AI 若不能带来付费、提价或更高装机率，就只是维持竞争资格，不是新增护城河。
