# Inversion Map

| Kill path | 当前证据 | 需要观察 |
|---|---|---|
| 国内采购低迷变成结构性萎缩 | 2025 国内收入 -22.97%；2026Q1 仅弱复苏 | 国内连续两个季度正增长 |
| 集采/竞争持续压低毛利率 | 传统三板块收入与毛利率承压 | 毛利率止跌、价格与销量拆分 |
| 国际增长遇到贸易壁垒 | 本地化程度高，但逆全球化风险上升 | 北美/欧洲增速、关税和注册限制 |
| 新兴业务并购回报不足 | 商誉 114.04 亿元，占归母权益约 30% | 惠泰等子公司利润、现金回报与减值 |
| AI 成为昂贵但不变现的功能 | 有装机/产品案例，无收入归因 | 付费率、ASP、软件收入或续费 |

## 不足以单独击穿长期逻辑的事件

- 单季国内招标延后；
- 人民币波动造成的单季汇兑影响；
- 新产品研发导致短期费用率上升；
- 在净现金资产负债表下的一次正常周期下行。
