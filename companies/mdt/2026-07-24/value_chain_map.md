# MDT Value Chain Map — REFRESH

Last updated: 2026-07-24 | as_of: 2026-07-24 | prior: `../2026-07-05/value_chain_map.md`

---

## Position in the Chain (unchanged, with an AI-layer addition)

Upstream (components, contract mfg) → **Medtronic (device design, manufacturing, regulatory/clinical, sales/training, increasingly software/AI)** → hospitals/ASCs/physicians → patients/payers (CMS + private).

MDT captures value by owning the high-IP, high-regulatory-barrier design + clinical-evidence + physician-training + reimbursement-navigation layers. It is NOT a commodity component maker; it is the integrator/brand/clinical-evidence owner.

## Deltas This Refresh

- **Payer/reimbursement layer is a live value driver this period**: the RDN reimbursement path (CMS TPT now, permanent Cat I CPT codes pending Sept-2026 AMA review) and the CMS ASC cardiac-ablation coverage (effective 2026-01-01) show MDT's reimbursement-navigation capability directly unlocking procedure volume. This is a genuine, hard-to-replicate value-chain position (a startup or Chinese entrant lacks the CMS/AMA relationships and evidence base).
- **A software/AI layer is being added on top of hardware**: Touch Surgery Aide (built on NVIDIA infrastructure) inserts MDT into the intra-operative data/AI/decision-support layer — potentially a new value-capture point (data + AI + workflow lock-in) that sits above the robot hardware. Early, unmonetized-separately, but strategically it moves MDT up the value chain toward the "surgical operating system," where Intuitive is strongest.
- **Manufacturing/tariff resilience**: <1% direct China-import tariff exposure + 23 exclusions + diversified manufacturing — MDT has de-risked the upstream/supply value-chain leg more than peers.
- **Distribution/training moat visible in Hugo ramp**: the US Hugo rollout (Cleveland Clinic, Duke, Wake Forest first) shows the physician-training/marquee-institution distribution layer at work — but also why it's slow (hospital capital cycles, physician retraining), which is exactly why the commercial-scale question stays open.

## Where MDT is a Price-Taker vs Price-Maker

- **Price-maker-ish**: PFA (share leader, 2 modalities), renal denervation (novel category, TPT reimbursement), neuromodulation (installed-base lock-in).
- **Price-taker-ish / contested**: TAVR/structural heart (competitive pressure this period), mature spine, and — until it proves scale — robotic surgery vs Intuitive's entrenched position. VBP in China is the clearest price-taker pressure, though "largely behind us" per management.
