## 4. 🔴 「分散度值多少钱」—— 把 9.29pp 拆开

AZN base **+8.59%** vs MRK base **−0.71%**，**差 9.29pp**。
**但这不全是分散度的功劳。** 两个反事实：

| 反事实 | 结果 |
|---|---|
| **AZN 若按 MRK 的 P/S（5.55x）定价**（市值 $341.5B） | base IRR **+8.58% → +1.78%** |
| **MRK 若按 AZN 的 P/S（3.03x）定价**（市值 $202.2B） | base IRR **−0.71% → +6.42%**，**仍不到 8%** |

```
9.29pp 的差  =  约 6.8pp 来自「价格便宜」  +  约 2.5pp 来自「基本面/终局」
```

> ### ⇒ 本批配对二的答案
> **「分散度」在这一对里主要不是通过基本面创造价值，
> 而是通过"市场愿意给多少倍数"。**
>
> **把整个 9.3pp 归给"分散"是错的 —— 分散只值约 2.5pp，
> 剩下 6.8pp 是 AZN 单纯更便宜。**
>
> 但反过来也成立：**即使给 MRK AZN 的便宜倍数，MRK 也只到 +6.42%，仍不过门槛。**
> **⇒ MRK 的问题不只是价格，确实有约 2.5pp 的真实基本面差距。**
