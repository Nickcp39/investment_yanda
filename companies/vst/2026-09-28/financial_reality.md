# VST — M4 财务现实

## 1. 报表是否验证机制
| 检验 | 结果 |
|---|---|
| EBITDA 增长 | Q2 +31%，来自更高的已实现电价、容量价和 Lotus 电厂 —— **是价格 + 并购，不是有机量** |
| GAAP 净利的噪音 | Q2 含 $472M 未实现对冲损失（非现金）→ **不能用 GAAP 净利/市盈率**，用 FCFbG |
| 现金流构成（2026-09-05 立的检查项） | TTM OCF $5.12B；capex $2.87B **含增长性支出**（Permian 燃气机组、太阳能）→ 报表 FCF $2.26B 低估了维持性自由现金流；公司 FCFbG 中值 $4.325B |
| FCFbG 可信吗 | 口径 = 增长前；本卡再扣优先股股息约 $0.19B 与 SBC $0.13B → **OE ≈ $4.0B** |
| 资产负债表 | 债务 $19.6B + 其他融资 $0.9B + 优先股 $2.48B，现金 $0.44B；**约 3.2x EBITDA**；投资级（BBB−） |
| 股东权益方向 | 股数 −0.75% YoY（基本）、自 2021-11 起 −30% |

## 2. Owner earnings 三锚
| 口径 | 值 | 说明 |
|---|---:|---|
| 报表 FCF（OCF − 全部 capex） | $2.26B | 把增长性 capex 当维护 —— 过于保守 |
| **FCFbG 中值 − 优先股股息 − SBC** | **$4.0B** | base |
| 2028 对冲滚动到更低电价后的 FCFbG | ~$3.4B | bear：假设远期曲线变软的部分落地（−15%） |

OE 收益率（base）= $4.0B / $46.47B = **8.6%**。

## 3. 周期位置
**不在谷底也不在峰值**：已实现价格因对冲而高于当前现货（ERCOT North Hub $30.20/MWh 走弱中）；
2028 年仅对冲 72% —— **真正的商品风险敞口在 2028 年开始暴露**。bear 情景即按此设定。

## 4. 倍数 vs 基数
12 个月股价 −33%，同期 Q2 EBITDA +31%、2026 指引重申 → **下跌全部由倍数承担**（市场在折现 2028 年后的电价与监管，不是当期利润）。

**M4 信号：+1** —— 现金生成能力强、股数在降；扣分项是杠杆和增长依赖并购/借债。
