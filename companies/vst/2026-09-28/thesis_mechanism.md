# VST — M2 主题 / 机制

| 项 | 内容 |
|---|---|
| Theme | 数据中心要电；**已建成、可调度、低碳**的发电资产（尤其核电）变稀缺 |
| Why now | 股价 −33%（12 个月）、−36.2% 距高点，而 Q2 EBITDA +31%、全年指引重申、20 年 Meta 核电合同已签 |
| 市场叙事 | 德州 2027 远期电价偏软；监管（FERC 共址、PJM 价格上限、德州大负荷规则）会把数据中心溢价分给居民；AI 电力交易退潮 |
| 市场可能高估的 | 电价下跌对 2026–27 的影响（已对冲 100% / 94%） |
| 市场可能低估的 | ① 45U 核电 PTC 到 2032 年给电价托底；② Meta 合同 = 2,609 MW × 20 年的**长期固定需求**；③ 以 $185/股发的 500 万股收购对价，按现价等于打了七五折 |
| 资金流证据 | 公司持续回购（Q2 均价 $153.34），剩余授权约 $1.2B |
| 稀缺资源 | 核电机组（不可新建、审批十年以上）+ PJM/ERCOT 已并网燃气容量 |
| 谁付钱 | 零售电力客户（TXU 等，Retail 占 Q2 EBITDA 44%）+ 批发市场 + 长约买方（Meta） |
| 价值单位 / 成本单位 | $/MWh 与 $/MW-day 容量价 / 燃料（天然气）+ 固定运维 + 核燃料 |
| 利润池 | 电价 − 边际成本（spark spread）+ 容量费 + 核电 PTC；**商品周期决定大头** |
| 迫使市场更新的一个指标 | **2027 年 EBITDA 指引**（预计随 Q3/Q4 财报给出）：若 ≥$7.4B 下沿，"电价下行被对冲掉"成立 |
| 催化剂 | Q3 财报（约 11 月初）、Cogentrix 交割、2028 对冲进度 |
| **context_label** | **`cyclical_inflection`**（M2/M4/M5/M6 主导；典型错误 = 用峰值或谷值盈利） |

**本批配对二的对照**：BE 与 VST 都向数据中心卖电。BE 按 139 倍 owner earnings 定价、12 个月 +311%；
VST 按约 12 倍、12 个月 −33%。**市场把 BE 当未来，把 VST 当过去。**

**M2 信号：+1** —— 需求侧机制真实、有长约背书；扣分项是利润池由商品价格而非公司决定。
