**逐条的一手证据**

- **TurboTax — 漏水是真的，但方式是"主动弃低端"**：联邦单量 FY22 42.7M → FY25 **39.2M**（连跌四年，累计 −8.2%），FY2026 指引再 **−2%**；**FY2026 首次量化 e-file 份额 −1pt**；pay-nothing 客户 **800 万 → 700 万**；CEO 原话 *"We lost on price"*、*"we did not have the overall tax season we expected"*。
  **但同期**：ARPU **+11%**，TurboTax Live 收入 **+36% 至 $2.8B（占 TurboTax 收入 53%）**，Live 客户 **+38%**，付费单量 **+2%**。
  → 数学上目前还赚（价 > 量的流失）。**但生意的性质变了**：从"垄断 DIY 分发"变成"高端助报服务"，护城河从**分发**移到**专家网络 + 品牌**——后者更薄，且和 AI 正面撞。
  → **给 haircut，不给 veto。**
- **QuickBooks / GBS — 找不到裂缝**：9M FY2026 QBO Accounting **+24%**、Online Ecosystem **+20%**、GBS **+17%**；FY2025 ARPC **+14%**、付费客户 **+5%**；中端市场（QBO Advanced + Intuit Enterprise Suite）**+38%**；线上支付额 **+30%**。
  唯一裂缝：付费客户增速 **6% → 5%**（增长越来越靠提价），国际只有 +9~10%。
  → **AI 在这条腿上目前是 Intuit 的武器，不是它的敌人。**
- **Credit Karma — 好看但在减速，且历史上塌过一次**：FY2026 逐季 **+27% → +23% → +15%**；增长几乎全来自个人贷 + 车险这两个最周期的品类。**FY2023 收入 −9%、分部营业利润 −19%** 已经演示过一次周期下行。会员数从不披露。
- **Mailchimp — 一手证据链闭合**：ex-Mailchimp 增速差（Q3 GBS 报告 +15% / ex-MC **+17%**）→ MD&A 增量桥隐含 9M **≈ −$15M** → CFO 自认 *"revenue was down slightly"* 且 *"we are rightsizing our investment in Mailchimp"* → 恢复双位数增长目标从"exiting FY2026"推迟到 **"beyond fiscal 2026"**。$12B（2021）收购**至今未计提减值**。

## (c) 政策风险 —— **独立时间线，且本轮是往有利方向走的**

**这一节刻意不与 AI 叙事混谈。**

| 日期 | 事件 |
|---|---|
| 2024 | IRS Direct File 试点，12 州 |
| 2025 报税季 | 扩至 25 州，实际使用 **296,531 份** |
| **2025-11-03/05** | **IRS 产品经理致函各州："IRS Direct File will not be available in Filing Season 2026. No launch date has been set for the future."** Treasury 理由：低使用率 + 高成本（TY2024 运行成本 $41M，**≥$138/份**） |
| 现行法 | OBBBA §70607 指示财政部研究**公私合作**替代模型（方向对 Intuit 有利，不是不利） |

**量级校准**：296,531 份 ÷ 全美约 1.6 亿份个人电子申报 ≈ **0.19%**。
即便 Direct File 存活并翻十倍，也只有约 2% 的份额——**它从来不是把 Intuit 打到 13x 前瞻 P/E 的那个东西。**

**三个必须说清的推论**
1. **政策威胁在整个回撤窗口内是缓解的，不是恶化的。** 2025-11-05 Direct File 被杀，股价当月仍在跌 —— 说明市场当时定价的不是政策。
2. **2026-05-21 的 −20% 与政策无关。** 管理层把原因归到"年收入 <$5 万的价格敏感 DIY 人群"的价格竞争，并明确说 *"None of this has anything to do with AI."*
3. → **把 TurboTax 的份额流失记在政府头上是错的。** 真实的流失方向是**私营的免费/低价竞品**（Cash App Taxes、FreeTaxUSA 一类）**加上 Intuit 自己主动放弃低端**（pay-nothing 800 万 → 700 万是**策略**，不是被抢）。
4. **反向风险**：Direct File 死了，但 §70607 的公私合作替代方案是**未定的开放变量**；同时 FTC/多州"免费"广告案的后续状态本轮**未核实**（→ O10）。

## (e) Intuit 自己的 AI：**在花钱防守，收钱的证据为零**

- **零披露**：本轮**没有找到任何**AI 归因收入、AI 带来的 ARPC 增益、或 AI 定价的量化数字。**未披露本身就是发现。**

- **17% 裁员（约 3,100 人）+ $300–340M 重组费用**，管理层措辞是"faster, leaner"、"reduce management layers"、"coordination-heavy roles"。
  → 这是**用 AI 换成本**（防守型），不是**用 AI 换价格**（进攻型）。
- **唯一的进攻性证据是 ARPU +11%**，但 Intuit 把它归因于"更多客户选择助报产品与更快退款"，**没有归因于 AI**。
