# INTU Value Chain Map — as_of 2026-08-06

## 1. 消费税链条（TurboTax）

```
纳税人
  │  ① 获客：搜索 / 电视广告 / Credit Karma 导流（FY26 +54%）
  ▼
TurboTax（DIY 软件） ──分流──▶ TurboTax Live（AI + 人类专家，FY26E 占收入 53%）
  │  ② 数据导入：W-2 / 1099 / 券商 / 银行
  │  ③ 计算：税法规则引擎（← AI 已经能做，成本 ~$0.12/份）
  │  ④ 担责：准确性担保 + 稽核代表（← AI 做不了）
  ▼
⑤ 报送关口：Authorized e-File Provider + EFIN + MeF   ← 牌照卡点（O9 未一手核实）
  ▼
IRS / 50 个州税务局
  ▼
⑥ 退税：Credit Karma Money / 提前退税（>35% 客户采用）← Intuit 在这里二次变现
```

**Intuit 占住的环节**：①②③④⑤⑥ 全链。
**AI 攻击的环节**：③（已失守）、④ 的成本侧（专家时薪）。
**AI 绕不过的环节**：⑤（牌照）、④ 的责任侧、① 的品牌信任。
**Intuit 自己放弃的环节**：低价段的 ①（pay-nothing 8M → 7M）。

## 2. 小微企业链条（QuickBooks / GBS）—— 这才是主战场

```
小微/中端企业（约 1,000 万家）
  ▲                                        ▲
  │ 会计师推荐（约 100 万名）                │
  │                                         │
  ▼                                         │
QuickBooks 账套（订阅）  ───────────────────┘
  │
  ├─ 银行 / 信用卡直连  ──▶ 自动对账 ──▶ 多年历史（← 迁移壁垒的真正来源）
  │
  ├─ 收款：Intuit Payments（money transmitter 牌照）
  │        └─ 支付流水 ──▶ 抽成（Q3 FY26 线上支付额 +30%）
  │
  ├─ 发薪：QuickBooks Payroll
  │        └─ 作为 registered agent 向 50 州申报并汇缴薪资税  ← 最硬的牌照卡点
  │
  ├─ 融资：QuickBooks Capital
  │        └─ 用自家账套现金流做风控（9M FY26 放款 $4,930M，回收 $3,125M，转售 $1,389M）
  │
  └─ 营销：Mailchimp  ← 唯一没接进数据链的模块，也是唯一在萎缩的
```

**关键洞察**：Intuit 的价值捕获点已经从**订阅费**下移到**交易流水**。
Q3 FY2026 Online Services 的全部增量来自 money（+$107M）与 payroll（+$55M）——
即"账本"是入口，"钱流"才是收入。

**这也解释了为什么 AI 威胁被高估**：一个 AI 记账助手要抢的是"账本"这一层，
但 Intuit 的钱已经不主要在那一层了。

## 3. 消费金融链条（Credit Karma）

```
消费者（约 1.4 亿会员）
  │ 免费信用分 / 信用报告
  ▼
Credit Karma 匹配引擎
  │ "你大概率能批下来"
  ▼
发卡行 / 贷款商 / 保险公司  ──成交──▶ cost-per-action 付费给 Intuit
  ▲
  └── 放贷方风险胃口 = 信贷周期  ← 整条链的真实瓶颈
  │
  └─▶ 反向导流：Credit Karma → TurboTax（FY26 +54%），双用户 ARPU +30%
```

## 4. 谁在链条上有议价权（对 Intuit 不利的方向）

| 对手方 | 议价权 | 说明 |
|---|:--:|---|
| **纳税人（低价段）** | **上升** | 免费/低价替代品充分；Intuit 自认"We lost on price" |
| 纳税人（高价段） | 低 | ARPU 仍能 +11% |
| 小微企业主 | **低** | 迁移成本高；ARPC 连续两年提价 +11% / +14% |
| 会计师 | 中 | 是渠道也是守门人；改变默认推荐的成本很高 |
| 银行/支付网络 | 中 | Intuit 需要数据接入与结算通道 |
| **州税务局** | **结构性** | 50 套规则既是成本也是护城河 |
| 放贷方（Credit Karma） | **高且周期** | 他们收紧，Credit Karma 立刻掉收入 |
| **模型供应商（OpenAI 等）** | **上升** | AI 能力越来越是外购的商品，不是 Intuit 的专有优势 → 见 O5 |

---

## 5. 一句话

**Intuit 真正卖的是"跨过合规关口的通行权 + 关口两侧的数据历史"。**
凡是价值坐在关口上的（薪资代缴、支付、报送资质、账套历史），AI 短期动不了；
凡是价值坐在界面和内容上的（Mailchimp、DIY 算税），AI 已经动了或正在动。
**四条腿的差别，全部可以由这一条线解释。**
