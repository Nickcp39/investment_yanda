## 2. 股权激励的真实成本:账面的 1.70 倍

这是本次重推最重要的单一发现。用 FY2026 的回购与股数倒推:

| 步骤 | 计算 | 结果 |
|---|---|---:|
| 回购金额 | $5,412M | |
| 期内均价 | ~$321 | |
| 理论注销股数 | 5,412 / 321 | **16.9M 股** |
| 实际股数变化 | 283M → 277M | **净减 6.0M 股** |
| **=> 期内发行股数** | 16.9 − 6.0 | **10.9M 股** |
| **按市价计的稀释成本** | 10.9 × $321 | **$3,486M** |
| 账面 SBC 费用 | | $2,056M |
| **真实成本 / 账面成本** | 3,486 / 2,056 | **1.70x** |

> **公司每年用 $5,412M 回购(占市值 6.07%),只换来 2.1% 的净股数下降。
> 差额 $3,486M 全部用来堵股权激励造成的稀释 —— 而账面上只记了 $2,056M。**

**这就是三个口径的来源:**

| 口径 | owner earnings | 占营收 | 每股 | 现价收益率 | 入场倍数 |
|---|---:|---:|---:|---:|---:|
| **乐观** 正常化 FCF | $7,447M | 34.7% | $26.88 | **8.36%** | 12.0x |
| **基准** FCF − 账面 SBC | $5,391M | 25.1% | $19.46 | **6.05%** | 16.5x |
| **保守** FCF − 市值稀释 | $3,961M | 18.5% | $14.30 | **4.45%** | 22.5x |

## 5. 反向 DCF:现价隐含了什么

假设利润率走 Base 路径(+3.9pp/10y)、退出 16x、股数持平:

| 口径 | 入场倍数 | 现价收益率 | **达 8% 需营收增速** | **达 10% 需** | 达 12% 需 |
|---|---:|---:|---:|---:|---:|
| 乐观 | 12.0x | 8.36% | **2.0%** | **3.8%** | 5.7% |
| **基准** | **16.5x** | **6.05%** | **5.2%** | **7.1%** | 9.1% |
| 保守 | 22.5x | 4.45% | **8.2%** | **10.2%** | 12.2% |

**对照系:FY2027 公司指引营收 +9~10%;过去四年实际营收 CAGR +13.9%。**

> **基准口径下,现价隐含的营收增速要求只有 7.1%(达 10% IRR)—— 低于公司自己的指引。
> 这就是垫子所在。**
> **保守口径下,要求 10.2% —— 高于指引上沿。垫子消失。**

## 6. 🔴 我最大的忧虑

### 6.1 FY2026 的三个顺风,两个不会重复

| 顺风 | 量级 | 会重复吗 |
|---|---:|---|
| **OBBBA 税务窗口** | **$1,170M** | ❌ **不会** —— 已在附录证实,资本化研发 DTA $1,895M → $673M |
| **17% 裁员(~3,100 人)** | 重组费用 $300–340M | ❌ **不会** —— 裁员只能裁一次 |
| QuickBooks 真实经营杠杆 | — | ✅ **会** —— 这一条是真的 |

FY2026 那张漂亮的报表(FCF +41.5%、利润率 +1.3pp、EPS +20%),**三分之二的推力是一次性的。**

### 6.2 更要命的:历史增速本身就不可复制

四年 EPS CAGR 的分解(全部来自 10-K):

```
EPS CAGR 22.62%
  = 营收增长      13.94%
  + 利润率扩张     7.95%      <- 35% 的贡献
  + 回购           0.62%
  + 其他           0.11%
```

**那 7.95%/年,是营业利润率从 20.2% 涨到 27.4% 换来的。**

**如果再来十年同样速度,利润率要达到 58%。** 那是不可能的 —— 而且方向还在反着走:
TurboTax Live 已占 TurboTax 营收 **53%** 且增长 +37%,**那是人力密集的服务收入,不是软件收入**。
公司在用**毛利率更低的服务**去守单量。

> **所以:任何人看到「EPS 复合 22.6%,才 19.5 倍 PE」就觉得便宜的,是在犯一个具体的错误 ——
> 用一个数学上不可能重复的增速,去给一个被一次性事件抬高的基数定价。**
>
> **前向 EPS 增速结构上是 10~13%,不是 22.6%。这是我最大的忧虑,也是我把 Base 的利润率
> 扩张速度设成历史一半(+3.9pp vs +7.2pp)的原因。**

### 6.3 第二忧虑:TurboTax 的成本结构不对称

来自你自己 2026-08-07 那张卡(不是我新加的):

> **AI 处理一份标准个税的边际成本约 $0.12,TurboTax 收最高 $162。**
> 历史上,当一个产品的成本结构被压掉三个数量级,护城河如果只剩"合规资质 + 品牌 + 广告预算",
> 它撑得住十年的概率并不高。更要命的是 Intuit 自己的应对——把免费用户让出去、往高端跑——
> 在会计上好看,**在战略上是放弃分发**。

已经发生的:单量 **−2%**(Desktop **−7%**)、e-file 份额 **−1pt**、管理层原话 **"We lost on price"**。

Consumer 占营收 **40%**。**如果单量降幅从 −2% 走到 −8%,就是 Bear 情景 —— 基准口径 IRR 3.77%。**

那张卡自己写过一条检验:「**如果那天单量是 −5% 而不是 −2%,这张卡的 base 就该重写。**」
**FY2026 实际是 −2%,这一关过了。但这是一次年度检验,不是永久豁免。**

### 6.4 第三忧虑:藏在投资活动下的放贷业务

FY2026 发放应收票据 **$6,755M(+69% YoY)**,预期信用损失准备 **$134M → $237M(+77%)**。
全部走投资活动,OCF 看不见。**软件估值框架不覆盖信贷:上行期盈利前置、损失后置。**
这块现在还小,但增速是全公司最快的。

## 7. 反方 —— 帮你反驳我

我的忧虑可能错在哪,诚实列出:

| 我的忧虑 | 反方论证 |
|---|---|
| 「利润率扩张到头了」 | 27.4% 营业利润率对一家有 GBS 分部 **77% 分部利润率**的公司并不高。公司层面被 Consumer 的营销开支和 Mailchimp 拖累。**如果 Mailchimp 被处置或修复,公司利润率有非线性上修空间** —— 而它正好从 FY2027 起被单独披露 |
| 「TurboTax 要被 AI 吃掉」 | 单量 −2% 而营收 +7%、TurboTax Live +37% —— **定价权到目前为止是成立的**。而且报税的护城河不只是软件:IRS 授权、州级合规、责任担保、退税预付。ChatGPT 算得出税,但不承担审计责任 |
| 「股权成本要按市值稀释算」 | 市值稀释 $3,486M 是用 **$321 的股价**算的。股价越高,同样股数的稀释成本越高 —— **这个口径有顺周期偏差**。如果股价腰斩,这个口径会让公司「变便宜」,那显然不合理 |
| 「FY2026 是一次性堆出来的」 | 那也意味着 **FY2027 的对比基数里,税务红利消失是已知的**。市场已经知道 FY2027 指引 +9~10%,股价里应该已经反映 |
| 「$6.8B 放贷业务是风险」 | 净现金流出只有 $292M,大部分当期就卖出或回收。这更像**过桥式的资产周转**,不是留在表上的信贷簿 |

**其中第三条我认为最有力。** 市值稀释口径确实有顺周期问题。
**更中性的做法可能是:用「股权激励股数 × 长期平均股价」而不是当期股价。** 我没做这个修正。

## 8. 结论

### buy_below 建议

**采用基准口径(FCF − 账面 SBC),但把保守口径作为显式的下行检验:**

| 档位 | 价格 | 依据 |
|---|---:|---|
| **no-chase 上沿(8%)** | **~$431** | Base 情景,基准口径 |
| **buy_below 主锚(10%)** | **~$362** | Base 情景,基准口径 —— **从 $328 上修** |
| **加仓 / 评 CORE(12%)** | **~$306** | Base 情景 |
| **保守口径的 10% 线** | **~$279** | 若你认为股权成本应按市值稀释计 |
| **Bear 情景 8% 下行锚** | **~$223** | 下行保护参考,非买点 |

### 现价 $321.57 的位置

- **在基准口径的 10% 线($362)之下 12.6%** → **有垫子**
- **在保守口径的 10% 线($279)之上 15.3%** → **若按市值稀释计,没有垫子**
- Base 情景 IRR:基准口径 **11.42%**,保守口径 **8.34%**
- Bear 情景 IRR:基准口径 **3.77%**,保守口径 **0.31%** → **下行是「白等十年」,不是「亏大钱」**
