# 美债滚动压力与 YCC 可能性 — 查证计划
日期: 2026-08-11
提问: 美债利率"滚动得很厉害"是否属实? 真实利息支出多少? 是否在走向 YCC?
工作假设(用户设定): 短期内既不加息也不降息 — 若证据冲突则明确指出

## 需要回答的四个问题
1. **滚动墙有多大** — 未来 12 个月到期的国债规模、其中 T-bills 占比、加权平均到期期限(WAM)
2. **真实成本** — 财年利息支出(一手: Treasury MTS / Fiscal Data API)、债务加权平均利率、利息/GDP 与利息/财政收入
3. **市场在发生什么** — 近期收益率水平(10Y/30Y)、拍卖尾部、期限溢价、买家结构(海外/美联储/货基)
4. **YCC 信号** — 官方是否讨论、有无先例条件(2020 澳日、1942-51 美国)、触发 YCC 的前置条件是否出现

## 数据源优先级
| 层级 | 来源 | 用途 |
|---|---|---|
| 一手 | fiscaldata.treasury.gov API | 利息支出、平均利率、债务构成 |
| 一手 | treasurydirect.gov 拍卖结果 | 拍卖需求、尾部 |
| 一手 | FRED (DGS10/DGS30/GFDEBTN/A091RC1Q027SBEA) | 收益率、利息支出时序 |
| 一手 | 财政部 QRA 再融资声明 | 发行计划、期限结构指引 |
| 二手 | 财经媒体 | 只用于定位事件与时间点, 不作为数字来源 |

## 执行顺序
1. 搜索近期新闻定位事件(8月拍卖、QRA、YCC 讨论) — 只为定位
2. 拉 Fiscal Data API: 利息支出 + 平均利率 + 债务余额
3. 拉 FRED: 10Y/30Y 收益率、利息支出季频
4. 交叉核对新闻里的数字 vs 一手数据, 冲突以一手为准
5. 判断 YCC: 列出前置条件清单, 逐条对照当前状态
6. 产出 HTML

## 已知需警惕
- "利息支出超过国防开支"这类说法口径混乱(gross vs net interest), 必须标明口径
- 新闻常把"到期滚动"和"新增赤字融资"混为一谈, 要拆开
- 上一轮 wechat_mp 分析里出现"美联储换主席沃什"的未核实前提, 本次顺带验证
